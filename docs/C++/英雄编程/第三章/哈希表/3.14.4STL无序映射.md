## 本节概述：STL 里的哈希表 — unordered_map

C++ 标准库早就给我们封装好了哈希表，叫 **unordered_map**（无序映射）。

为什么叫"无序"？因为哈希表的元素不是按 key 排序的，是按哈希值分布的——遍历时顺序跟插入顺序不一样。

> 对应的还有一个 **map**，底层是红黑树（平衡二叉搜索树），是有序的，查找 O(log n)。
> unordered_map 底层是哈希表，平均 O(1)，但无序。

## 头文件和定义

引入头文件：

```cpp
#include <unordered_map>
```

它是一个模板类，两个模板参数：

| 位置 | 名称 | 说明 |
|---|---|---|
| 第一个 | **Key** | 键的类型，必须唯一 |
| 第二个 | **T** | 值的类型，可以是任意类型 |

定义方式：

```cpp
unordered_map<键类型, 值类型> 变量名;
```

举几个例子：

```cpp
unordered_map<string, int> score;   // key=名字(string), value=分数(int)
unordered_map<int, string> id2name; // key=学号(int), value=姓名(string)
unordered_map<int, int> cnt;        // key=数字(int), value=计数(int)
```

> 就跟 vector 一样，尖括号里填类型，想用什么类型就填什么。
> 第一个是 key 的类型，第二个是 value 的类型，别搞反了。

## 插入和修改 — 用中括号 `[]`

unordered_map 最方便的就是**用中括号像数组一样操作**：

```cpp
unordered_map<string, int> hashMap;

// 插入键值对
hashMap["aaa"] = 6;    // key="aaa", value=6
hashMap["xxx"] = 9;    // key="xxx", value=9

// 输出值
cout << hashMap["aaa"] << endl;   // 输出 6
```

> `哈希表[key] = value` — 赋值语法，非常直观。
>
> - 如果 key 不存在 → **插入**新的键值对
> - 如果 key 已存在 → **修改** value 的值
>
> 增和改是同一个操作——中括号赋值。

还可以直接做自增自减：

```cpp
hashMap["aaa"]++;      // value 从 6 变成 7
cout << hashMap["aaa"] << endl;   // 输出 7
```

> 这就是哈希计数器的天然写法——`hashMap[key]++` 一行搞定。
> 如果 key 不存在，中括号访问会自动插入一个默认值（int 默认 0），然后再自增变成 1。
> 第一次出现的 key 自动变成 1，正好符合计数需求。

## 查找 — find 函数

用 `find(key)` 查找某个 key 是否存在。

```cpp
if (hashMap.find("aaa") != hashMap.end()) {
    cout << "found" << endl;
}
```

> 固定语法：`对象名.find(key) != 对象名.end()`
>
> - **find** — 返回一个迭代器（可以理解成指向那个元素的指针）
> - **end()** — 表示"找不到"的特殊位置（尾部之后）
> - 不等于 end → 找到了
> - 等于 end → 没找到

> [!TIP]
> 为什么不直接用 `hashMap[key]` 判断？
> 因为中括号有副作用——**key 不存在时会自动插入一个默认值**。
> 如果你只是想查一下有没有，不想插新元素，就用 find。
>
> 比如判断一个数出现没出现过，用 find 才是正确姿势。

找到之后怎么拿 value？用迭代器的 `->second`：

```cpp
auto it = hashMap.find("aaa");
if (it != hashMap.end()) {
    cout << "value = " << it->second << endl;   // 输出 7
}
```

> `it->first` 是 key，`it->second` 是 value。
> 因为 unordered_map 存的是 pair（键值对），first 是第一个元素（key），second 是第二个（value）。

## 删除 — erase 函数

用 `erase(key)` 删除某个键值对。

```cpp
hashMap.erase("aaa");   // 删除 key="aaa" 的键值对
```

> erase 就是"擦掉、擦除"的意思（橡皮 eraser 同一个词根）。
>
> 删除之后再 find，就返回 end() 了——找不到了。

```cpp
hashMap.erase("aaa");
if (hashMap.find("aaa") == hashMap.end()) {
    cout << "not found (after erase)" << endl;   // 输出这句话
}
```

## 增删改查总览

| 操作 | 写法 | 说明 |
|---|---|---|
| **增 / 改** | `hashMap[key] = value` | key 不存在就插，存在就改 |
| **查** | `hashMap.find(key) != hashMap.end()` | 看 key 是否存在 |
| **删** | `hashMap.erase(key)` | 删除指定 key 的键值对 |
| **取值** | `hashMap[key]` 或 `it->second` | 中括号有副作用，find 更安全 |

> 就四个操作，记住这四个就够用了。

## 完整示例

```cpp
#include <iostream>
#include <unordered_map>
#include <string>
using namespace std;

int main() {
    unordered_map<string, int> hashMap;

    // ====== 插入 ======
    hashMap["aaa"] = 6;
    hashMap["xxx"] = 9;
    cout << "aaa = " << hashMap["aaa"] << endl;   // 6
    cout << "xxx = " << hashMap["xxx"] << endl;   // 9

    // ====== 修改 ======
    hashMap["aaa"]++;
    cout << "aaa++ = " << hashMap["aaa"] << endl; // 7

    hashMap["aaa"] = 5;
    cout << "aaa = 5: " << hashMap["aaa"] << endl; // 5

    // ====== 查找 ======
    if (hashMap.find("aaa") != hashMap.end()) {
        cout << "find: aaa 存在" << endl;          // 存在
    }

    if (hashMap.find("bbb") == hashMap.end()) {
        cout << "find: bbb 不存在" << endl;        // 不存在
    }

    // ====== 删除 ======
    hashMap.erase("aaa");
    if (hashMap.find("aaa") == hashMap.end()) {
        cout << "erase 后: aaa 不存在了" << endl;  // 不存在了
    }

    // ====== 哈希计数器玩法 ======
    unordered_map<int, int> counter;
    int arr[] = {3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5};
    int n = sizeof(arr) / sizeof(arr[0]);

    for (int i = 0; i < n; i++) {
        counter[arr[i]]++;   // 一行搞定计数
    }

    cout << endl << "每个数出现的次数：" << endl;
    cout << "1 出现了 " << counter[1] << " 次" << endl;  // 2
    cout << "5 出现了 " << counter[5] << " 次" << endl;  // 3
    cout << "7 出现了 " << counter[7] << " 次" << endl;  // 0（没出现过）

    return 0;
}
```

运行结果：

```
aaa = 6
xxx = 9
aaa++ = 7
aaa = 5: 5
find: aaa 存在
find: bbb 不存在
erase 后: aaa 不存在了

每个数出现的次数：
1 出现了 2 次
5 出现了 3 次
7 出现了 0 次
```

> 哈希计数器真的超好用——一行 `counter[key]++` 就搞定了。
> 比自己手写的 HashCounter 类还方便，因为不用提前分配大小，自动扩容。

## unordered_map vs map 对比

| 特性 | unordered_map | map |
|---|---|---|
| 底层实现 | 哈希表 | 红黑树（平衡BST） |
| 查找时间 | O(1) 平均 | O(log n) |
| 有序性 | 无序 | 有序（按 key 排序） |
| 插入删除 | O(1) 平均 | O(log n) |
| 头文件 | `<unordered_map>` | `<map>` |
| 适用场景 | 追求速度，不需要有序 | 需要有序，最坏情况稳定 |

> 简单记：
> - 要**快** → 用 unordered_map（哈希表）
> - 要**有序** → 用 map（红黑树）

## 注意事项

> [!WARNING]
> 1. **中括号有副作用** — 用 `hashMap[key]` 访问时，如果 key 不存在会自动插入默认值。只是想判断存在与否，用 find
> 2. **value 类型要匹配** — 定义时 value 是 int，赋值就不能给 NULL 或字符串，类型不匹配会编译报错
> 3. **迭代器访问方式** — `it->first` 是 key，`it->second` 是 value，别搞反了
> 4. **无序的** — 遍历时顺序跟插入顺序不一样，不要依赖遍历顺序
> 5. **key 必须唯一** — 同一个 key 只能有一个 value，重复插入会覆盖
> 6. **哈希函数要求** — 内置类型（int/string 等）都有默认哈希函数，自定义类型要自己写

## 本章小结

**unordered_map** 是 C++ STL 提供的哈希表实现，底层哈希表 + 链地址法，平均 O(1)。

**四大操作**：
- **增/改** — `hashMap[key] = value`，key 不存在插入，存在修改
- **查** — `hashMap.find(key) != hashMap.end()`，安全无副作用
- **删** — `hashMap.erase(key)`，直接擦除
- **取值** — 中括号或 `it->second`

**哈希计数器** — `counter[key]++` 一行搞定，第一次出现自动从 0 变成 1。

**unordered_map vs map**：一个快（哈希表，无序），一个有序（红黑树，O(log n)），按需选用。
