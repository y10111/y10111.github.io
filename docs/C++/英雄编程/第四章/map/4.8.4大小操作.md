## 本节概述：map 的大小操作

map 的大小操作和 set、vector 完全一致——就两个接口：`empty()` 判空，`size()` 获取键值对的个数。非常简单。

## 两个接口

| 函数 | 返回值 | 作用 |
|---|---|---|
| `m.empty()` | `bool` | map 为空返回 true，否则返回 false |
| `m.size()` | `size_t` | 返回 map 中键值对的个数 |

## 空 map 的情况

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<int, int> m1;   // 默认构造，空 map

    cout << "m1.empty() = " << m1.empty() << endl;   // 1（true，空）
    cout << "m1.size()  = " << m1.size()  << endl;   // 0（0 个键值对）

    return 0;
}
```

运行结果：

```
m1.empty() = 1
m1.size()  = 0
```

> 空 map：`empty()` 返回 `true`（打印出来是 1），`size()` 返回 0。

## 非空 map 的情况

```cpp
map<int, int> m2 = {
    pair<int, int>(1, 10),
    pair<int, int>(3, 30),
    pair<int, int>(4, 40),
    pair<int, int>(5, 50),
    pair<int, int>(1, 100)   // key 重复，不会插入
};

cout << "m2.empty() = " << m2.empty() << endl;   // 0（false，非空）
cout << "m2.size()  = " << m2.size()  << endl;   // 4
```

运行结果：

```
m2.empty() = 0
m2.size()  = 4
```

> [!NOTE]
> **为什么 size 是 4，不是 5？**
>
> 我传了 5 个 pair 进去，但有两个 key 都是 1。
>
> map 不允许重复 key，第二个 key=1 的会被丢弃。所以最终只有 4 个键值对，size = 4。
>
> 这又复习了一遍 map 的核心特性：**key 不重复**。

## empty 和 size 的关系

其实 `empty()` 的底层实现大致就是判断 `size() == 0`。

```cpp
// 伪代码
bool empty() const {
    return size() == 0;
}
```

> 两个函数本质上是一回事，只是表达角度不同。写代码时用哪个都行，看哪个读起来更自然。

## 完整代码示例

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    // 空 map
    map<int, int> m1;
    cout << "m1.empty() = " << m1.empty() << endl;
    cout << "m1.size()  = " << m1.size()  << endl;

    cout << "----------------" << endl;

    // 非空 map
    map<int, int> m2 = {
        pair<int, int>(1, 10),
        pair<int, int>(3, 30),
        pair<int, int>(4, 40),
        pair<int, int>(5, 50),
        pair<int, int>(1, 100)
    };
    cout << "m2.empty() = " << m2.empty() << endl;
    cout << "m2.size()  = " << m2.size()  << endl;

    return 0;
}
```

运行结果：

```
m1.empty() = 1
m1.size()  = 0
----------------
m2.empty() = 0
m2.size()  = 4
```

## 本章小结

**两个接口** — `empty()` 判空，`size()` 获取键值对个数。所有 STL 容器都一样，高度统一。

**map 的 size 是去重后的数量** — 因为 key 不允许重复，重复 key 的元素不会被计入 size。

**empty 本质就是 size == 0** — 两个函数表达同一个意思，用哪个看代码语境。

**这节课很简单** — 但它是后面操作的基础，插入、删除后都常用 size 和 empty 来判断容器状态。
