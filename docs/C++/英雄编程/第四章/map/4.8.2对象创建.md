## 本节概述：map 的对象创建

map 的对象创建和 set 很像——默认构造、初始化列表、迭代器区间、拷贝构造，四种常用方式。但 map 的每个元素是 pair（键值对），所以初始化列表里放的是一个个 pair。

## 打印函数

先写一个通用的打印函数，后面所有例子都用它。

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}
```

> [!TIP]
> **迭代器指向的是 pair**
>
> map 的迭代器解引用后得到的是一个 pair，所以：
> - `it->first` 是 key
> - `it->second` 是 value
>
> 容器是 const 的，迭代器要用 const_iterator。

## 四种创建方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 默认构造 | `map<int, int> m` | 空 map |
| 2. 初始化列表 | `map<int, int> m {{k1,v1}, {k2,v2}}` | 大括号直接给键值对 |
| 3. 迭代器区间 | `map<int, int> m(begin, end)` | 左闭右开拷贝 |
| 4. 拷贝构造 | `map<int, int> m(other)` | 复制另一个 map |

## 方式一：默认构造

```cpp
map<int, int> m1;
cout << "m1:" << endl;
printMap(m1);   // （空，什么都不输出）
```

> 默认构造函数创建一个**空的** map，size = 0。

## 方式二：初始化列表

map 的初始化列表里，每个元素都是一个 pair。两种写法都可以：

```cpp
// 写法一：等号 + 大括号（隐式构造）
map<int, int> m2_1 = {
    pair<int, int>(1, 15),
    pair<int, int>(4, 24),
    pair<int, int>(3, 43),
    pair<int, int>(2, 10)
};
cout << "m2_1:" << endl;
printMap(m2_1);

// 写法二：直接大括号（显式构造）
map<int, int> m2_2 {
    pair<int, int>(1, 18),
    pair<int, int>(4, 23),
    pair<int, int>(3, 41),
    pair<int, int>(2, 11)
};
cout << "m2_2:" << endl;
printMap(m2_2);
```

运行结果：

```
m2_1:
key=1 value=15
key=2 value=10
key=3 value=43
key=4 value=24
----------------
m2_2:
key=1 value=18
key=2 value=11
key=3 value=41
key=4 value=23
----------------
```

> [!NOTE]
> **注意两个细节**
>
> 1. **按 key 自动排序**：我插入顺序是 1、4、3、2，但输出是按 key 从小到大 1、2、3、4。底层红黑树按 key 排序。
>
> 2. **key 不重复**：如果两个 pair 的 key 相同，后面那个不会插入成功，map 里只会保留一个。
>
> 两种写法效果一样——等号版走的是隐式构造，括号版走的是显式构造，最终调用的都是初始化列表构造函数。

## 方式三：迭代器区间

```cpp
map<int, int> m3(m2_1.begin(), m2_1.end());
cout << "m3:" << endl;
printMap(m3);   // 和 m2_1 一模一样
```

> [!TIP]
> 迭代器区间是**左闭右开** `[begin, end)`：包含起点，不包含终点。
>
> 迭代器不一定非得是 map 的——只要元素类型是 pair<key, value>，其他容器的迭代器也能用。

## 方式四：拷贝构造

```cpp
map<int, int> m4(m2_2);
cout << "m4:" << endl;
printMap(m4);   // 和 m2_2 一模一样
```

> 括号里传另一个同类型的 map 对象，完整拷贝一份。
> 函数签名：`map(const map& other)`

## 完整代码示例

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    // 1. 默认构造
    map<int, int> m1;
    cout << "m1:" << endl;
    printMap(m1);

    // 2. 初始化列表（两种写法）
    map<int, int> m2_1 = {
        pair<int, int>(1, 15),
        pair<int, int>(4, 24),
        pair<int, int>(3, 43),
        pair<int, int>(2, 10)
    };
    cout << "m2_1:" << endl;
    printMap(m2_1);

    map<int, int> m2_2 {
        pair<int, int>(1, 18),
        pair<int, int>(4, 23),
        pair<int, int>(3, 41),
        pair<int, int>(2, 11)
    };
    cout << "m2_2:" << endl;
    printMap(m2_2);

    // 3. 迭代器区间
    map<int, int> m3(m2_1.begin(), m2_1.end());
    cout << "m3:" << endl;
    printMap(m3);

    // 4. 拷贝构造
    map<int, int> m4(m2_2);
    cout << "m4:" << endl;
    printMap(m4);

    return 0;
}
```

运行结果：

```
m1:
----------------
m2_1:
key=1 value=15
key=2 value=10
key=3 value=43
key=4 value=24
----------------
m2_2:
key=1 value=18
key=2 value=11
key=3 value=41
key=4 value=23
----------------
m3:
key=1 value=15
key=2 value=10
key=3 value=43
key=4 value=24
----------------
m4:
key=1 value=18
key=2 value=11
key=3 value=41
key=4 value=23
----------------
```

## 本章小结

**四种创建方式** — 默认构造、初始化列表（等号版和括号版都行）、迭代器区间、拷贝构造。跟 set 的套路一样。

**每个元素是 pair** — 初始化列表里放的是一个个 pair 对象，first 是 key，second 是 value。

**按 key 自动排序** — 不管插入顺序如何，输出一定按 key 从小到大排列，因为底层是红黑树。

**key 不重复** — 相同 key 的元素不会重复插入。

**打印函数用 const_iterator** — const 引用传参时，迭代器必须用 const_iterator，否则报错。

**构造函数有 16 个重载** — 但常用的就这 4 个，掌握核心的就行。
