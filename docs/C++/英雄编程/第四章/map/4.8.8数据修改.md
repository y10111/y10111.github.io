## 本节概述：map 的数据修改

map 的数据修改用**下标运算符 `[]`**——`m[key] = newValue`，直接把 key 对应的值改成新的。非常简单直观。

## 基本用法：赋值修改

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    map<int, int> m;
    m.insert(make_pair(1, 20));
    m.insert(make_pair(2, 330));
    m.insert(make_pair(3, 4440));
    m.insert(make_pair(4, 4000));

    cout << "修改前：" << endl;
    printMap(m);

    // 把 key=3 的 value 改成 888
    m[3] = 888;
    cout << "m[3] = 888 后：" << endl;
    printMap(m);

    return 0;
}
```

运行结果：

```
修改前：
key=1 value=20
key=2 value=330
key=3 value=4440
key=4 value=4000
----------------
m[3] = 888 后：
key=1 value=20
key=2 value=330
key=3 value=888
key=4 value=4000
----------------
```

> key=3 的 value 从 4440 变成了 888，修改成功。

## `[]` 返回的是 value 的引用

`m[key]` 返回的不是值的拷贝，而是**值的引用**。所以你不仅可以用它赋值，还可以直接对值做各种运算。

### 自增自减

```cpp
m[2]++;   // value 加 1（330 → 331）
```

### 复合赋值

```cpp
m[1] -= 21;   // value 减 21（20 → -1）
```

### 其他运算

所有能作用在 value 类型上的运算都可以用，比如 `+=`、`*=`、`/=`、`%=` 等等。

> [!TIP]
> **为什么 `[]` 能直接修改？**
>
> 因为 `m[key]` 返回的是 value 的引用（`int&`），而不是值的拷贝。
>
> 引用相当于 value 的"别名"，对引用做任何修改，本质上都是在修改 map 里的那个 value。

## 完整示例

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    map<int, int> m;
    m.insert(make_pair(1, 20));
    m.insert(make_pair(2, 330));
    m.insert(make_pair(3, 4440));
    m.insert(make_pair(4, 4000));

    cout << "原始：" << endl;
    printMap(m);

    // 1. 赋值修改
    m[3] = 888;
    cout << "m[3] = 888 后：" << endl;
    printMap(m);

    // 2. 自增
    m[2]++;
    cout << "m[2]++ 后：" << endl;
    printMap(m);

    // 3. 复合赋值
    m[1] -= 21;
    cout << "m[1] -= 21 后：" << endl;
    printMap(m);

    return 0;
}
```

运行结果：

```

key=4 value=4000
----------------
m[3] = 888 后：
key=1 value=20
key=2 value=330

key=4 value=4000
----------------
```

## 注意事项

> [!WARNING]
> **key 不存在时会自动插入**
>
> 如果你写 `m[5] = 100`，而 key=5 不在 map 里——`[]` 会先插入 (5, 默认值)，然后再把默认值改成 100。
>
> 最终效果虽然是对的（多了一个键值对），但你要知道 `[]` 有这个副作用。
>
> 如果只是想判断 key 是否存在再修改，应该先用 find 查找，确认存在后再用 `[]` 修改。

## 本章小结

**修改用 `[]`** — `m[key] = newValue`，最直观最方便的修改方式。

**`[]` 返回 value 的引用** — 所以赋值、自增、复合赋值都能用，因为操作的就是 map 里的 value 本身。

**key 不存在时 `[]` 会插入** — 这是 `[]` 的副作用。纯查找请用 find，不要用 `[]`。

**修改只改 value，不改 key** — map 的 key 是不能修改的（因为红黑树按 key 排序，改了 key 会打乱结构）。只能改 value。

**这节课很简单** — 核心就是一个 `[]`，但要理解它为什么能修改（返回引用），以及它的副作用（key 不存在会插入）。
