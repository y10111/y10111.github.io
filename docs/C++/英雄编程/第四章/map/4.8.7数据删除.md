## 本节概述：map 的数据删除

map 的删除用 `erase` 函数，有三种常用方式：按 key 删除、按迭代器删除、按区间删除。另外还有 `clear` 可以一次性清空所有元素。

## 打印函数

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}
```

## 方式一：按 key 删除

直接传 key 的值，`erase` 会找到并删掉对应的键值对：

```cpp
map<int, int> m = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

m.erase(1);          // 删除 key=1 的键值对
cout << "删除 key=1 后：" << endl;
printMap(m);
```

运行结果：

```
删除 key=1 后：
key=2 value=80
key=3 value=20
key=4 value=17
----------------
```

> 按 key 删除最方便——传 key 进去，键值对一起删掉。

## 方式二：按迭代器删除

传一个迭代器进去，删除迭代器指向的那个键值对：

```cpp
// 接着上面的 m，现在 m 里是 key=2、3、4
map<int, int>::iterator it = m.begin();   // 指向 key=2
m.erase(it);                              // 删除迭代器指向的元素
cout << "删除 begin 后：" << endl;
printMap(m);
```

运行结果：

```
删除 begin 后：
key=3 value=20
key=4 value=17
----------------
```

> [!TIP]
> **什么时候用迭代器删除？**
>
> 如果你已经有一个迭代器了（比如 find 找到的结果），直接传迭代器给 erase 比传 key 更高效——省掉了一次查找。
>
> 但要注意：必须保证迭代器有效（不等于 end）才能删除。

## 方式三：按区间删除

传两个迭代器，删除区间内的所有键值对：

```cpp
map<int, int> m = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

m.erase(m.begin(), m.end());   // 删除全部
cout << "删除全部后：" << endl;
printMap(m);                    // 空的
```

> [!IMPORTANT]
> **左闭右开区间**
>
> 和所有 STL 迭代器区间一样，`erase(first, last)` 也是**左闭右开** `[first, last)`：
> - first 指向的元素会被删除
> - last 指向的元素不会被删除
>
> 所以 `erase(m.begin(), m.end())` 就是从 begin 删到 end 之前，正好把所有元素都删光。

## 方式四：clear 清空

要删除所有元素，除了用区间删除，还可以直接调用 `clear`：

```cpp
map<int, int> m = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

m.clear();          // 清空所有元素
cout << "clear 后：" << endl;
printMap(m);         // 空的
```

> `clear()` 的效果和 `erase(begin(), end())` 一样，但写起来更简洁，意图也更明确。

## 四种删除方式对比

| 删除方式 | 写法 | 适用场景 |
|---|---|---|
| 按 key 删除 | `m.erase(key)` | 知道 key，直接删，最方便 |
| 按迭代器删除 | `m.erase(it)` | 已经有迭代器了，高效 |
| 按区间删除 | `m.erase(first, last)` | 批量删除一段，左闭右开 |
| 全部清空 | `m.clear()` | 一次性删光所有元素 |

## 迭代器失效

> [!WARNING]
> **指向被删元素的迭代器会失效**
>
> 删除操作后，指向被删除元素的那个迭代器就失效了，不能再使用。
>
> 其他没被删除的元素的迭代器仍然有效——红黑树删除节点不会影响其他节点的指针。

```cpp
map<int, int> m = { {1, 10}, {2, 20}, {3, 30} };
map<int, int>::iterator it = m.find(2);
m.erase(it);        // 删除 it 指向的元素
// cout << it->first;  // ❌ 错误！it 已经失效
```

## 完整代码示例

```cpp
#include <iostream>
#include <map>
using namespace std;

void printMap(const map<int, int>& m) {
    for (map<int, int>::const_iterator it = m.begin(); it != m.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    map<int, int> m = {
        pair<int, int>(1, 4),
        pair<int, int>(2, 80),
        pair<int, int>(3, 20),
        pair<int, int>(4, 17)
    };
    cout << "原始：" << endl;
    printMap(m);

    // 1. 按 key 删除
    m.erase(1);
    cout << "删除 key=1 后：" << endl;
    printMap(m);

    // 2. 按迭代器删除
    map<int, int>::iterator it = m.begin();
    m.erase(it);
    cout << "删除 begin 后：" << endl;
    printMap(m);

    // 恢复数据，演示区间删除和 clear
    m = {
        pair<int, int>(1, 4),
        pair<int, int>(2, 80),
        pair<int, int>(3, 20),
        pair<int, int>(4, 17)
    };

    // 3. 按区间删除（左闭右开）
    map<int, int>::iterator itL = m.find(2);
    map<int, int>::iterator itR = m.find(4);
    m.erase(itL, itR);   // 删除 [2, 4)，即 2 和 3
    cout << "删除 [2,4) 后：" << endl;
    printMap(m);

    // 4. clear 清空
    m.clear();
    cout << "clear 后：" << endl;
    printMap(m);

    return 0;
}
```

运行结果：

```
原始：
key=1 value=4
key=2 value=80
key=3 value=20
key=4 value=17
----------------
删除 key=1 后：
key=2 value=80
key=3 value=20
key=4 value=17
----------------
删除 begin 后：
key=3 value=20
key=4 value=17
----------------
删除 [2,4) 后：
key=1 value=4
key=4 value=17
----------------
clear 后：
----------------
```

## 本章小结

**erase 三种方式** — 按 key 删除（最方便）、按迭代器删除（最高效）、按区间删除（批量删除）。

**左闭右开区间** — 所有 STL 迭代器区间都是左闭右开 `[first, last)`。

**clear 一键清空** — 比 `erase(begin(), end())` 更简洁。

**迭代器失效** — 指向被删元素的迭代器会失效，删除后不能再用。其他元素的迭代器不受影响。

**时间复杂度 O(log n)** — 红黑树删除效率高。

**和 set 的删除几乎一模一样** — 只不过 set 删的是值，map 删的是键值对。
