## 本节概述：unordered_map 的数据修改

unordered_map 的数据修改用**下标运算符 中括号**——`um[key] = newValue`，直接把 key 对应的值改成新的。非常简单直观。

## 基本用法：赋值修改

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    unordered_map<int, int> um;
    um.insert(make_pair(1, 20));
    um.insert(make_pair(2, 330));
    um.insert(make_pair(3, 4440));
    um.insert(make_pair(4, 4000));

    cout << "修改前：" << endl;
    printMap(um);

    // 把 key=3 的 value 改成 888
    um[3] = 888;
    cout << "um[3] = 888 后：" << endl;
    printMap(um);

    return 0;
}
```

运行结果（顺序不固定）：

```
修改前：
key=4 value=4000
key=3 value=4440
key=2 value=330
key=1 value=20
----------------
um[3] = 888 后：
key=4 value=4000
key=3 value=888
key=2 value=330
key=1 value=20
----------------
```

> key=3 的 value 从 4440 变成了 888，修改成功。

## 中括号 返回的是 value 的引用

`um[key]` 返回的不是值的拷贝，而是**值的引用**。所以你不仅可以用它赋值，还可以直接对值做各种运算。

### 自增自减

```cpp
um[2]++;   // value 加 1（330 → 331）
```

### 复合赋值

```cpp
um[1] -= 21;   // value 减 21（20 → -1）
```

### 其他运算

所有能作用在 value 类型上的运算都可以用，比如 `+=`、`*=`、`/=`、`%=` 等等。

> [!TIP]
> **为什么 中括号 能直接修改？**
>
> 因为 `um[key]` 返回的是 value 的引用（`int&`），而不是值的拷贝。
>
> 引用相当于 value 的"别名"，对引用做任何修改，本质上都是在修改 unordered_map 里的那个 value。

## 完整示例

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    unordered_map<int, int> um;
    um.insert(make_pair(1, 20));
    um.insert(make_pair(2, 330));
    um.insert(make_pair(3, 4440));
    um.insert(make_pair(4, 4000));

    cout << "原始：" << endl;
    printMap(um);

    // 1. 赋值修改
    um[3] = 888;
    cout << "um[3] = 888 后：" << endl;
    printMap(um);

    // 2. 自增
    um[2]++;
    cout << "um[2]++ 后：" << endl;
    printMap(um);

    // 3. 复合赋值
    um[1] -= 21;
    cout << "um[1] -= 21 后：" << endl;
    printMap(um);

    return 0;
}
```

运行结果（顺序不固定）：

```
原始：
key=4 value=4000
key=3 value=4440
key=2 value=330
key=1 value=20
----------------
um[3] = 888 后：
key=4 value=4000
key=3 value=888
key=2 value=330
key=1 value=20
----------------
um[2]++ 后：
key=4 value=4000
key=3 value=888

----------------
```

## 注意事项

> [!WARNING]
> **key 不存在时会自动插入**
>
> 如果你写 `um[5] = 100`，而 key=5 不在 unordered_map 里——中括号 会先插入 (5, 默认值)，然后再把默认值改成 100。
>
> 最终效果虽然是对的（多了一个键值对），但你要知道 中括号 有这个副作用。
>
> 如果只是想判断 key 是否存在再修改，应该先用 find 查找，确认存在后再用 中括号 修改。

## 修改的是 value，key 不可修改

unordered_map 中，**key 是不能修改的**，只能修改 value。

```cpp
unordered_map<int, int> um = { {1, 10}, {2, 20} };

// ✅ 可以修改 value
um[1] = 100;

// ❌ 不能修改 key
// it->first = 5;  // 编译错误！key 是 const 的
```

> 为什么 key 不能改？
>
> 因为 key 决定了元素在哈希表中的位置（通过哈希函数计算）。如果改了 key，哈希值就变了，元素就不在正确的桶里了，后续查找就会找不到。
>
> 所以 pair 的 first 是 `const int` 类型，不允许修改。

## 本章小结

**修改用 中括号** — `um[key] = newValue`，最直观最方便的修改方式。

**中括号 返回 value 的引用** — 所以赋值、自增、复合赋值都能用，因为操作的就是 unordered_map 里的 value 本身。

**key 不存在时 中括号 会插入** — 这是 中括号 的副作用。纯查找请用 find，不要用 中括号。

**修改只改 value，不改 key** — unordered_map 的 key 是不能修改的（因为哈希表按 key 的哈希值定位，改了 key 会打乱结构）。只能改 value。

**这节课很简单** — 核心就是一个 中括号，但要理解它为什么能修改（返回引用），以及它的副作用（key 不存在会插入）。
