## 本节概述：unordered_map 的对象创建

unordered_map 的对象创建和 map 很像——默认构造、初始化列表、迭代器区间、拷贝构造，四种常用方式。但 unordered_map 的元素是无序的，打印顺序不固定。

## 打印函数

先写一个通用的打印函数，后面所有例子都用它。

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}
```

> [!TIP]
> **迭代器指向的是 pair**
>
> unordered_map 的迭代器解引用后得到的是一个 pair，所以：
> - `it->first` 是 key
> - `it->second` 是 value
>
> 容器是 const 的，迭代器要用 const_iterator。

## 四种创建方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 默认构造 | `unordered_map<int, int> um` | 空 unordered_map |
| 2. 初始化列表 | `unordered_map<int, int> um {{k1,v1}, {k2,v2}}` | 大括号直接给键值对 |
| 3. 迭代器区间 | `unordered_map<int, int> um(begin, end)` | 左闭右开拷贝 |
| 4. 拷贝构造 | `unordered_map<int, int> um(other)` | 复制另一个 unordered_map |

## 方式一：默认构造

```cpp
unordered_map<int, int> um1;
cout << "um1:" << endl;
printMap(um1);   // （空，什么都不输出）
```

> 默认构造函数创建一个**空的** unordered_map，size = 0。

## 方式二：初始化列表

unordered_map 的初始化列表里，每个元素都是一个 pair。两种写法都可以：

```cpp
// 写法一：等号 + 大括号（隐式构造）
unordered_map<int, int> um2_1 = {
    pair<int, int>(1, 15),
    pair<int, int>(4, 24),
    pair<int, int>(3, 43),
    pair<int, int>(2, 10)
};
cout << "um2_1:" << endl;
printMap(um2_1);

// 写法二：直接大括号（显式构造）
unordered_map<int, int> um2_2 {
    pair<int, int>(1, 18),
    pair<int, int>(4, 23),
    pair<int, int>(3, 41),
    pair<int, int>(2, 11)
};
cout << "um2_2:" << endl;
printMap(um2_2);
```

运行结果（顺序不固定，取决于哈希函数）：

```
um2_1:
key=2 value=10
key=3 value=43
key=1 value=15
key=4 value=24
----------------
um2_2:
key=2 value=11
key=3 value=41
key=1 value=18
key=4 value=23
----------------
```

> [!NOTE]
> **注意两个细节**
>
> 1. **元素无序**：我插入顺序是 1、4、3、2，输出顺序不一定按 key 从小到大。底层是哈希表，元素按哈希值分布在各个桶里。
>
> 2. **key 不重复**：如果两个 pair 的 key 相同，后面那个不会插入成功，unordered_map 里只会保留一个。
>
> 两种写法效果一样——等号版走的是隐式构造，括号版走的是显式构造，最终调用的都是初始化列表构造函数。

> [!TIP]
> **打印顺序不重要**
>
> 学习 unordered_map 的时候，不要纠结打印出来的顺序。它本来就是无序的，不同编译器、不同运行环境结果可能都不一样。
>
> 重点关注 key 和 value 的对应关系对不对，而不是顺序对不对。

## 方式三：迭代器区间

```cpp
unordered_map<int, int> um3(um2_1.begin(), um2_1.end());
cout << "um3:" << endl;
printMap(um3);   // 和 um2_1 内容一样，顺序可能不同
```

> [!TIP]
> 迭代器区间是**左闭右开** `[begin, end)`：包含起点，不包含终点。
>
> 迭代器不一定非得是 unordered_map 的——只要元素类型是 pair<key, value>，其他容器的迭代器也能用。

## 方式四：拷贝构造

```cpp
unordered_map<int, int> um4(um2_2);
cout << "um4:" << endl;
printMap(um4);   // 和 um2_2 一模一样
```

> 括号里传另一个同类型的 unordered_map 对象，完整拷贝一份。
> 函数签名：`unordered_map(const unordered_map& other)`

## 完整代码示例

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    // 1. 默认构造
    unordered_map<int, int> um1;
    cout << "um1:" << endl;
    printMap(um1);

    // 2. 初始化列表（两种写法）
    unordered_map<int, int> um2_1 = {
        pair<int, int>(1, 15),
        pair<int, int>(4, 24),
        pair<int, int>(3, 43),
        pair<int, int>(2, 10)
    };
    cout << "um2_1:" << endl;
    printMap(um2_1);

    unordered_map<int, int> um2_2 {
        pair<int, int>(1, 18),
        pair<int, int>(4, 23),
        pair<int, int>(3, 41),
        pair<int, int>(2, 11)
    };
    cout << "um2_2:" << endl;
    printMap(um2_2);

    // 3. 迭代器区间
    unordered_map<int, int> um3(um2_1.begin(), um2_1.end());
    cout << "um3:" << endl;
    printMap(um3);

    // 4. 拷贝构造
    unordered_map<int, int> um4(um2_2);
    cout << "um4:" << endl;
    printMap(um4);

    return 0;
}
```

运行结果（顺序不固定）：

```
um1:
----------------
um2_1:
key=2 value=10
key=3 value=43
key=1 value=15
key=4 value=24
----------------
um2_2:
key=2 value=11
key=3 value=41
key=1 value=18
key=4 value=23
----------------
um3:
key=2 value=10
key=3 value=43
key=1 value=15
key=4 value=24
----------------
um4:
key=2 value=11
key=3 value=41
key=1 value=18
key=4 value=23
----------------
```

## 本章小结

**四种创建方式** — 默认构造、初始化列表（等号版和括号版都行）、迭代器区间、拷贝构造。跟 map 的套路一样。

**每个元素是 pair** — 初始化列表里放的是一个个 pair 对象，first 是 key，second 是 value。

**元素无序** — 打印顺序不固定，取决于哈希函数和桶的数量。学习时不要纠结顺序，只关注内容对不对。

**key 不重复** — 相同 key 的元素不会重复插入。

**打印函数用 const_iterator** — const 引用传参时，迭代器必须用 const_iterator，否则报错。

**头文件是 `<unordered_map>`** — 注意和 map 的头文件 `<map>` 区分开。
