## 本节概述：unordered_map 的大小操作

unordered_map 的大小操作和 map、set、vector 完全一致——就两个接口：`empty()` 判空，`size()` 获取键值对的个数。非常简单。

## 两个接口

| 函数 | 返回值 | 作用 |
|---|---|---|
| `um.empty()` | `bool` | unordered_map 为空返回 true，否则返回 false |
| `um.size()` | `size_t` | 返回 unordered_map 中键值对的个数 |

## 空 unordered_map 的情况

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<int, int> um1;   // 默认构造，空 unordered_map

    cout << "um1.empty() = " << um1.empty() << endl;   // 1（true，空）
    cout << "um1.size()  = " << um1.size()  << endl;   // 0（0 个键值对）

    return 0;
}
```

运行结果：

```
um1.empty() = 1
um1.size()  = 0
```

> 空 unordered_map：`empty()` 返回 `true`（打印出来是 1），`size()` 返回 0。

## 非空 unordered_map 的情况

```cpp
unordered_map<int, int> um2 = {
    pair<int, int>(1, 10),
    pair<int, int>(3, 30),
    pair<int, int>(4, 40),
    pair<int, int>(5, 50),
    pair<int, int>(1, 100)   // key 重复，不会插入
};

cout << "um2.empty() = " << um2.empty() << endl;   // 0（false，非空）
cout << "um2.size()  = " << um2.size()  << endl;   // 4
```

运行结果：

```
um2.empty() = 0
um2.size()  = 4
```

> [!NOTE]
> **为什么 size 是 4，不是 5？**
>
> 我传了 5 个 pair 进去，但有两个 key 都是 1。
>
> unordered_map 不允许重复 key，第二个 key=1 的会被丢弃。所以最终只有 4 个键值对，size = 4。
>
> 这又复习了一遍 unordered_map 的核心特性：**key 不重复**。

## empty 和 size 的关系

其实 `empty()` 的底层实现大致就是判断 `size() == 0`。

```cpp
// 伪代码
bool empty() const {
    return size() == 0;
}
```

> 两个函数本质上是一回事，只是表达角度不同。写代码时用哪个都行，看哪个读起来更自然。

## 所有 STL 容器接口统一

不只是 unordered_map，所有 STL 容器的大小操作接口都是一样的：

| 容器 | empty() | size() |
|---|---|---|
| vector | 有 | 有 |
| list | 有 | 有 |
| deque | 有 | 有 |
| set / multiset | 有 | 有 |
| map / multimap | 有 | 有 |
| unordered_set / unordered_multiset | 有 | 有 |
| unordered_map / unordered_multimap | 有 | 有 |
| stack | 有 | 有 |
| queue | 有 | 有 |

> [!TIP]
> **STL 接口高度统一**
>
> 这就是 STL 的设计哲学——相同语义的操作用相同的函数名。
> 学会一个容器，其他容器举一反三，不用重新记一套接口。

## 完整代码示例

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    // 空 unordered_map
    unordered_map<int, int> um1;
    cout << "um1.empty() = " << um1.empty() << endl;
    cout << "um1.size()  = " << um1.size()  << endl;

    cout << "----------------" << endl;

    // 非空 unordered_map
    unordered_map<int, int> um2 = {
        pair<int, int>(1, 10),
        pair<int, int>(3, 30),
        pair<int, int>(4, 40),
        pair<int, int>(5, 50),
        pair<int, int>(1, 100)
    };
    cout << "um2.empty() = " << um2.empty() << endl;
    cout << "um2.size()  = " << um2.size()  << endl;

    return 0;
}
```

运行结果：

```
um1.empty() = 1
um1.size()  = 0
----------------
um2.empty() = 0
um2.size()  = 4
```

## 本章小结

**两个接口** — `empty()` 判空，`size()` 获取键值对个数。所有 STL 容器都一样，高度统一。

**unordered_map 的 size 是去重后的数量** — 因为 key 不允许重复，重复 key 的元素不会被计入 size。

**empty 本质就是 size == 0** — 两个函数表达同一个意思，用哪个看代码语境。

**这节课很简单** — 但它是后面操作的基础，插入、删除后都常用 size 和 empty 来判断容器状态。
