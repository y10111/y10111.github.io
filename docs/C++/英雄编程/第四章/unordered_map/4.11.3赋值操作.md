## 本节概述：unordered_map 的赋值操作

unordered_map 的赋值操作主要有两种：用另一个 unordered_map 对象赋值，和用初始化列表赋值。跟 map 的赋值逻辑是一样的。

## 先准备一个初始 unordered_map

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    unordered_map<int, int> um = {
        pair<int, int>(1, 20),
        pair<int, int>(2, 8),
        pair<int, int>(3, 18),
        pair<int, int>(4, 36)
    };
    cout << "um:" << endl;
    printMap(um);

    return 0;
}
```

运行结果（顺序不固定）：

```
um:
key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------
```

> [!NOTE]
> **定义时的等号 = 构造，不是赋值**
>
> `unordered_map<int, int> um = {...}` 看起来像赋值，实际上走的是**构造函数**（初始化列表构造）。
>
> 只有在对象已经创建好之后，再用等号才是真正的赋值操作。

## 方式一：对象赋值

把一个 unordered_map 完整赋值给另一个 unordered_map：

```cpp
unordered_map<int, int> um1;
um1 = um;              // 把 um 赋值给 um1
cout << "um1:" << endl;
printMap(um1);         // 和 um 一模一样
```

> 底层调用的是 `operator=(const unordered_map& other)`，先清空自己，再把对方的所有键值对拷贝过来。

## 方式二：初始化列表赋值

直接用大括号给 unordered_map 赋值：

```cpp
unordered_map<int, int> um2;
um2 = {
    pair<int, int>(1, 100),
    pair<int, int>(2, 200),
    pair<int, int>(3, 300)
};
cout << "um2:" << endl;
printMap(um2);
```

> 底层调用的是 `operator=(initializer_list<value_type> il)`，先清空原有的数据，再把列表里的键值对插进去。

## 为什么赋值运算符要返回值？

赋值运算符的返回值是 `unordered_map&`（自身的引用），而不是 `void`——因为要支持**连续赋值**：

```cpp
unordered_map<int, int> a, b, c;
a = b = c = um;   // 连续赋值
```

**执行顺序：从右往左**

1. 先执行 `c = um`，返回 `c` 的引用
2. 再执行 `b = c`，返回 `b` 的引用
3. 最后执行 `a = b`

如果返回值是 `void`，第一步执行完就变成了 `void`，后面就没法继续赋值了，编译会报错。

> [!TIP]
> **赋值运算符返回自身引用**
>
> 这是 C++ 的通用规则：`operator=` 必须返回对象自身的引用（`*this`），才能支持连续赋值的语法。
> 这个知识点在所有 STL 容器里都一样。

## 完整代码示例

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    // 初始 unordered_map
    unordered_map<int, int> um = {
        pair<int, int>(1, 20),
        pair<int, int>(2, 8),
        pair<int, int>(3, 18),
        pair<int, int>(4, 36)
    };
    cout << "um:" << endl;
    printMap(um);

    // 1. 对象赋值
    unordered_map<int, int> um1;
    um1 = um;
    cout << "um1:" << endl;
    printMap(um1);

    // 2. 初始化列表赋值
    unordered_map<int, int> um2;
    um2 = {
        pair<int, int>(1, 100),
        pair<int, int>(2, 200),
        pair<int, int>(3, 300)
    };
    cout << "um2:" << endl;
    printMap(um2);

    // 3. 连续赋值
    unordered_map<int, int> a, b, c;
    a = b = c = um;
    cout << "a:" << endl;
    printMap(a);
    cout << "b:" << endl;
    printMap(b);
    cout << "c:" << endl;
    printMap(c);

    return 0;
}
```

运行结果（顺序不固定）：

```

key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------
um1:
key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------
um2:
key=3 value=300
key=2 value=200
key=1 value=100
----------------
a:
key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------
b:
key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------

key=4 value=36
key=3 value=18
key=2 value=8
key=1 value=20
----------------
```

## 本章小结

**两种赋值方式** — 对象赋值（`um1 = um`）和初始化列表赋值（`um2 = {...}`），底层都是 `operator=` 重载。

**定义时的等号 = 构造** — 只有对象已创建后再用等号才是赋值，不要搞混。

**赋值运算符返回自身引用** — 目的是支持连续赋值（`a = b = c = um`），这是 C++ 的通用规则。

**赋值会先清空再拷贝** — 不管哪种赋值，都会先丢掉原来的数据，再放入新数据。

**和 map 的赋值几乎一模一样** — STL 接口高度统一，学会一个就能举一反三。
