## 本节概述：unordered_map 的数据删除

unordered_map 的删除用 `erase` 函数，有三种常用方式：按 key 删除、按迭代器删除、按区间删除。另外还有 `clear` 可以一次性清空所有元素。

## 打印函数

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}
```

## 方式一：按 key 删除

直接传 key 的值，`erase` 会找到并删掉对应的键值对：

```cpp
unordered_map<int, int> um = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

int n = um.erase(1);          // 删除 key=1 的键值对，返回删除的个数
cout << "删除了 " << n << " 个元素" << endl;
cout << "删除 key=1 后：" << endl;
printMap(um);
```

运行结果：

```
删除了 1 个元素
删除 key=1 后：
key=4 value=17
key=3 value=20
key=2 value=80
----------------
```

> 按 key 删除的返回值是 `size_t`，表示实际删除了几个元素。
> 对于 unordered_map 来说，因为 key 不重复，所以返回值只能是 0 或 1。

> [!TIP]
> **按 key 删除最方便**
>
> 传 key 进去，键值对一起删掉。不用先 find 再删，写起来最简洁。

## 方式二：按迭代器删除

传一个迭代器进去，删除迭代器指向的那个键值对：

```cpp
// 接着上面的 um，现在 um 里是 key=2、3、4
unordered_map<int, int>::iterator it = um.begin();   // 指向第一个元素
um.erase(it);                                        // 删除迭代器指向的元素
cout << "删除 begin 后：" << endl;
printMap(um);
```

运行结果（顺序不固定）：

```
删除 begin 后：
key=3 value=20
key=2 value=80
----------------
```

> [!TIP]
> **什么时候用迭代器删除？**
>
> 如果你已经有一个迭代器了（比如 find 找到的结果），直接传迭代器给 erase 比传 key 更高效——省掉了一次哈希查找。
>
> 但要注意：必须保证迭代器有效（不等于 end）才能删除。

## 方式三：按区间删除

传两个迭代器，删除区间内的所有键值对：

```cpp
unordered_map<int, int> um = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

um.erase(um.begin(), um.end());   // 删除全部
cout << "删除全部后：" << endl;
printMap(um);                      // 空的
```

> [!IMPORTANT]
> **左闭右开区间**
>
> 和所有 STL 迭代器区间一样，`erase(first, last)` 也是**左闭右开** `[first, last)`：
> - first 指向的元素会被删除
> - last 指向的元素不会被删除
>
> 所以 `erase(um.begin(), um.end())` 就是从 begin 删到 end 之前，正好把所有元素都删光。

> [!NOTE]
> **插入顺序与键顺序无关**
>
> 因为 unordered_map 是无序的，所以按区间删除的时候，删的是迭代器顺序上的一段，而不是按 key 大小的一段。
>
> 这一点和 map 不同——map 是按 key 排序的，所以区间删除可以删掉 key 在某个范围内的所有元素。unordered_map 做不到这一点。

## 方式四：clear 清空

要删除所有元素，除了用区间删除，还可以直接调用 `clear`：

```cpp
unordered_map<int, int> um = {
    pair<int, int>(1, 4),
    pair<int, int>(2, 80),
    pair<int, int>(3, 20),
    pair<int, int>(4, 17)
};

um.clear();          // 清空所有元素
cout << "clear 后：" << endl;
printMap(um);         // 空的
```

> `clear()` 的效果和 `erase(begin(), end())` 一样，但写起来更简洁，意图也更明确。

## 四种删除方式对比

| 删除方式 | 写法 | 返回值 | 适用场景 |
|---|---|---|---|
| 按 key 删除 | `um.erase(key)` | 删除的个数 | 知道 key，直接删，最方便 |
| 按迭代器删除 | `um.erase(it)` | 无（void） | 已经有迭代器了，高效 |
| 按区间删除 | `um.erase(first, last)` | 无（void） | 批量删除一段，左闭右开 |
| 全部清空 | `um.clear()` | 无（void） | 一次性删光所有元素 |

## 迭代器失效

> [!WARNING]
> **指向被删元素的迭代器会失效**
>
> 删除操作后，指向被删除元素的那个迭代器就失效了，不能再使用。
>
> 其他没被删除的元素的迭代器仍然有效——哈希表删除节点不会影响其他节点的指针。

```cpp
unordered_map<int, int> um = { {1, 10}, {2, 20}, {3, 30} };
unordered_map<int, int>::iterator it = um.find(2);
um.erase(it);        // 删除 it 指向的元素
// cout << it->first;  // ❌ 错误！it 已经失效
```

## 完整代码示例

```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

void printMap(const unordered_map<int, int>& um) {
    for (unordered_map<int, int>::const_iterator it = um.begin(); it != um.end(); ++it) {
        cout << "key=" << it->first
             << " value=" << it->second << endl;
    }
    cout << "----------------" << endl;
}

int main() {
    unordered_map<int, int> um = {
        pair<int, int>(1, 4),
        pair<int, int>(2, 80),
        pair<int, int>(3, 20),
        pair<int, int>(4, 17)
    };
    cout << "原始：" << endl;
    printMap(um);

    // 1. 按 key 删除
    int n = um.erase(1);
    cout << "删除了 " << n << " 个元素" << endl;
    cout << "删除 key=1 后：" << endl;
    printMap(um);

    // 2. 按迭代器删除
    unordered_map<int, int>::iterator it = um.begin();
    um.erase(it);
    cout << "删除 begin 后：" << endl;
    printMap(um);

    // 恢复数据，演示区间删除和 clear
    um = {
        pair<int, int>(1, 4),
        pair<int, int>(2, 80),
        pair<int, int>(3, 20),
        pair<int, int>(4, 17)
    };

    // 3. 按区间删除（左闭右开）
    um.erase(um.begin(), um.end());
    cout << "erase(begin, end) 后：" << endl;
    printMap(um);

    // 重新插入数据演示 clear
    um = {
        pair<int, int>(1, 4),
        pair<int, int>(2, 80),
        pair<int, int>(3, 20),
        pair<int, int>(4, 17)
    };

    // 4. clear 清空
    um.clear();
    cout << "clear 后：" << endl;
    printMap(um);

    return 0;
}
```

运行结果（顺序不固定）：

```
原始：
key=4 value=17
key=3 value=20
key=2 value=80
key=1 value=4
----------------
删除了 1 个元素
删除 key=1 后：
key=4 value=17
key=3 value=20
key=2 value=80
----------------
删除 begin 后：
key=3 value=20
key=2 value=80
----------------
erase(begin, end) 后：
----------------
clear 后：
----------------
```

## 本章小结

**erase 三种方式** — 按 key 删除（最方便，返回删除个数）、按迭代器删除（最高效）、按区间删除（批量删除）。

**左闭右开区间** — 所有 STL 迭代器区间都是左闭右开 `[first, last)`。

**clear 一键清空** — 比 `erase(begin(), end())` 更简洁。

**迭代器失效** — 指向被删元素的迭代器会失效，删除后不能再用。其他元素的迭代器不受影响。

**插入顺序与键顺序无关** — unordered_map 是无序的，区间删除删的是迭代器顺序的一段，不是 key 范围的一段。

**时间复杂度平均 O(1)** — 哈希表删除效率高。

**和 map 的删除几乎一模一样** — 只不过 map 删完还是有序的，unordered_map 删完还是无序的。
