## 本节概述：unordered_set 的数据统计

unordered_set 的数据统计用 `count` 函数，用来统计某个值在集合中出现了几次。因为 unordered_set 不允许重复元素，所以它的返回值只有两种可能：**0 或 1**。

## count 的基本用法

```cpp
#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    unordered_set<int> us = {1, 2, 3, 4, 5};

    cout << "元素 0 出现次数：" << us.count(0) << endl;   // 0
    cout << "元素 2 出现次数：" << us.count(2) << endl;   // 1
    cout << "元素 4 出现次数：" << us.count(4) << endl;   // 1
    cout << "元素 6 出现次数：" << us.count(6) << endl;   // 0

    return 0;
}
```

运行结果：

```
元素 0 出现次数：0
元素 2 出现次数：1
元素 4 出现次数：1
元素 6 出现次数：0
```

> 对于 unordered_set 来说，`count(val)` 要么返回 0（不存在），要么返回 1（存在）。

## 用循环演示 count

```cpp
unordered_set<int> us = {1, 2, 3, 4, 5};

// 遍历 0、2、4、6，看看每个数出现几次
for (int i = 0; i < 8; i += 2) {
    cout << "元素 " << i << " 出现次数：" << us.count(i) << endl;
}
```

运行结果和上面一样。

## 时间复杂度

`count` 的时间复杂度是 **均摊 O(1)**，和 `find` 一样。

> 底层都是哈希表的查找操作，先找到位置再统计。对于 unordered_set 来说，找到就返回 1，找不到就返回 0，其实就相当于判断"有没有"。

## 一个问题：为什么叫 count 而不叫 has？

既然 unordered_set 中 `count` 只有 0 和 1 两种结果，本质上就是判断"是否存在"，那为什么函数名不叫 `has` 或者 `contains` 呢？

答案是：**为了和 unordered_multiset 保持接口统一**。

```mermaid
graph TD
    A[unordered_set / unordered_multiset<br/>接口统一] --> B[count 函数]
    B --> C[unordered_set: 返回 0 或 1]
    B --> D[unordered_multiset: 返回实际出现次数]
```

> unordered_multiset 支持重复元素，所以它的 `count` 返回的是真正的数量（可以是 0、1、2、3……）。
>
> unordered_set 和 unordered_multiset 用同一个函数名 `count`，是 STL 接口设计的统一性体现——学会一个，另一个直接就能用。

> [!TIP]
> **统一命名是为了代码通用性**
>
> 假设你写了一个模板函数，既要能处理 set 也要能处理 multiset：
>
> ```cpp
> template <typename T>
> void printCount(const T& container, int val) {
>     cout << container.count(val) << endl;
> }
> ```
>
> 如果 set 叫 `has`、multiset 叫 `count`，这段代码就写不出来了。统一叫 `count`，同一个函数两种容器都能用。

## unordered_multiset 的 count（扩展）

unordered_multiset 允许重复元素，所以 count 的返回值就丰富了：

```cpp
#include <iostream>
#include <unordered_set>   // unordered_multiset 也在这个头文件里
using namespace std;

int main() {
    unordered_multiset<int> ums = {1, 2, 2, 2, 2, 2, 2, 2, 4, 4, 4, 4, 4, 6, 6, 6, 6, 6};

    for (int i = 0; i < 8; i += 2) {
        cout << "元素 " << i << " 出现次数：" << ums.count(i) << endl;
    }

    return 0;
}
```

运行结果：

```
元素 0 出现次数：0
元素 2 出现次数：7
元素 4 出现次数：5
元素 6 出现次数：5
```

> unordered_multiset 的 `count` 才真正体现了"统计数量"的含义。

## unordered_set 和 unordered_multiset 的区别

| 特性 | unordered_set | unordered_multiset |
|---|---|---|
| 元素重复 | 不允许 | 允许 |
| count 返回值 | 0 或 1 | 0、1、2……（实际数量） |
| 底层结构 | 哈希表 | 哈希表 |
| 头文件 | `#include <unordered_set>` | `#include <unordered_set>` |
| 其他接口 | 基本一致 | 基本一致 |

> [!NOTE]
> **unordered_multiset 也是无序的**
>
> unordered_multiset 的底层也是哈希表，所以元素同样是无序的。和 unordered_set 的唯一区别就是：unordered_multiset 允许重复元素。
>
> 其他接口（insert、find、erase、size、empty 等）用法几乎一样。

## 完整代码示例

```cpp
#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    // === unordered_set 的 count ===
    unordered_set<int> us = {1, 2, 3, 4, 5};
    cout << "=== unordered_set ===" << endl;
    for (int i = 0; i < 8; i += 2) {
        cout << "元素 " << i << " 出现次数：" << us.count(i) << endl;
    }

    // === unordered_multiset 的 count ===
    unordered_multiset<int> ums = {2, 2, 2, 2, 2, 2, 2, 4, 4, 4, 4, 4, 6, 6, 6, 6, 6};
    cout << "\n=== unordered_multiset ===" << endl;
    for (int i = 0; i < 8; i += 2) {
        cout << "元素 " << i << " 出现次数：" << ums.count(i) << endl;
    }

    return 0;
}
```

运行结果：

```
=== unordered_set ===
元素 0 出现次数：0
元素 2 出现次数：1
元素 4 出现次数：1
元素 6 出现次数：0

=== unordered_multiset ===
元素 0 出现次数：0
元素 2 出现次数：7
元素 4 出现次数：5
元素 6 出现次数：5
```

## 本章小结

**count 统计元素出现次数** — `us.count(val)` 返回 val 在集合中出现的次数。

**unordered_set 的 count 只有 0 或 1** — 因为元素不重复，所以 count 本质就是判断"有没有"。

**为什么叫 count 不叫 has** — 为了和 unordered_multiset 接口统一。unordered_multiset 的 count 返回真正的数量。统一命名是为了代码通用性，模板函数可以同时适配两种容器。

**时间复杂度均摊 O(1)** — 和 find 一样，哈希表查找效率高。

**unordered_multiset 是 unordered_set 的"重复版"** — 除了允许重复元素，其他特性和接口基本一致，头文件也都是 `#include <unordered_set>`。
