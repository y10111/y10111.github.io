## 本节概述：vector 的随机访问

随机访问是用 vector 的最大理由——像数组下标一样，O(1) 直接取值。

## 两种随机访问方式

| 方式 | 语法 | 越界处理 | 效率 |
|---|---|---|---|
| **中括号 `[]`** | `v[2]` | 不检查（Release 版不报错，未定义行为） | 更快 |
| **at** | `v.at(2)` | 抛异常 `out_of_range` | 稍慢（有检查） |

> [!TIP]
> 随机访问就是像数组下标一样，直接用下标取值，**O(1)**。
> 这是 vector 最大的优点——链表做不到 O(1) 随机访问，vector 可以。

## 中括号 `[]` 访问

```cpp
vector<int> v = {9, 8, 7, 6, 5};

cout << v[2] << endl;   // 7（下标从 0 开始：0→9, 1→8, 2→7）
```

> 跟数组的下标访问一模一样，下标从 0 开始。

## at 访问

```cpp
cout << v.at(2) << endl;   // 7（跟中括号结果一样）
```

> 老师进源码看了——`at` 和 `operator[]` 底层返回的是同一个东西（数组首地址 + 下标）。
> 区别在于 **at 多了一层越界检查**。

## `[]` vs at 的区别

### 源码层面

```
operator[]  →  return data[n]         （直接取值，不检查）
at(n)       →  if (n >= size)         （先检查）
                 throw out_of_range   （越界抛异常）
              return data[n]          （没越界才取值）
```

### 越界行为对比

```cpp
vector<int> v = {9, 8, 7, 6, 5};   // size=5，有效下标 0~4

// 中括号越界（Release 版）
cout << v[12] << endl;   // 不报错！输出一个垃圾值（比如 0）
                         // 这是"未定义行为"——程序不会崩，但值是错的

// at 越界
cout << v.at(12) << endl;   // 抛出 out_of_range 异常！程序中断
```

> [!WARNING]
> **中括号越界不报错，这是很多 bug 的来源！**
> - `v[12]` 越界了，程序不崩溃，返回一个垃圾值
> - 你拿这个垃圾值去用，后面逻辑全错了
> - 这种 bug 很难找——程序不报错，但结果不对
>
> **at 越界会抛异常** — 程序立刻中断，告诉你哪里错了，方便调试。

### Debug vs Release

| 模式 | `v[12]` 越界 | `v.at(12)` 越界 |
|---|---|---|
| **Debug** | 可能报错（有容器检查） | 抛异常 |
| **Release** | 不报错，返回垃圾值 | 抛异常 |

> at 无论 Debug 还是 Release 都会检查——更安全但稍慢。
> 中括号在 Release 下完全不检查——更快但有风险。

> [!NOTE]
> **实际开发建议**：
> - 如果确定下标不会越界 → 用 `[]`，效率最高
> - 如果下标可能来自外部输入 → 用 `at`，安全第一
> - 写调试阶段可以用 `at`，上线后换 `[]`

## front 和 back

```cpp
cout << v.front() << endl;   // 9（第一个元素）
cout << v.back() << endl;    // 5（最后一个元素）
```

> front 和 back 不叫随机访问，叫**访问首尾元素**。
> 随机访问是指用下标取任意位置的值。

## 完整代码示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {9, 8, 7, 6, 5};

    // 1. 中括号访问
    cout << "v[2] = " << v[2] << endl;          // 7
    cout << "v[0] = " << v[0] << endl;          // 9
    cout << "v[4] = " << v[4] << endl;          // 5

    // 2. at 访问
    cout << "v.at(2) = " << v.at(2) << endl;    // 7

    // 3. front 和 back
    cout << "v.front() = " << v.front() << endl; // 9
    cout << "v.back() = " << v.back() << endl;   // 5

    // 4. 越界对比（注意： uncomment 会导致异常！）
    // cout << v[12] << endl;      // 不报错，垃圾值（未定义行为）
    // cout << v.at(12) << endl;   // 抛出 out_of_range 异常！

    return 0;
}
```

运行结果：

```
v[2] = 7
v[0] = 9
v[4] = 5
v.at(2) = 7
v.front() = 9
v.back() = 5
```

## 本章小结

**两种随机访问**：`[]`（不检查越界，更快）和 `at`（检查越界并抛异常，更安全）。

**越界区别**：`[]` 越界返回垃圾值不报错（未定义行为，很多 bug 的来源）；`at` 越界抛 `out_of_range` 异常。

**选择建议**：确定不越界用 `[]`，可能越界用 `at`。

**front/back** — 访问首尾元素，不是随机访问。
