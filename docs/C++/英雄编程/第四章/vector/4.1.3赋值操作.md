## 本节概述：vector 的赋值操作

vector 是类，对象之间可以赋值。本节介绍四种赋值方式。

## 准备工作

先写打印函数 + 初始化一个 vector：

```cpp
#include <iostream>
#include <vector>
using namespace std;

void printVector(const vector<int>& v) {
    for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    vector<int> v = {9, 8, 5, 2, 1, 1};
    cout << "v: ";
    printVector(v);   // 9 8 5 2 1 1
    // ...
}
```

## 四种赋值方式总览

| 序号 | 方式 | 语法 | 说明 |
|---|---|---|---|
| 1 | 等号赋值 | `v1 = v;` | 重载了 `operator=`，直接赋值 |
| 2 | assign 迭代器区间 | `v2.assign(v1.begin(), v1.end());` | 左闭右开拷贝 |
| 3 | assign 初始化列表 | `v3.assign({1,2,3,4,5,6,7});` | 直接给列表 |
| 4 | assign count 个值 | `v4.assign(8, 6);` | 8 个 6 |

### 方式一：等号赋值

```cpp
vector<int> v1 = v;   // 重载了 operator=
printVector(v1);      // 9 8 5 2 1 1
```

> 等号赋值跟拷贝构造很像，区别在**时机**：
> - 拷贝构造 — **创建时**用一个已存在的初始化新对象
> - 等号赋值 — **创建后**把一个已存在的赋给另一个已存在的

### 方式二：assign 迭代器区间

```cpp
vector<int> v2;
v2.assign(v1.begin(), v1.end());
printVector(v2);   // 9 8 5 2 1 1
```

> assign 就是"赋值"的意思。传两个迭代器 `[first, last)`，左闭右开。
> 跟构造函数的迭代器区间方式很像，区别是 assign 是**对已存在的容器重新赋值**。

### 方式三：assign 初始化列表

```cpp
vector<int> v3;
v3.assign({1, 2, 3, 4, 5, 6, 7});
printVector(v3);   // 1 2 3 4 5 6 7
```

> 直接传一个初始化列表进去，一次性赋好值。

### 方式四：assign count 个值

```cpp
vector<int> v4;
v4.assign(8, 6);
printVector(v4);   // 6 6 6 6 6 6 6 6
```

> assign(8, 6) — 申请 8 个元素，每个值为 6。
> 语法：`assign(count, value)`

> [!NOTE]
> assign 有三个重载——迭代器区间、初始化列表、count+value。
> assign 和等号赋值的区别：assign 可以**改变元素个数**（原来 6 个，assign 之后可能变 8 个或 3 个），等号赋值则是**完整复制**。

## 完整代码示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

void printVector(const vector<int>& v) {
    for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    vector<int> v = {9, 8, 5, 2, 1, 1};
    cout << "v:   ";
    printVector(v);       // 9 8 5 2 1 1

    // 1. 等号赋值
    vector<int> v1 = v;
    cout << "v1:  ";
    printVector(v1);      // 9 8 5 2 1 1

    // 2. assign 迭代器区间
    vector<int> v2;
    v2.assign(v1.begin(), v1.end());
    cout << "v2:  ";
    printVector(v2);      // 9 8 5 2 1 1

    // 3. assign 初始化列表
    vector<int> v3;
    v3.assign({1, 2, 3, 4, 5, 6, 7});
    cout << "v3:  ";
    printVector(v3);      // 1 2 3 4 5 6 7

    // 4. assign count 个值
    vector<int> v4;
    v4.assign(8, 6);
    cout << "v4:  ";
    printVector(v4);      // 6 6 6 6 6 6 6 6

    return 0;
}
```

运行结果：

```
v:   9 8 5 2 1 1
v1:  9 8 5 2 1 1
v2:  9 8 5 2 1 1
v3:  1 2 3 4 5 6 7
v4:  6 6 6 6 6 6 6 6
```

## 本章小结

**四种赋值方式**：等号赋值（`operator=`）、assign 迭代器区间（`[begin, end)`）、assign 初始化列表（`{}`）、assign count 个值（`count, value`）。

**assign 三个重载** — 迭代器区间 / 初始化列表 / count+value，可以改变元素个数。

**等号赋值 vs assign**：等号完整复制，assign 可以改个数。
