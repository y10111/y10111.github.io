## 本节概述：vector 的六种创建方式

vector 是一个类，创建 vector 就是实例化对象的过程。本节介绍六种构造方式。

## 打印函数：先写个工具

后面要频繁打印 vector 的内容，先写一个打印函数：

```cpp
void printVector(const vector<int>& v) {
    for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }
    cout << endl;
}
```

> [!TIP]
> 参数为什么要用 **const 引用**？
> - **加引用** — vector 可能有一万个元素，不加引用会拷贝一份，消耗巨大；加了引用只传地址，O(1)
> - **加 const** — 只读不修改，防止函数内部误改数据
>
> 这是 STL 容器传参的**标准姿势**：`const 容器<T>& 参数名`

遍历用迭代器：`vector<int>::iterator` 是迭代器类型，从 `begin` 遍历到 `end`，`*it` 解引用拿值。

## 六种创建方式总览

| 序号 | 方式 | 语法 | 说明 |
|---|---|---|---|
| 1 | 默认构造 | `vector<int> v1;` | 空 vector，没元素 |
| 2 | 初始化列表 | `vector<int> v2 = {9,8,7,6,5};` | 跟数组初始化一样 |
| 3 | 迭代器区间 | `vector<int> v3(v2.begin(), v2.end());` | 左闭右开拷贝 |
| 4 | count 个默认值 | `vector<int> v4(8);` | 8 个 0 |
| 5 | count 个指定值 | `vector<int> v5(8, 6);` | 8 个 6 |
| 6 | 拷贝构造 | `vector<int> v6(v2);` | 复制另一个 vector |

### 方式一：默认构造

```cpp
vector<int> v1;
printVector(v1);   // 没输出（空容器）
```

> 默认构造函数不放任何数据，自然打印不出东西。正常现象。

### 方式二：初始化列表

```cpp
// 等号版（隐式构造）
vector<int> v2_1 = {9, 8, 7, 6, 5};

// 括号版（显式构造）
vector<int> v2_2({9, 6, 6, 8, 5});

printVector(v2_1);   // 9 8 7 6 5
printVector(v2_2);   // 9 6 6 8 5
```

> 两种写法效果一样——都调用 `initializer_list` 构造函数。
> - `=` 等号版是**隐式构造**——编译器发现右边是初始化列表，自动找匹配的构造函数
> - `()` 括号版是**显式构造**——直接调用
>
> 跟普通数组初始化几乎一模一样：`int a[5] = {9,8,7,6,5};`

### 方式三：迭代器区间

```cpp
vector<int> v3(v2_1.begin(), v2_1.end());
printVector(v3);   // 9 8 7 6 5（跟 v2_1 一样）
```

> 传两个迭代器 `[first, last)`，**左闭右开**——end 取不到，实际拷贝到 end 的前一个位置。
> 把另一个容器的一段区间拷过来。

### 方式四：count 个默认值

```cpp
vector<int> v4(8);
printVector(v4);   // 0 0 0 0 0 0 0 0
```

> 申请 8 个元素的空间，每个初始化为 **0**（int 默认值）。
> 不给值就默认 0——初始化成其他值反而不合理。

### 方式五：count 个指定值

```cpp
vector<int> v5(8, 6);
printVector(v5);   // 6 6 6 6 6 6 6 6
```

> 申请 8 个元素，每个初始化为 **6**。
> 语法：`vector<T>(count, value)`

### 方式六：拷贝构造

```cpp
vector<int> v6(v2_2);
printVector(v6);   // 9 6 6 8 5（跟 v2_2 一样）
```

> 传一个同类型的 vector 进去，拷贝构造一个一模一样的。
> 面向对象里学过的拷贝构造——参数是 `const vector<T>&`。

## 完整代码示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

// 打印函数
void printVector(const vector<int>& v) {
    for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    // 1. 默认构造
    vector<int> v1;
    cout << "v1: ";
    printVector(v1);       // （空）

    // 2. 初始化列表
    vector<int> v2_1 = {9, 8, 7, 6, 5};
    vector<int> v2_2({9, 6, 6, 8, 5});
    cout << "v2_1: ";
    printVector(v2_1);     // 9 8 7 6 5
    cout << "v2_2: ";
    printVector(v2_2);     // 9 6 6 8 5

    // 3. 迭代器区间
    vector<int> v3(v2_1.begin(), v2_1.end());
    cout << "v3: ";
    printVector(v3);       // 9 8 7 6 5

    // 4. count 个默认值
    vector<int> v4(8);
    cout << "v4: ";
    printVector(v4);       // 0 0 0 0 0 0 0 0

    // 5. count 个指定值
    vector<int> v5(8, 6);
    cout << "v5: ";
    printVector(v5);       // 6 6 6 6 6 6 6 6

    // 6. 拷贝构造
    vector<int> v6(v2_2);
    cout << "v6: ";
    printVector(v6);       // 9 6 6 8 5

    return 0;
}
```

运行结果：

```
v1:
v2_1: 9 8 7 6 5
v2_2: 9 6 6 8 5
v3: 9 8 7 6 5
v4: 0 0 0 0 0 0 0 0
v5: 6 6 6 6 6 6 6 6
v6: 9 6 6 8 5
```

> [!NOTE]
> 不用死记——写代码时打出 `vector<int> v(` 之后 IDE 会自动列出所有构造函数，看参数类型就知道用哪个。

## 本章小结

**六种创建方式**：默认构造（空）、初始化列表（`{}`）、迭代器区间（`[begin, end)`）、count 个默认值（全 0）、count 个指定值（全 value）、拷贝构造（复制另一个）。

**传参标准姿势**：`const 容器<T>& 参数名`——加引用避免拷贝，加 const 防止误改。

**迭代器遍历**：`vector<int>::iterator` 类型，从 `begin` 到 `end`，`*it` 解引用，`it++` 往后移。
