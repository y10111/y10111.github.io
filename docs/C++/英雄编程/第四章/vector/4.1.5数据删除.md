## 本节概述：vector 的数据删除

vector 删除数据有三个函数：**pop_back**（尾部删除）、**erase**（任意位置删除）、**clear**（全清）。

## 三个删除函数总览

| 函数 | 语法 | 说明 | 返回值 |
|---|---|---|---|
| **pop_back** | `v.pop_back();` | 删尾部最后一个元素 | 无 |
| **erase** | `v.erase(iterator);` | 删迭代器指向的元素 | 返回下一个元素的迭代器 |
| **clear** | `v.clear();` | 清空所有元素 | 无 |

## pop_back — 尾部删除

```cpp
vector<int> v = {9, 8, 5, 2, 1, 1};
printVector(v);   // 9 8 5 2 1 1

v.pop_back();     // 删掉最后一个（1）
printVector(v);   // 9 8 5 2 1
```

> pop_back 没有参数——一定是删最后一个，不需要指定。
> 跟 push_back 对应：push 往尾部加，pop 从尾部删。

> [!NOTE]
> 这里 985 是三个分开的数（9、8、5），211 是三个分开的数（2、1、1）。
> pop_back 只删最后一个元素（最后一个 1），不是删 "211" 这个数字。

## erase — 任意位置删除

erase 传一个**迭代器**，删除该位置上的元素。

```cpp
// 删第一个元素（9）
v.erase(v.begin());
printVector(v);   // 8 5 2 1

// 删第二个元素（5）
v.erase(v.begin() + 1);
printVector(v);   // 8 2 1
```

> [!WARNING]
> erase 传的是**迭代器**，不是值！
> - 如果传值，当有多个相同值时不知道删哪个
> - 传迭代器就是传位置——删第几个就删第几个，明确无歧义

### erase 的返回值

erase 删除后会**返回一个迭代器**，指向刚才删除位置的下一个元素。

```cpp
vector<int> v = {9, 8, 5, 2, 1, 1};
vector<int>::iterator it = v.erase(v.begin());   // 删掉 9
cout << *it << endl;   // 8（指向删除位置的下一个）
```

> 删掉 9 之后，it 指向 8（原来 9 的下一个位置）。
> 这个返回值在循环删除时非常有用——删完不需要手动移动迭代器。

## clear — 清空

```cpp
v.clear();        // 清空所有元素
printVector(v);   // （空）
```

> clear 一次性删完，没有参数，没有返回值。
> 清空后 vector 大小变 0，但底层数组内存还在（capacity 不变）。

## 完整代码示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

void printVector(const vector<int>& v) {
    for (vector<int>::iterator it = v.begin(); it != v.end(); it++) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    vector<int> v = {9, 8, 5, 2, 1, 1};
    cout << "原始: ";
    printVector(v);       // 9 8 5 2 1 1

    // 1. pop_back 尾部删除
    v.pop_back();
    cout << "pop_back: ";
    printVector(v);       // 9 8 5 2 1

    // 2. erase 删第一个
    v.erase(v.begin());
    cout << "erase首元素: ";
    printVector(v);       // 8 5 2 1

    // 3. erase 删第二个（begin+1）
    v.erase(v.begin() + 1);
    cout << "erase第二元素: ";
    printVector(v);       // 8 2 1

    // 4. erase 返回值
    vector<int>::iterator it = v.erase(v.begin());
    cout << "erase返回值: " << *it << endl;   // 2

    // 5. clear 清空
    v.clear();
    cout << "clear后: ";
    printVector(v);       // （空）

    return 0;
}
```

运行结果：

```
原始: 9 8 5 2 1 1
pop_back: 9 8 5 2 1
erase首元素: 8 5 2 1
erase第二元素: 8 2 1
erase返回值: 2
clear后:
```

## 本章小结

**三个删除函数**：pop_back（尾部删，无参数无返回）、erase（任意位置删，传迭代器，返回下一个迭代器）、clear（全清）。

**erase 传迭代器不传值** — 位置明确无歧义，多个相同值也不怕。

**erase 返回值** — 指向删除位置的下一个元素，循环删除时很好用。
