## 本节概述：vector 的空间预留

如果不预留空间，每次 capacity==size 都会扩容，频繁拷贝数据很慢。用 reserve 预先分配空间可以提升效率。

## 不预留空间：频繁扩容

```cpp
vector<int> v;
for (int i = 0; i < 100; i++) {
    v.push_back(i);
    cout << "size=" << v.size() << "  capacity=" << v.capacity() << endl;
}
```

输出（前几个）：

```
size=1  capacity=1      ← 扩容
size=2  capacity=2      ← 扩容
size=3  capacity=4      ← 扩容
size=4  capacity=4
size=5  capacity=6      ← 扩容
size=6  capacity=6
size=7  capacity=9      ← 扩容
size=8  capacity=9
...
```

> [!WARNING]
> 数据量小的时候扩容非常频繁——1→2→4→6→9→13→19→28...
> 每次扩容都要：申请新内存 → 拷贝旧数据 → 释放旧内存。
> 数据量大时这个开销很可观。

## 预留空间：一次到位

```cpp
vector<int> v;
v.reserve(100);   // 预留 100 个元素的空间

for (int i = 0; i < 100; i++) {
    v.push_back(i);
    cout << "size=" << v.size() << "  capacity=" << v.capacity() << endl;
}
```

输出：

```
size=1   capacity=100
size=2   capacity=100
size=3   capacity=100
...
size=100 capacity=100
```

> 预留之后 capacity 一开始就是 100，插 100 个元素全程不扩容。
> 没有内存申请和数据拷贝，效率高得多。

## reserve vs resize

| 函数 | 修改什么 | size 变不变 | capacity 变不变 |
|---|---|---|---|
| **reserve** | capacity | 不变 | 变大（只增不减） |
| **resize** | size | 变大或变小 | 不够时才扩容 |

> [!TIP]
> - `reserve(100)` — 告诉 vector "我要放 100 个元素"，先把碗做够大，但不盛饭（size 不变）
> - `resize(100)` — 直接把饭盛到 100 个（size 变 100），碗不够大就先扩容

## reserve vs reverse

> [!WARNING]
> **两个长得很像的词，千万别搞混！**
>
> | 单词 | 含义 | 用途 |
> |---|---|---|
> | **reserve** | 预留空间 | `v.reserve(100)` — 预留 capacity |
> | **reverse** | 反转 | `reverse(v.begin(), v.end())` — 翻转元素顺序 |
>
> 英语重不重要？一个字母的差别，功能完全不同。

## 完整代码示例

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 1. 不预留空间 — 频繁扩容
    cout << "=== 不预留空间 ===" << endl;
    vector<int> v1;
    int count1 = 0;  // 扩容次数
    for (int i = 0; i < 100; i++) {
        int old_cap = v1.capacity();
        v1.push_back(i);
        if (v1.capacity() != old_cap) {
            count1++;
            cout << "第" << count1 << "次扩容: size=" << v1.size()
                 << " capacity=" << v1.capacity() << endl;
        }
    }
    cout << "总共扩容 " << count1 << " 次" << endl;

    // 2. 预留空间 — 不扩容
    cout << "\n=== 预留空间 ===" << endl;
    vector<int> v2;
    v2.reserve(100);
    int count2 = 0;
    for (int i = 0; i < 100; i++) {
        int old_cap = v2.capacity();
        v2.push_back(i);
        if (v2.capacity() != old_cap) {
            count2++;
        }
    }
    cout << "总共扩容 " << count2 << " 次" << endl;

    cout << "\nv1: size=" << v1.size() << " capacity=" << v1.capacity() << endl;
    cout << "v2: size=" << v2.size() << " capacity=" << v2.capacity() << endl;

    return 0;
}
```

运行结果：

```
=== 不预留空间 ===
第1次扩容: size=1 capacity=1
第2次扩容: size=2 capacity=2
第3次扩容: size=3 capacity=4
...（省略）
总共扩容 8 次

=== 预留空间 ===
总共扩容 0 次

v1: size=100 capacity=142
v2: size=100 capacity=100
```

## 本章小结

**reserve** — 预留空间，改 capacity 不改 size，提前把碗做够大，避免频繁扩容。

**resize** — 改 size，碗不够才扩容。

**reverse** — 反转元素顺序，跟 reserve 长得像但完全不同。

**实际建议** — 已知要插入 N 个元素时，先 `reserve(N)` 再 push_back，效率最高。
