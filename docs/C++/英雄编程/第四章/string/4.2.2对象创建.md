## 本节概述：string 的对象创建

string 有 18 种构造函数重载，本节介绍常用的 6 种。

## 六种创建方式总览

| 序号 | 方式 | 语法 | 说明 |
|---|---|---|---|
| 1 | 无参构造 | `string s1;` | 空字符串 |
| 2 | 初始化列表 | `string s2 = {'h','e','l','l','o'};` | 单个字符拼接成字符串 |
| 3 | 字符串初始化 | `string s3 = "英雄哪里出来";` | 直接用字符串字面量 |
| 4 | 前 N 个字符 | `string s4("英雄哪里出来", 6);` | 取前 N 个字符 |
| 5 | 拷贝构造 | `string s5(s4);` | 复制另一个 string |
| 6 | count 个字符 | `string s6(8, 'O');` | 8 个 'O' |

### 方式一：无参构造

```cpp
string s1;
cout << s1 << endl;   // （空，什么都不输出）
```

> 构造一个空字符串，里面什么都没有。

### 方式二：初始化列表

```cpp
string s2 = {'h','e','l','l','o'};
cout << s2 << endl;   // hello
```

> [!TIP]
> 初始化列表用大括号 `{}`，里面是**单引号**引起来的单个字符，逗号分隔。
> string 会把这些字符拼起来变成一个字符串，末尾自动加 `\0`。

### 方式三：字符串初始化

```cpp
string s3 = "英雄哪里出来";
cout << s3 << endl;   // 英雄哪里出来
```

> 最常用的方式。双引号引起来的字符串字面量，直接赋值。
> 中文字符串也可以。

### 方式四：取前 N 个字符

```cpp
string s4("英雄哪里出来", 6);
cout << s4 << endl;   // 英雄哪
```

> [!WARNING]
> 这里的 N 是**字符个数**，不是"中文字数"。
> 在当前编码下，一个中文字符占 **2 个 char**：
> - N=2 → "英"
> - N=4 → "英雄"
> - N=6 → "英雄哪"
> - N=5（奇数）→ "英雄" + 半个"哪"，打印出来是乱码
>
> 奇数会把中文字符拆成两半，前半截是**不可打印字符**（负数 ASCII 码）。

### 奇数验证

```cpp
string s41("英雄哪里出来", 5);
cout << s41 << endl;          // 英雄（后面有乱码）
cout << s41.size() << endl;   // 5

// 看看第 5 个字符是什么
cout << (int)s41[4] << endl;  // -60（负数，中文的一部分）
```

> [!NOTE]
> 中文字符由多个字节组成，第一个字节的 ASCII 码是**负数**（如 -60）。
> 这是编码相关的知识（UTF-8/GBK），这里点到为止不深入。

### 方式五：拷贝构造

```cpp
string s5(s4);    // 传一个已有的 string
cout << s5 << endl;   // 英雄哪（跟 s4 一样）
```

> 面向对象学过的拷贝构造——传一个同类型的 string 进去，复制一份。

### 方式六：count 个字符

```cpp
string s6(8, 'O');
cout << s6 << endl;   // OOOOOOOO
```

> 语法：`string(count, ch)` — count 个 ch 字符拼成字符串。
> 8 个 'O' → "OOOOOOOO"

## 完整代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. 无参构造
    string s1;
    cout << "s1: " << s1 << "|" << endl;   // s1: |

    // 2. 初始化列表
    string s2 = {'h','e','l','l','o'};
    cout << "s2: " << s2 << endl;          // s2: hello

    // 3. 字符串初始化
    string s3 = "英雄哪里出来";
    cout << "s3: " << s3 << endl;          // s3: 英雄哪里出来

    // 4. 取前 N 个字符
    string s4("英雄哪里出来", 6);
    cout << "s4: " << s4 << endl;          // s4: 英雄哪

    // 5. 拷贝构造
    string s5(s4);
    cout << "s5: " << s5 << endl;          // s5: 英雄哪

    // 6. count 个字符
    string s6(8, 'O');
    cout << "s6: " << s6 << endl;          // s6: OOOOOOOO

    return 0;
}
```

运行结果：

```
s1: |
s2: hello
s3: 英雄哪里出来
s4: 英雄哪
s5: 英雄哪
s6: OOOOOOOO
```

## 本章小结

**六种创建方式** — 无参构造（空串）、初始化列表（单引号字符拼接）、字符串初始化（双引号）、前 N 个字符（注意中文占 2 个 char）、拷贝构造（复制另一个）、count 个字符（重复填充）。

**中文编码坑** — 一个中文字符占 2 个 char，取奇数个字符会把中文拆成两半，产生乱码。

**string 有 18 种构造重载** — 常用 6 种，不用死记，IDE 会自动提示。
