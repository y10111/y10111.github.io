## 本节概述：string 的拼接操作

往字符串尾部追加内容，有四种方式：`+`、`+=`、`append`、`push_back`。

## 四种拼接方式总览

| 方式 | 语法 | 适用场景 |
|---|---|---|
| `+` | `s1 = s1 + "哪里"` | 拼接后赋值，变量写两次 |
| `+=` | `s1 += "哪里"` | 直接追加，变量只写一次 |
| `append` | `s3.append("算法")` | 函数式，多种重载 |
| `push_back` | `s4.push_back('6')` | 只能追加单个字符 |

## 方式一：加号 `+`

```cpp
string s1 = "英雄";
string t1 = "出来";

s1 = s1 + "哪里";      // 英雄哪里
s1 = s1 + t1;          // 英雄哪里出来
s1 = s1 + ';';         // 英雄哪里出来;
```

> [!TIP]
> `+` 是**运算符重载**，string 是类，`operator+` 支持三种参数：
> - `const string&` — 拼 string 变量
> - `const char*` — 拼 C 字符串常量
> - `char` — 拼单个字符

## 方式二：加等于 `+=`

```cpp
string s2 = "夜深人静";
string t2 = "写算法";

s2 += "人静";     // 夜深人静人静
s2 += t2;         // 夜深人静人静写算法
s2 += '!';        // 夜深人静人静写算法!
```

> [!NOTE]
> `+=` 和 `+` 的区别：`+=` 只需要写一次变量名，更简洁。
> 底层也是运算符重载 `operator+=`。

## 方式三：append 函数

append 有多种重载版本：

### 版本一：append(字符串)

```cpp
string s3 = "英雄";
s3.append("算法");      // 英雄算法
```

### 版本二：append(string 变量)

```cpp
string t3 = "联盟";
s3.append(t3);           // 英雄算法联盟
```

### 版本三：append(字符串, n) — 取前 n 个字符

```cpp
s3.append("5201314", 3); // 英雄算法联盟520
```

> 取 "5201314" 的前 **3 个字符** 拼上去 → "520"

### 版本四：append(字符串, pos, n) — 从 pos 位置取 n 个字符

```cpp
s3.append("5201314", 3, 4);  // 英雄算法联盟5201314
```

> [!WARNING]
> **注意区分两个版本！**
>
> | 写法 | 第三个参数含义 | 结果 |
> |---|---|---|
> | `append("5201314", 3)` | 3 = **个数**，取前 3 个 | "520" |
> | `append("5201314", 3, 4)` | 3 = **位置**，4 = **个数** | "1314" |
>
> 同样是数字 3，一个代表个数，一个代表位置——容易搞混！

## 方式四：push_back

```cpp
string s4 = "英雄编程";
s4.push_back('6');   // 英雄编程6
s4.push_back('6');   // 英雄编程66
s4.push_back('6');   // 英雄编程666
s4.push_back(';');   // 英雄编程666;
```

> [!NOTE]
> `push_back` 只接受**单个字符**（`char`），没有重载版本。
> 跟 vector 的 push_back 一样——往尾部追加元素。

## 源码分析：operator+ 的实现

F12 进源码，搜 `operator+`：

```cpp
// operator+ 底层调用 append
template <class charT, class traits, class Allocator>
basic_string<charT, traits, Allocator> operator+(
    const basic_string<charT, traits, Allocator>& lhs,  // const string 引用
    const charT* rhs                                      // const char*
) {
    return basic_string<charT, traits, Allocator>(lhs) += rhs;
    //                          ↑ 拷贝构造一个新对象，再调 operator+=
}
```

> [!TIP]
> `operator+` 底层就是：**拷贝构造一个新对象 + 调 operator+=**。
> 所以 `s1 = s1 + "哪里"` 会产生一次额外拷贝，`s1 += "哪里"` 不会。
> 追求效率时用 `+=` 或 `append` 更好。

## 完整代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. 加号
    string s1 = "英雄";
    string t1 = "出来";
    s1 = s1 + "哪里";
    s1 = s1 + t1;
    s1 = s1 + ';';
    cout << "s1: " << s1 << endl;   // 英雄哪里出来;

    // 2. 加等于
    string s2 = "夜深人静";
    string t2 = "写算法";
    s2 += t2;
    s2 += '!';
    cout << "s2: " << s2 << endl;   // 夜深人静写算法!

    // 3. append
    string s3 = "英雄";
    s3.append("算法");
    string t3 = "联盟";
    s3.append(t3);
    s3.append("5201314", 3);       // 取前 3 个 → 520
    s3.append("5201314", 3, 4);    // 从位置 3 取 4 个 → 1314
    cout << "s3: " << s3 << endl;  // 英雄算法联盟5201314

    // 4. push_back
    string s4 = "英雄编程";
    s4.push_back('6');
    s4.push_back('6');
    s4.push_back('6');
    s4.push_back(';');
    cout << "s4: " << s4 << endl;   // 英雄编程666;

    return 0;
}
```

运行结果：

```
s1: 英雄哪里出来;
s2: 夜深人静写算法!
s3: 英雄算法联盟5201314
s4: 英雄编程666;
```

## 本章小结

**四种拼接方式** — `+`（运算符重载，产生额外拷贝）、`+=`（直接追加，更高效）、`append`（函数式，多种重载）、`push_back`（只追加单个字符）。

**append 两种重载** — `append(str, n)` 取前 n 个字符，`append(str, pos, n)` 从 pos 位置取 n 个字符，注意 n 和 pos 的含义不同。

**效率排序** — `+=` 和 `append` > `+`（因为 `+` 会拷贝构造新对象）。
