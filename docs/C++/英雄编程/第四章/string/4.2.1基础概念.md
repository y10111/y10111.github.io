## 本节概述：string 基础概念

C++ 风格的 string 是一个类，封装了 char 数组，自动管理内存，提供丰富的成员函数。

## C 语言字符串 vs C++ string

| 对比项 | C 语言字符串 | C++ string |
|---|---|---|
| **本质** | char 数组 | string 类的对象 |
| **定义** | `char a[20] = "hello";` | `string b = "hello";` |
| **大小** | 固定大小，必须预设 | 自动扩容，不用关心长度 |
| **操作** | C 函数（strlen/strcpy/strcat） | 成员函数（b.insert/b.find/b.replace） |
| **头文件** | `<cstring>` | `<string>`（被 `<iostream>` 隐式包含） |

## C 语言风格字符串

```cpp
char a[20] = "英雄哪里出来";
cout << a << endl;   // 直接打印字符串

// 打印地址（隐藏知识点）
cout << (void*)a << endl;   // 转成 void* 才能打印指针地址
```

> [!NOTE]
> `a` 是数组首地址（char* 指针），cout 会把它当字符串打印，不是地址。
> 要打印地址需要转成 `void*`，cout 才会识别为指针。

## C++ 风格 string

```cpp
#include <string>   // 严格来说需要包含，但 <iostream> 已经隐式包含了

string b = "英雄算法联盟";
cout << b << endl;   // 英雄算法联盟
```

> [!TIP]
> **string 是一个类，b 是对象。**
> string 内部封装了 char 数组，所有 C 语言对字符串的操作（插入、查找、替换等）都可以通过**成员函数**调用：
> - `b.insert(...)` — 插入
> - `b.find(...)` — 查找
> - `b.replace(...)` — 替换
> - 增删改查后面会一个一个讲

## string 的最大优点：自动扩容

```cpp
// C 语言：必须预设大小
char a[20] = "hello";     // 最多 19 个字符 + \0
strcat(a, " world!!!");    // 超出 20 就溢出了！

// C++ string：自动扩容
string b = "hello";
b += " world!!!";          // 不用关心长度，自动扩容
```

> [!WARNING]
> C 语言字符串必须预设固定大小，超出就溢出——很多 bug 的来源。
> string 完全不用关心长度，自动扩容——跟 vector 一样。

## 头文件隐藏知识点

```cpp
// 不写 #include <string> 也能用？
#include <iostream>
// #include <string>    ← 注释掉

string b = "hello";   // 居然能编译通过！
```

> 原因：`<iostream>` 头文件内部已经**隐式包含**了 `<string>`。
> 但如果你注释掉 `<iostream>`（比如不用 cout），string 就会报"未定义标识符"。

> [!NOTE]
> **建议还是显式写 `#include <string>`** — 不要依赖隐式包含，代码更规范、可读性更好。

## 完整代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. C 语言风格
    char a[20] = "英雄哪里出来";
    cout << "C风格: " << a << endl;
    cout << "地址: " << (void*)a << endl;

    // 2. C++ string 风格
    string b = "英雄算法联盟";
    cout << "C++风格: " << b << endl;

    // 3. 自动扩容
    string c = "hello";
    c += " world";
    c += "!!!";
    cout << "扩容后: " << c << endl;   // hello world!!!

    // 4. 成员函数预览
    cout << "长度: " << c.length() << endl;
    cout << "查找: " << c.find("world") << endl;   // 返回下标

    return 0;
}
```

运行结果：

```
C风格: 英雄哪里出来
地址: 0x7ffd1234abcd
C++风格: 英雄算法联盟
扩容后: hello world!!!
长度: 13
查找: 6
```

## 本章小结

**C 风格 vs C++ string** — char 数组（固定大小）vs string 类（自动扩容）。

**string 是类** — 封装了 char 数组，提供 insert/find/replace 等成员函数。

**自动扩容** — 不用预设长度，超出自动扩，跟 vector 一样。

**头文件** — `<iostream>` 隐式包含了 `<string>`，但建议显式写。
