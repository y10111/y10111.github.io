## 本节概述：string 的赋值操作

string 的赋值操作有两种方式：等号赋值和 assign 成员函数，assign 有 8 个重载版本，本节介绍常用的几种。

## 两种赋值方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 等号赋值 | `s = "hello";` | 最常用，底层调用 assign |
| assign 函数 | `s.assign(...)` | 更灵活，多种重载 |

## 等号赋值

### 方式一：字符串常量赋值

```cpp
string s1;
s1 = "英雄哪里出来";
cout << s1 << endl;   // 英雄哪里出来
```

> 最常用的方式。双引号字符串常量，直接用等号赋值。

### 方式二：字符串变量赋值

```cpp
string s2;
s2 = s1;
cout << s2 << endl;   // 英雄哪里出来
```

> 用一个已有的 string 变量赋值给另一个，结果一样。

### 方式三：字符常量赋值

```cpp
string s3;
s3 = 'X';
cout << s3 << endl;   // X
```

> [!TIP]
> 注意区别：
> - **双引号** `"hello"` → 字符串常量
> - **单引号** `'X'` → 字符常量
>
> 单引号赋值后，s3 也是一个字符串，只不过只有一个字符。

## assign 函数

assign 有 **8 个重载版本**，介绍常用的 4 种。

### 版本一：assign(字符串常量)

```cpp
string s4;
s4.assign("英雄算法联盟");
cout << s4 << endl;   // 英雄算法联盟
```

### 版本二：assign(字符串常量, n)

```cpp
string s5;
s5.assign("英雄算法联盟", 6);
cout << s5 << endl;   // 英雄算法
```

> [!NOTE]
> 取前 **6 个 char**（不是 6 个中文字符）。
> "英雄算法联盟" 每个中文字占 2 个 char，6 个 char = 3 个中文字 = "英雄算"。

### 版本三：assign(另一个 string)

```cpp
string s6;
s6.assign(s5);
cout << s6 << endl;   // 英雄算法（跟 s5 一样）
```

> 类似拷贝构造——直接传一个 string 进去，复制一份。

### 版本四：assign(count, ch)

```cpp
string s7;
s7.assign(8, '6');
cout << s7 << endl;   // 66666666
```

> 8 个 '6' 字符拼成字符串 → "66666666"。

## 等号赋值 vs assign

> [!TIP]
> F12 进源码发现：**等号赋值底层调的就是 assign**。
>
> 所以 `s = "hello"` 和 `s.assign("hello")` 效果完全一样，等号只是更简洁的写法。
>
> assign 的优势在于多了几种重载版本（取前 N 个、count 个字符等），更灵活。

## 完整代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. 字符串常量赋值
    string s1;
    s1 = "英雄哪里出来";
    cout << "s1: " << s1 << endl;   // 英雄哪里出来

    // 2. 字符串变量赋值
    string s2;
    s2 = s1;
    cout << "s2: " << s2 << endl;   // 英雄哪里出来

    // 3. 字符常量赋值
    string s3;
    s3 = 'X';
    cout << "s3: " << s3 << endl;   // X

    // 4. assign(字符串常量)
    string s4;
    s4.assign("英雄算法联盟");
    cout << "s4: " << s4 << endl;   // 英雄算法联盟

    // 5. assign(字符串常量, n)
    string s5;
    s5.assign("英雄算法联盟", 6);
    cout << "s5: " << s5 << endl;   // 英雄算法

    // 6. assign(另一个 string)
    string s6;
    s6.assign(s5);
    cout << "s6: " << s6 << endl;   // 英雄算法

    // 7. assign(count, ch)
    string s7;
    s7.assign(8, '6');
    cout << "s7: " << s7 << endl;   // 66666666

    return 0;
}
```

运行结果：

```
s1: 英雄哪里出来
s2: 英雄哪里出来
s3: X
s4: 英雄算法联盟
s5: 英雄算法
s6: 英雄算法
s7: 66666666
```

## 本章小结

**两种赋值方式** — 等号赋值（最常用）和 assign 函数（更灵活），等号底层调的就是 assign。

**等号赋值三种** — 字符串常量（双引号）、字符串变量、字符常量（单引号）。

**assign 四种常用版本** — assign(字符串)、assign(字符串, n)、assign(另一个string)、assign(count, ch)。
