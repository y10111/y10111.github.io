## 本节概述：string 的数据插入

使用 `insert` 成员函数在字符串的任意位置插入内容，有 9 个重载版本，本节介绍常用的几种。

## insert 常用重载总览

| 版本 | 语法 | 参数说明 |
|---|---|---|
| 插入 count 个字符 | `s.insert(pos, count, ch)` | pos=位置，count=个数，ch=字符 |
| 插入字符串 | `s.insert(pos, str)` | pos=位置，str=字符串 |
| 插入单个字符（迭代器） | `s.insert(iter, ch)` | iter=迭代器，ch=单个字符 |

## 版本一：插入 count 个字符

```cpp
string s = "heworld";

// 在位置 2 前面插入 2 个 'L'
s.insert(2, 2, 'L');
cout << s << endl;   // heLLworld
```

> [!TIP]
> 三个参数含义：
> - **第一个 2** = 位置（在 W 前面，W 的下标是 2）
> - **第二个 2** = 个数（插入 2 个）
> - **第三个 'L'** = 字符（插入什么字符）

### 位置说明

```
下标:  0  1  2  3  4  5  6
字符:  h  e  w  o  r  l  d
           ↑
        插入位置 2（在 w 前面）
```

## 版本二：插入字符串

```cpp
// 在位置 4 前面插入 "o "（o + 空格）
s.insert(4, "o ");
cout << s << endl;   // heLLo world
```

> [!NOTE]
> 这个版本只有两个参数：位置 + 字符串。
> 跟版本一是**不同的重载**——三个参数 vs 两个参数。

## 版本三：插入到尾部

```cpp
// 插入到字符串末尾
s.insert(s.size(), "嘿嘿嘿");
cout << s << endl;   // heLLo world嘿嘿嘿
```

> `s.size()` 就是末尾位置，相当于尾部追加（跟 `append` 效果一样）。

## 版本四：迭代器插入单个字符

```cpp
// 在 begin 前面插入单个字符
s.insert(s.begin(), ':');
cout << s << endl;   // :heLLo world嘿嘿嘿
```

> [!WARNING]
> **迭代器版本的限制**：
> - 第一个参数是**迭代器**（如 `s.begin()`），不是下标
> - 第二个参数只能是**单个字符**（char），不能传字符串
>
> ```cpp
> s.insert(s.begin(), "英雄编程");  // ❌ 编译报错
> s.insert(s.begin(), ':');         // ✅ 只能插单个字符
> ```
>
> 记不住没关系——写代码时编译器会报错提醒你。

## 各版本对比

| 版本 | 第一参数 | 后续参数 | 能插什么 |
|---|---|---|---|
| `insert(pos, count, ch)` | 下标 | 个数 + 字符 | 多个相同字符 |
| `insert(pos, str)` | 下标 | 字符串 | 整个字符串 |
| `insert(iter, ch)` | 迭代器 | 单个字符 | 只能单个字符 |

> [!NOTE]
> **下标 vs 迭代器**：
> - 下标版本：`insert(2, ...)` — 2 是位置，插在 W 前面
> - 迭代器版本：`insert(begin(), ...)` — begin() 是首元素前面
>
> 两种参数类型不同，触发不同的重载版本。

## 完整代码示例

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "heworld";

    // 1. 插入 2 个 'L'（三个参数版本）
    s.insert(2, 2, 'L');
    cout << "插LL: " << s << endl;     // heLLworld

    // 2. 插入字符串（两个参数版本）
    s.insert(4, "o ");
    cout << "插o空: " << s << endl;   // heLLo world

    // 3. 插入到尾部
    s.insert(s.size(), "嘿嘿嘿");
    cout << "尾部: " << s << endl;     // heLLo world嘿嘿嘿

    // 4. 迭代器插入单个字符
    s.insert(s.begin(), ':');
    cout << "开头: " << s << endl;    // :heLLo world嘿嘿嘿

    // 5. 迭代器版本不能插字符串（取消注释会报错）
    // s.insert(s.begin(), "英雄编程");  // ❌ 编译报错

    return 0;
}
```

运行结果：

```
插LL: heLLworld
插o空: heLLo world
尾部: heLLo world嘿嘿嘿
开头: :heLLo world嘿嘿嘿
```

## 本章小结

**insert 有 9 个重载** — 常用 4 种：插入 count 个字符、插入字符串、尾部插入、迭代器插入单个字符。

**三个参数版本** — `insert(pos, count, ch)`：pos 位置、count 个数、ch 字符。

**两个参数版本** — `insert(pos, str)`：pos 位置、str 字符串。

**迭代器版本** — `insert(iter, ch)`：只能插单个字符，不能插字符串。

**记不住没关系** — 写代码时编译器会报错提醒，多试几次就记住了。
