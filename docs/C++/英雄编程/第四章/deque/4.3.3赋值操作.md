## 本节概述：deque 的赋值操作

deque 的赋值操作跟 vector 基本一致，相当于复习。常见的有 4 种赋值方式。

## 四种赋值方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 等号赋值 | `dq1 = dq2` | 完整复制另一个 deque |
| 2. assign 迭代器区间 | `dq.assign(begin, end)` | 左闭右开拷贝 |
| 3. assign 初始化列表 | `dq.assign({a, b, c})` | 大括号直接给数据 |
| 4. assign count 个值 | `dq.assign(n, val)` | n 个 val |

> [!NOTE]
> **初始化 vs 赋值的区别**：
>
> - **定义时的等号** → 初始化 → 调用构造函数
> - **定义之后的等号** → 赋值 → 调用 `operator=`
>
> ```cpp
> deque<int> d2 = d1;   // 这是初始化（拷贝构造）
> deque<int> d3;
> d3 = d1;              // 这才是赋值（operator=）
> ```

## 方式一：等号赋值

```cpp
deque<int> d {9, 8, 5, 2, 1, 1};

deque<int> d1;
d1 = d;   // 赋值，调用 operator=
printDeque(d1);   // 9 8 5 2 1 1
```

> 完整复制所有数据，赋值之后两个 deque 内容一模一样。

## 方式二：assign 迭代器区间

```cpp
deque<int> d2;
d2.assign(d.begin() + 1, d.end());   // 从第 2 个开始到末尾
printDeque(d2);   // 8 5 2 1 1
```

> [!TIP]
> 传一对迭代器表示左闭右开区间 `[begin+1, end)`。
> 可以灵活控制拷贝哪一部分。

## 方式三：assign 初始化列表

```cpp
deque<int> d3;
d3.assign({1, 2, 3, 5, 6, 7});
printDeque(d3);   // 1 2 3 5 6 7
```

> 直接传大括号列表，跟构造函数的初始化列表语法类似，只是通过 assign 调用。

## 方式四：assign count 个值

```cpp
deque<int> d4;
d4.assign(8, 6);
printDeque(d4);   // 6 6 6 6 6 6 6 6
```

> 两个参数：
> - 第一个 = 元素个数（8 个）
> - 第二个 = 每个元素的值（6）

## 完整代码示例

```cpp
#include <iostream>
#include <deque>
using namespace std;

void printDeque(const deque<int>& dq) {
    for (deque<int>::const_iterator it = dq.begin(); it != dq.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    deque<int> d {9, 8, 5, 2, 1, 1};

    // 1. 等号赋值
    deque<int> d1;
    d1 = d;
    cout << "d1: "; printDeque(d1);

    // 2. assign 迭代器区间
    deque<int> d2;
    d2.assign(d.begin() + 1, d.end());
    cout << "d2: "; printDeque(d2);

    // 3. assign 初始化列表
    deque<int> d3;
    d3.assign({1, 2, 3, 5, 6, 7});
    cout << "d3: "; printDeque(d3);

    // 4. assign count 个值
    deque<int> d4;
    d4.assign(8, 6);
    cout << "d4: "; printDeque(d4);

    return 0;
}
```

运行结果：

```
d1: 9 8 5 2 1 1
d2: 8 5 2 1 1
d3: 1 2 3 5 6 7
d4: 6 6 6 6 6 6 6 6
```

## 本章小结

**deque 的 4 种赋值方式** — 等号赋值、assign 迭代器区间、assign 初始化列表、assign count 个值。

**跟 vector 完全一致** — 逻辑连续的容器，赋值接口都一样。

**初始化 vs 赋值** — 定义时的等号是初始化（构造函数），定义之后的等号才是赋值（operator=）。
