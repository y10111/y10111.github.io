## 本节概述：deque 的数据删除

跟插入对应，删除也分三种：头删 `pop_front`、尾删 `pop_back`、中间删 `erase`，再加一个全清 `clear`。

## 四种删除方式总览

| 方式 | 语法 | 时间复杂度 | 是否需要迭代器 |
|---|---|---|---|
| 头删 | `dq.pop_front()` | O(1) | 不需要 |
| 尾删 | `dq.pop_back()` | O(1) | 不需要 |
| 中间删 | `dq.erase(pos)` | O(n) | 需要 |
| 清空 | `dq.clear()` | O(n) | 不需要 |

> [!TIP]
> **头删尾删不需要迭代器**——位置固定，直接删。
> 只有 erase 删中间的，需要用迭代器告诉你删哪个。

## pop_front：头删

```cpp
deque<int> d {-1, 9, 8, 5, 2, 1, 1, -1};

d.pop_back();    // 删掉尾部的 -1
// -1 9 8 5 2 1 1

d.pop_front();   // 删掉头部的 -1
// 9 8 5 2 1 1
```

> 头删尾删都很简单，无参数无返回值，直接删第一个或最后一个元素。

## erase：删除单个元素

传一个迭代器，删掉迭代器指向的那个元素：

```cpp
deque<int> d {9, 8, 5, 2, 1, 1};

d.erase(d.begin() + 2);   // 删掉下标 2 的元素（5）
// 9 8 2 1 1
```

> [!NOTE]
> **位置对应关系**：
>
> | 迭代器 | 指向的元素 | 删除效果 |
> |---|---|---|
> | `begin()` | 第一个元素 | 删第一个，跟 pop_front 一样 |
> | `begin() + 1` | 第二个元素 | 删第二个 |
> | `begin() + 2` | 第三个元素 | 删第三个 |
> | `end() - 1` | 最后一个元素 | 删最后一个，跟 pop_back 一样 |

### erase 的返回值

erase 返回一个迭代器，指向**被删元素的下一个元素**：

```cpp
deque<int>::iterator it = d.erase(d.begin() + 2);
cout << *it << endl;   // 2（被删的 5 的下一个是 2）
```

> [!TIP]
> **返回值的用途**：可以继续删。
>
> ```cpp
> it = d.erase(it);   // 再删一个，it 又往后挪了
> ```
>
> 这就是"迭代器"名字的由来——可以不断迭代（重复）地调用。

## erase：删除区间

传两个迭代器，删掉左闭右开区间内的所有元素：

```cpp
deque<int> d {9, 8, 1, 1};

d.erase(d.begin() + 1, d.begin() + 3);
// 删掉下标 1 和 2（8 和 1），剩下 9 和 1
// 9 1
```

> [!WARNING]
> **左闭右开，个数 = end - begin**：
> - `d.begin() + 1` 到 `d.begin() + 3`
> - 包含 begin+1，不包含 begin+3
> - 删除个数 = 3 - 1 = 2 个
>
> 如果写的是 `begin + 2`，那只删 1 个元素。

## clear：清空

```cpp
d.clear();
// 空了
```

> 一次性删掉所有元素，size 变成 0。

## 验证：empty 和 size

```cpp
d.clear();
cout << d.empty() << endl;   // 1（true，空了）
cout << d.size() << endl;    // 0
```

## 完整代码示例

```cpp
#include <iostream>
#include <deque>
using namespace std;

void printDeque(const deque<int>& dq) {
    for (size_t i = 0; i < dq.size(); i++) {
        cout << dq[i] << " ";
    }
    cout << endl;
}

int main() {
    deque<int> d {-1, 9, 8, 5, 2, 1, 1, -1};
    cout << "初始: "; printDeque(d);   // -1 9 8 5 2 1 1 -1

    // 1. 尾删
    d.pop_back();
    cout << "pop_back: "; printDeque(d);   // -1 9 8 5 2 1 1

    // 2. 头删
    d.pop_front();
    cout << "pop_front: "; printDeque(d);  // 9 8 5 2 1 1

    // 3. erase 单个元素
    deque<int>::iterator it = d.erase(d.begin() + 2);
    cout << "erase(5): "; printDeque(d);   // 9 8 2 1 1
    cout << "返回迭代器的值: " << *it << endl;  // 2

    // 4. 继续删（迭代器迭代调用）
    it = d.erase(it);
    cout << "再删一个: "; printDeque(d);   // 9 8 1 1
    cout << "返回迭代器的值: " << *it << endl;  // 1

    // 5. erase 区间
    d.erase(d.begin() + 1, d.begin() + 3);
    cout << "erase区间: "; printDeque(d);  // 9 1

    // 6. clear 清空
    d.clear();
    cout << "clear后empty: " << d.empty() << endl;  // 1
    cout << "clear后size: " << d.size() << endl;    // 0

    return 0;
}
```

运行结果：

```
初始: -1 9 8 5 2 1 1 -1
pop_back: -1 9 8 5 2 1 1
pop_front: 9 8 5 2 1 1
erase(5): 9 8 2 1 1
返回迭代器的值: 2
再删一个: 9 8 1 1
返回迭代器的值: 1
erase区间: 9 1
clear后empty: 1
clear后size: 0
```

## 本章小结

**四种删除** — pop_front 头删、pop_back 尾删、erase 中间删、clear 全清。

**头尾删除最简单** — 无参数无返回，O(1)，deque 的核心优势。

**erase 删单个** — 传迭代器，返回被删元素的下一个迭代器，可以继续删。

**erase 删区间** — 左闭右开，删除个数 = end - begin。

**erase 时间复杂度** — O(n)，因为中间删除后元素要挪动填补空位。
