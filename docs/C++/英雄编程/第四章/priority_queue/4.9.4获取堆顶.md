## 本节概述：获取堆顶元素

获取堆顶元素用成员函数 **`top`**。大顶堆的 top 返回最大值，小顶堆的 top 返回最小值。它的底层就是 vector 的第一个元素，时间复杂度 O(1)。

## 基本用法

```cpp
#include <queue>
using namespace std;

priority_queue<int> pq;
pq.push(30);
pq.push(50);
pq.push(10);

cout << pq.top() << endl;   // 50（大顶堆，堆顶是最大值）
```

## 大顶堆 vs 小顶堆的 top

| 堆类型 | top 返回什么 | 说明 |
|---|---|---|
| 大顶堆 less<T> | 最大值 | 默认情况 |
| 小顶堆 greater<T> | 最小值 | 需要指定三个模板参数 |

### 对比示例

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    priority_queue<int> maxHeap;              // 大顶堆
    priority_queue<int, vector<int>, greater<int>> minHeap;  // 小顶堆

    maxHeap.push(30);  minHeap.push(30);
    maxHeap.push(10);  minHeap.push(10);
    maxHeap.push(50);  minHeap.push(50);
    maxHeap.push(20);  minHeap.push(20);
    maxHeap.push(40);  minHeap.push(40);

    cout << "大顶堆 top = " << maxHeap.top() << endl;   // 50
    cout << "小顶堆 top = " << minHeap.top() << endl;   // 10

    return 0;
}
```

运行结果：

```
大顶堆 top = 50
小顶堆 top = 10
```

同样的数据，大顶堆取到的是最大值，小顶堆取到的是最小值。

## 底层原理：就是数组第 0 个元素

top 的底层实现非常简单——直接返回底层 vector 的第一个元素：

```cpp
const_reference top() const {
    return c.front();   // c 是底层 vector，front() 就是第 0 个元素
}
```

```mermaid

    A[pq.top] --> B[调用底层容器的front]
    B --> C[返回数组下标为零的元素]
    C --> D[时间复杂度为O(1)]
```

堆顶永远在数组下标 0 的位置，所以直接取就行，不用算、不用找——**O(1) 时间复杂度**。

> [!TIP]
> **为什么堆顶固定在下标 0？**
>
> 因为堆的性质决定了——堆顶是优先级最高的元素，永远是根节点。
> 而完全二叉树的根节点就是数组第 0 个元素，位置固定不变。
> 所以不管怎么 push 怎么 pop，堆顶永远在下标 0。

## top 是只读的

`top()` 返回的是 const 引用，只能读不能改。

```cpp
pq.top() = 100;   // ❌ 编译报错！不能通过 top 修改堆顶
```

为什么不让改？因为如果你改了堆顶的值，堆的性质就被破坏了——堆顶可能不再是最大/最小值。所以 STL 设计成只读的，防止你不小心搞乱堆结构。

> [!WARNING]
> **空堆不能 top！**
>
> 优先队列为空时调用 `top()` 是未定义行为，会触发断言报错。
> 取值前先用 `empty()` 判断一下。
>
> 标准写法是先判空再取值：`if (!pq.empty()) { cout << pq.top(); }`

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    // 大顶堆
    priority_queue<int> maxHeap;

    // 空的时候不能 top
    cout << "empty = " << maxHeap.empty() << endl;   // 1（空）

    maxHeap.push(30);
    maxHeap.push(10);
    maxHeap.push(50);
    maxHeap.push(20);
    maxHeap.push(40);

    // 取堆顶
    cout << "堆顶 = " << maxHeap.top() << endl;      // 50
    cout << "大小 = " << maxHeap.size() << endl;     // 5

    // top 是只读的，不能修改
    // maxHeap.top() = 100;  // 编译报错

    // 小顶堆
    priority_queue<int, vector<int>, greater<int>> minHeap;
    minHeap.push(30);
    minHeap.push(10);
    minHeap.push(50);

    cout << "小顶堆堆顶 = " << minHeap.top() << endl; // 10

    return 0;
}
```

运行结果：

```
empty = 1
堆顶 = 50
大小 = 5
小顶堆堆顶 = 10
```

## 本章小结

**接口是 top** — `pq.top()` 获取堆顶元素，返回 const 引用（只读）。

**大顶堆 top 是最大值** — 默认情况，返回优先级最高（值最大）的元素。

**小顶堆 top 是最小值** — 指定 greater<T> 后，返回值最小的元素。

**底层是 vector 的 front** — 就是数组第 0 个元素，堆顶位置固定不变。

**时间复杂度 O(1)** — 直接取下标 0，常数时间，非常快。

**top 是只读的** — 不能通过 top 修改堆顶元素，防止破坏堆性质。

**空堆不能 top** — 操作前先用 empty() 检查，否则崩溃。
