## 本节概述：priority_queue 的大小操作

priority_queue 的大小操作有两个接口：**`empty`** 和 **`size`**。前者判断队列是否为空，后者返回元素个数。这俩函数和 queue、stack 的同名函数用法完全一致。

## 两个接口总览

| 接口 | 返回值 | 作用 |
|---|---|---|
| `pq.empty()` | bool（true/false） | 优先队列是否为空 |
| `pq.size()` | size_t（无符号整数） | 优先队列中元素个数 |

> STL 容器的大小操作命名非常统一：empty 判空、size 取个数。
> 学过一个容器，其他容器直接套用法就行，不用重新记。

## empty 判空

```cpp
priority_queue<int> pq;
cout << pq.empty() << endl;   // 1（空）

pq.push(10);
cout << pq.empty() << endl;   // 0（非空）
```

空队列返回 true（也就是 1），有元素返回 false（也就是 0）。

## size 取元素个数

```cpp
priority_queue<int> pq;
cout << pq.size() << endl;    // 0

pq.push(10);
pq.push(20);
pq.push(30);
cout << pq.size() << endl;    // 3
```

size 返回的是当前堆里有多少个元素。

## 标准写法：while (!empty) 遍历出队

优先队列没有迭代器，不能像 vector 那样 for 循环遍历。标准做法是**边取堆顶边出队**：

```cpp
while (!pq.empty()) {
    cout << pq.top() << " ";   // 取堆顶
    pq.pop();                  // 出队
}
```

> [!TIP]
> **为什么用 while 不是 for？**
>
> 因为优先队列不支持随机访问，也没有迭代器，没法按下标取元素。
> 只能一个一个从堆顶取——取一个、弹一个，直到空了为止。
> while + empty 的写法天然安全，不会在空堆上操作。

## 出队过程中 top / size 的变化

往大顶堆里塞 30、10、50、20、40，然后边出队边打印：

| 第几次 | top（堆顶） | size | 说明 |
|---|---|---|---|
| 第 1 次 | 50 | 5 | 初始，5 个元素，堆顶最大 |
| 第 2 次 | 40 | 4 | 出了 50，新堆顶是 40 |
| 第 3 次 | 30 | 3 | 继续出，堆顶越来越小 |
| 第 4 次 | 20 | 2 | size 逐次 -1 |
| 第 5 次 | 10 | 1 | 剩最后一个 |
| 出完后 | — | 0 | 空堆，empty = true |

规律很明显：
- **top 一直在变** — 每次 pop 后新的堆顶是剩余元素中优先级最高的
- **size 逐次 -1** — 出一个少一个，从 5 减到 0

## 底层实现

F12 看源码，又是熟悉的配方——直接转发给底层容器：

```cpp
bool empty() const {
    return c.empty();   // 调用底层 vector 的 empty
}

size_type size() const {
    return c.size();    // 调用底层 vector 的 size
}
```

priority_queue 自己不维护大小，全甩给底层的 vector。

```
pq.empty()  →  c.empty()  →  vector 的判空
pq.size()   →  c.size()   →  vector 的大小
```

而 vector 的 empty 本质就是判断 size 是否等于 0：

```cpp
bool empty() const {
    return size() == 0;
}
```

所以 `empty()` 和 `size() == 0` 是等价的，只是 empty 读起来更自然、更语义化。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    priority_queue<int> pq;

    // 初始状态
    cout << "empty = " << pq.empty() << endl;   // 1
    cout << "size = " << pq.size() << endl;     // 0

    // 入队 5 个元素
    pq.push(30);
    pq.push(10);
    pq.push(50);
    pq.push(20);
    pq.push(40);

    cout << "入队后:" << endl;
    cout << "empty = " << pq.empty() << endl;   // 0
    cout << "size = " << pq.size() << endl;     // 5

    // 标准遍历方式：边出队边输出
    cout << "出队过程:" << endl;
    while (!pq.empty()) {
        cout << "top=" << pq.top()
             << ", size=" << pq.size() << endl;
        pq.pop();
    }

    // 出完后
    cout << "出完后:" << endl;
    cout << "empty = " << pq.empty() << endl;   // 1
    cout << "size = " << pq.size() << endl;     // 0

    return 0;
}
```

运行结果：

```
empty = 1
size = 0
入队后:
empty = 0
size = 5
出队过程:
top=50, size=5
top=40, size=4
top=30, size=3
top=20, size=2
top=10, size=1
出完后:
empty = 1
size = 0
```

堆顶从 50 一路降到 10，size 从 5 一路减到 0，完美印证了大顶堆的出队规律。

> [!WARNING]
> **size_t 是无符号整数**
>
> size() 的返回类型是 size_t，也就是无符号整数。
> 如果你拿它和 int 比较、或者做减法，要小心溢出问题。
>
> 比如 `pq.size() - 1` 在空堆时不会变成 -1，而是一个超大的数（下溢）。
> 所以判空优先用 empty()，不要用 `size() == 0` 之外的算术运算。

## 本章小结

**两个接口** — `empty()` 判空（返回 bool），`size()` 取元素个数（返回 size_t）。

**标准遍历写法** — `while (!pq.empty()) { pq.top(); pq.pop(); }`，边出队边处理，安全又简洁。

**出队变化规律** — top 一直在变（每次都是剩余元素中优先级最高的），size 逐次 -1。

**底层是转发** — empty 和 size 都是调用底层 vector 的对应函数，priority_queue 自己不计算。

**empty 就是 size == 0** — 两者等价，但 empty 更语义化、更推荐。

**size_t 是无符号** — 注意无符号整数的下溢问题，判空用 empty() 最安全。
