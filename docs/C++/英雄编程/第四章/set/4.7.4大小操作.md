## 本节概述：set 的大小操作

set 的大小操作和其他容器完全一致——就两个接口：`empty()` 判空，`size()` 获取元素个数。非常简单。

## 两个接口

| 函数 | 返回值 | 作用 |
|---|---|---|
| `s.empty()` | `bool` | 集合为空返回 true，否则返回 false |
| `s.size()` | `size_t` | 返回集合中元素的个数 |

## 空集合的情况

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s1;   // 默认构造，空集合

    cout << "s1.empty() = " << s1.empty() << endl;   // 1（true，空）
    cout << "s1.size()  = " << s1.size()  << endl;   // 0（0 个元素）

    return 0;
}
```

运行结果：

```
s1.empty() = 1
s1.size()  = 0
```

> 空集合：`empty()` 返回 `true`（打印出来是 1），`size()` 返回 0。

## 非空集合的情况

```cpp
set<int> s2 = {1, 1, 1, 1, 6, 7, 8, 9};

cout << "s2.empty() = " << s2.empty() << endl;   // 0（false，非空）
cout << "s2.size()  = " << s2.size()  << endl;   // 5
```

运行结果：

```
s2.empty() = 0
s2.size()  = 5
```

> [!NOTE]
> **为什么 size 是 5，不是 8？**
>
> 我传了 8 个元素进去：四个 1，加上 6、7、8、9。
>
> 但 set 不允许重复元素，四个 1 实际上只保留了一个。所以最终集合里只有 **1、6、7、8、9** 五个元素，size = 5。
>
> 这又复习了一遍 set 的核心特性：**元素不重复**。

## 完整代码示例

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    // 空集合
    set<int> s1;
    cout << "s1.empty() = " << s1.empty() << endl;
    cout << "s1.size()  = " << s1.size()  << endl;

    cout << "----------------" << endl;

    // 非空集合
    set<int> s2 = {1, 1, 1, 1, 6, 7, 8, 9};
    cout << "s2.empty() = " << s2.empty() << endl;
    cout << "s2.size()  = " << s2.size()  << endl;

    return 0;
}
```

运行结果：

```
s1.empty() = 1
s1.size()  = 0
----------------
s2.empty() = 0
s2.size()  = 5
```

## 本章小结

**两个接口** — `empty()` 判空，`size()` 获取元素个数。所有 STL 容器都是这俩，高度统一。

**set 的 size 是去重后的数量** — 因为 set 不允许重复元素，所以 size 一定 ≤ 你插入的元素总数。

**这节课很简单** — 但它是后面操作的基础，插入、删除后都常用 size 来判断容器状态。
