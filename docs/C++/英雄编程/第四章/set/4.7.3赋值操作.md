## 本节概述：set 的赋值操作

set 的赋值操作主要有两种：用另一个 set 对象赋值，和用初始化列表赋值。底层都是 `operator=` 的运算符重载。

## 先准备一个初始集合

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    set<int> s = {9, 8, 5, 2, 1, 1};
    cout << "s: ";
    printSet(s);   // 1 2 5 8 9
    return 0;
}
```

> [!NOTE]
> **定义时的等号 = 构造，不是赋值**
>
> `set<int> s = {9, 8, 5, 2, 1, 1};` 这行看起来像赋值，实际上走的是**构造函数**（初始化列表构造）。
>
> 只有在对象已经创建好之后，再用等号才是真正的赋值操作。

## 方式一：对象赋值

把一个 set 完整赋值给另一个 set：

```cpp
set<int> s1;
s1 = s;              // 把 s 赋值给 s1
cout << "s1: ";
printSet(s1);        // 1 2 5 8 9
```

> 底层调用的是 `operator=(const set& other)`，先清空自己，再把对方的元素全部拷贝过来。

## 方式二：初始化列表赋值

直接用大括号给 set 赋值：

```cpp
set<int> s2;
s2 = {3, 4, 5};      // 用初始化列表赋值
cout << "s2: ";
printSet(s2);        // 3 4 5
```

> 底层调用的是 `operator=(initializer_list<T> il)`，同样是先清空，再把列表里的元素插进去。

## 为什么赋值运算符要返回值？

你有没有想过——赋值运算符的返回值为什么是 `set&` 而不是 `void`？

因为要支持**连续赋值**：

```cpp
set<int> a, b, c;
a = b = c = {1, 2, 3};   // 连续赋值
```

**执行顺序**：从右往左

1. 先执行 `c = {1, 2, 3}`，返回 `c` 的引用
2. 再执行 `b = c`（其实是 `b = c的引用`），返回 `b` 的引用
3. 最后执行 `a = b`

如果返回值是 `void`，那么第一步执行完就变成了 `void`，第二步 `b = void` 就会编译报错。

> [!TIP]
> **赋值运算符返回自身引用**
>
> 这是 C++ 面向对象的一个通用规则：赋值运算符 `operator=` 必须返回对象自身的引用（`*this`），才能支持连续赋值的语法。

## 完整代码示例

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    set<int> s = {9, 8, 5, 2, 1, 1};
    cout << "s: "; printSet(s);     // 1 2 5 8 9

    // 1. 对象赋值
    set<int> s1;
    s1 = s;
    cout << "s1: "; printSet(s1);   // 1 2 5 8 9

    // 2. 初始化列表赋值
    set<int> s2;
    s2 = {3, 4, 5};
    cout << "s2: "; printSet(s2);   // 3 4 5

    // 3. 连续赋值
    set<int> a, b, c;
    a = b = c = {1, 2, 3};
    cout << "a: "; printSet(a);     // 1 2 3
    cout << "b: "; printSet(b);     // 1 2 3
    cout << "c: "; printSet(c);     // 1 2 3

    return 0;
}
```

运行结果：

```
s: 1 2 5 8 9
s1: 1 2 5 8 9
s2: 3 4 5
a: 1 2 3
b: 1 2 3
c: 1 2 3
```

## 本章小结

**两种赋值方式** — 对象赋值（`s1 = s`）和初始化列表赋值（`s2 = {3, 4, 5}`），底层都是 `operator=` 重载。

**定义时的等号 = 构造** — 只有对象已创建后再用等号才是赋值，不要搞混。

**赋值运算符返回自身引用** — 目的是支持连续赋值（`a = b = c`），这是 C++ 的通用规则。

**赋值会先清空再拷贝** — 不管哪种赋值，都会先丢掉原来的数据，再放入新数据。
