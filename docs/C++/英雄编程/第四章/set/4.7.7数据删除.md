## 本节概述：set 的数据删除

set 的删除用 `erase` 函数，有三种常用方式：按值删除、按迭代器删除、按区间删除。底层都是红黑树的节点删除，时间复杂度 O(log n)。

## 打印函数

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}
```

## 方式一：按值删除

直接传一个值，`erase` 会找到并删掉它：

```cpp
set<int> s = {1, 2, 3, 4, 5};
s.erase(3);          // 删除值为 3 的元素
printSet(s);         // 1 2 4 5
```

> 传值删除的底层逻辑其实是：先 find 找到位置，再按迭代器删除。一步到位，方便书写。

## 方式二：按迭代器删除

传一个迭代器进去，删除迭代器指向的那个元素：

```cpp
set<int> s = {1, 2, 3, 4, 5};

set<int>::iterator it = s.find(4);   // 先找到 4 的位置
if (it != s.end()) {
    s.erase(it);                     // 按迭代器删除
}
printSet(s);         // 1 2 3 5
```

> [!TIP]
> **为什么要先 find 再 erase？**
>
> 如果你已经有一个迭代器了（比如遍历过程中想删除某个元素），直接传迭代器给 erase 比传值更高效——省掉了一次查找。
>
> 但要注意：必须保证迭代器有效（不等于 end）才能删除，否则行为未定义。

## 方式三：按区间删除

传两个迭代器，删除区间内的所有元素：

```cpp
set<int> s = {1, 2, 3, 4, 5};

set<int>::iterator itL = s.find(2);   // 左边界：指向 2
set<int>::iterator itR = s.find(4);   // 右边界：指向 4

s.erase(itL, itR);                    // 删除 [itL, itR) 区间
printSet(s);         // 1 4 5
```

等等——为什么删掉的是 **2 和 3**，而不是 2、3、4？

> [!IMPORTANT]
> **左闭右开区间**
>
> STL 的迭代器区间统一都是**左闭右开** `[first, last)`：
> - **左闭**：左边的元素（first 指向的）包含在内，会被删除
> - **右开**：右边的元素（last 指向的）不包含在内，不会被删除
>
> 所以 `erase(itL, itR)` 删除的是从 itL 开始、到 itR 之前的所有元素，itR 指向的那个元素保留。
>
> 上面的例子中，itL 指向 2，itR 指向 4，所以删除的是 2 和 3，4 还在。

## 时间复杂度

删除操作的时间复杂度是 **O(log n)**，和插入一样。

> 红黑树删除节点需要重新调整树的平衡，但整体还是对数级别。vector 中间删除要挪动元素，是 O(n)，数据量大的时候 set 的优势很明显。

## 迭代器失效

> [!WARNING]
> **删除后，指向被删元素的迭代器会失效**
>
> 如果一个迭代器指向了被删除的那个元素，删除之后这个迭代器就失效了。继续使用它是未定义行为，可能导致程序崩溃。

```cpp
set<int> s = {1, 2, 3, 4, 5};
set<int>::iterator it = s.find(2);
s.erase(it);        // 删除 it 指向的元素
// cout << *it;     // 错误！it 已经失效，不能再用了
```

> 其他没被删除的元素的迭代器仍然有效，只有指向被删元素的那个迭代器会失效。

## 三种删除方式对比

| 删除方式 | 写法 | 适用场景 |
|---|---|---|
| 按值删除 | `s.erase(val)` | 知道值，直接删，最方便 |
| 按迭代器删除 | `s.erase(it)` | 已经有迭代器了，高效 |
| 按区间删除 | `s.erase(first, last)` | 批量删除一段，左闭右开 |

## 完整代码示例

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    // 1. 按值删除
    set<int> s = {1, 2, 3, 4, 5};
    cout << "原始: "; printSet(s);
    s.erase(3);
    cout << "删3后: "; printSet(s);   // 1 2 4 5

    // 2. 按迭代器删除
    s = {1, 2, 3, 4, 5};   // 恢复
    set<int>::iterator it = s.find(4);
    if (it != s.end()) {
        s.erase(it);
    }
    cout << "删4后: "; printSet(s);   // 1 2 3 5

    // 3. 按区间删除（左闭右开）
    s = {1, 2, 3, 4, 5};   // 恢复
    set<int>::iterator itL = s.find(2);
    set<int>::iterator itR = s.find(4);
    s.erase(itL, itR);
    cout << "删[2,4): "; printSet(s);   // 1 4 5

    return 0;
}
```

运行结果：

```
原始: 1 2 3 4 5 
删3后: 1 2 4 5 
删4后: 1 2 3 5 
删[2,4): 1 4 5 
```

## 本章小结

**erase 三种方式** — 按值删除（最方便）、按迭代器删除（最高效）、按区间删除（批量删除）。

**左闭右开区间** — 所有 STL 迭代器区间都是左闭右开 `[first, last)`，右边那个元素不包含在内。

**时间复杂度 O(log n)** — 红黑树删除效率高。

**迭代器失效** — 指向被删元素的迭代器会失效，删除后不能再用。其他元素的迭代器不受影响。

**clear 清空整个集合** — 用 `s.clear()` 可以一次性清空所有元素。
