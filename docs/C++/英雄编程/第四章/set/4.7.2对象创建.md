## 本节概述：set 的对象创建

set 的对象创建和其他容器很像——默认构造、初始化列表、迭代器区间、拷贝构造，套路基本一致。但 set 有两个独特点需要格外注意：**元素自动有序**和**元素不重复**。

## 打印函数：迭代器遍历

先写一个通用的打印函数，后面所有例子都用它。

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}
```

> [!TIP]
> **const 容器要用 const_iterator**
>
> 函数参数是 `const set<int>& s`（const 引用），说明不打算修改它。
> 这时候迭代器也必须用 `const_iterator`，不能用普通的 `iterator`——否则编译器会报错。
>
> 记住规律：容器是 const 的，迭代器就用 const_iterator。

## 四种创建方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 默认构造 | `set<int> s` | 空集合 |
| 2. 初始化列表 | `set<int> s {a, b, c}` | 大括号直接给数据 |
| 3. 迭代器区间 | `set<int> s(begin, end)` | 左闭右开拷贝 |
| 4. 拷贝构造 | `set<int> s(other)` | 复制另一个 set |

## 方式一：默认构造

```cpp
set<int> s1;
cout << "s1: ";
printSet(s1);   // （空，什么都不输出）
```

> 默认构造函数创建一个**空的**集合，size = 0。这个和 vector、deque、list 都一样。

## 方式二：初始化列表

两种写法都可以：

```cpp
// 写法一：等号 + 大括号
set<int> s2_1 = {9, 8, 7, 6, 5};
cout << "s2_1: ";
printSet(s2_1);   // 5 6 7 8 9

// 写法二：直接大括号
set<int> s2_2 {9, 8, 7, 7, 6, 5};
cout << "s2_2: ";
printSet(s2_2);   // 5 6 7 8 9
```

> [!NOTE]
> **注意两个细节**
>
> 1. **自动排序**：我插入的是 9 8 7 6 5，输出却是 5 6 7 8 9。因为底层是红黑树，中序遍历天然有序。
>
> 2. **自动去重**：s2_2 里传了两个 7，但最终只有一个 7。set 不允许重复元素，重复的会被自动丢弃。
>
> 如果需要支持重复元素，请用 `multiset`。

## 方式三：迭代器区间

```cpp
set<int> s3(s2_1.begin(), s2_1.end());
cout << "s3: ";
printSet(s3);   // 5 6 7 8 9
```

> [!TIP]
> 迭代器区间是**左闭右开** `[begin, end)`：包含起点，不包含终点。
>
> 而且这里的迭代器不一定非得是 set 的迭代器——vector、list 等其他容器的迭代器也可以，只要元素类型匹配就行。

## 方式四：拷贝构造

```cpp
set<int> s4(s2_2);
cout << "s4: ";
printSet(s4);   // 5 6 7 8 9
```

> 括号里传另一个 set 对象，完整拷贝一份。
> 函数签名：`set(const set& other)`

## 完整代码示例

```cpp
#include <iostream>
#include <set>
using namespace std;

void printSet(const set<int>& s) {
    for (set<int>::const_iterator it = s.begin(); it != s.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    // 1. 默认构造
    set<int> s1;
    cout << "s1: "; printSet(s1);

    // 2. 初始化列表（两种写法）
    set<int> s2_1 = {9, 8, 7, 6, 5};
    cout << "s2_1: "; printSet(s2_1);

    set<int> s2_2 {9, 8, 7, 7, 6, 5};
    cout << "s2_2: "; printSet(s2_2);

    // 3. 迭代器区间
    set<int> s3(s2_1.begin(), s2_1.end());
    cout << "s3: "; printSet(s3);

    // 4. 拷贝构造
    set<int> s4(s2_2);
    cout << "s4: "; printSet(s4);

    return 0;
}
```

运行结果：

```
s1: 
s2_1: 5 6 7 8 9
s2_2: 5 6 7 8 9
s3: 5 6 7 8 9
s4: 5 6 7 8 9
```

## 本章小结

**四种创建方式** — 默认构造、初始化列表（等号版和括号版都行）、迭代器区间、拷贝构造。

**自动排序** — 不管你按什么顺序插入，输出一定是从小到大有序的，因为底层是红黑树。

**自动去重** — 重复元素不会被插入，set 里每个值唯一。想支持重复就用 multiset。

**打印函数用 const_iterator** — const 引用传参时，迭代器必须用 const_iterator，否则报错。

**跟其他容器很像** — STL 接口高度统一，但 set 的有序和去重是独有的，这两点一定要记住。
