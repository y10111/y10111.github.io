## 本节概述：获取栈顶元素

获取栈顶用成员函数 **`top`**。栈顶就是"最新压入、还没被弹出的那个元素"。看完这节你会发现，它的底层实现和入栈一样简单。

## 基本用法

```cpp
#include <iostream>
#include <stack>
using namespace std;

stack<int> stk;
stk.push(5);

cout << stk.top() << endl;   // 5
```

因为我们 push 了一个 5，栈里唯一的元素就是 5，所以栈顶自然就是 5。

## top 内部干了什么

老规矩，对 `top` 按 F12 看实现：

```cpp
reference top() {
    return c.back();   // 返回底层容器的最后一个元素
}
```

`c` 还是那个底层容器（默认 deque），`top` 做的就是返回 **deque 的最后一个元素**——也就是 `back()`。

```
   stk.top()
      │
      │  stack::top
      ▼
   c.back()        （c 是底层 deque）
      │
      │  deque 的尾元素
      ▼
   返回 deque 尾部那个元素
```

> [!TIP]
> **栈顶 = deque 的尾部**
>
> 上一节说入栈是往 deque 尾部 push_back，所以栈顶元素就是 deque 的最后一个元素。
> 取栈顶，自然就是取 deque 的 `back()`。

## 连续 push 后的栈顶变化

不断往栈里压元素，每次 `top` 拿到的都是最新压入的那个：

```cpp
stack<int> stk;

stk.push(5);  cout << stk.top();   // 5
stk.push(4);  cout << stk.top();   // 4
stk.push(3);  cout << stk.top();   // 3
stk.push(2);  cout << stk.top();   // 2
stk.push(1);  cout << stk.top();   // 1
```

输出：

```
54321
```

> [!NOTE]
> **叠盘子看更直观**
>
> 5 最先放进去，压在最下面；之后 4 3 2 1 依次往上叠，1 在最上面。
> `top` 永远拿最上面那个，所以依次输出 5 4 3 2 1。
>
> 注意：这里只取栈顶、没有 pop，元素都还在栈里——只是每次打印的都是"当前最上面那个"。

## 完整代码示例

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;

    stk.push(5);
    cout << stk.top() << " ";   // 5

    stk.push(4);
    cout << stk.top() << " ";   // 4

    stk.push(3);
    cout << stk.top() << " ";   // 3

    stk.push(2);
    cout << stk.top() << " ";   // 2

    stk.push(1);
    cout << stk.top() << " ";   // 1

    cout << endl;   // 输出：5 4 3 2 1

    return 0;
}
```

运行结果：

```
5 4 3 2 1
```

> [!WARNING]
> **空栈不能 top！**
>
> 栈为空时调用 `top()` 是未定义行为，会崩溃。取值前先用 `empty()` 判断一下。

## 本章小结

**接口是 top** — 用 `stk.top()` 获取栈顶元素，它返回的是栈顶元素的引用。

**底层是 back** — `top` 的实现就是 `return c.back()`，返回底层 deque 的最后一个元素。

**栈顶 = 尾部** — 入栈往尾部 push_back，所以栈顶就对应 deque 的尾部。

**叠盘子理解** — 最先压入的在最下面，`top` 永远指向最上面那一个。

**空栈不能取** — 取栈顶前先 `empty()` 检查，否则崩溃。
