## 本节概述：stack 的出栈操作

出栈（从栈顶弹掉一个元素）调用的是 **`pop`** 函数。它和 `top` 一样没有参数——因为不需要指定弹谁，永远弹最上面那一个。这节课除了 pop 本身，还会顺带学到一套**调试报错**的方法。

## 基本用法

```cpp
#include <iostream>
#include <stack>
using namespace std;

stack<int> stk;
stk.push(5);
stk.push(4);
stk.push(3);

stk.pop();   // 弹掉栈顶（3）
```

> 每次 `pop` 就相当于从最上面取掉一个盘子。

| 接口 | 有无参数 | 说明 |
|---|---|---|
| `push(x)` | 有，要放进去的元素 | 入栈 |
| `pop()` | 无 | 出栈，只弹栈顶 |

## pop 内部干了什么

`pop` 只有一个函数原型，按 F12 看实现：

```cpp
void pop() {
    c.pop_back();   // 弹掉底层容器的最后一个元素
}
```

又是老熟人——调用了底层 deque 的 **`pop_back`**。

> [!TIP]
> **为什么是 pop_back？**
>
> 因为 `top` 拿到的是 deque 的 `back`（尾部元素），那弹掉栈顶自然就是 `pop_back`。
> 入栈是 push_back，出栈是 pop_back，一进一出正好对称。

## 出栈后栈顶的变化

接着上一节的 5 4 3 2 1（1 在栈顶），pop 一次：

```
出栈前：  [ 5 | 4 | 3 | 2 | 1 ]   ← top = 1
pop() 后： [ 5 | 4 | 3 | 2 ]      ← top = 2
```

弹掉了 1，栈顶变成 2，再 `top` 打印出来就是 2。

## 空栈 pop / top 会报错

一直 pop 直到栈空，如果这时再取 `top`，程序就会报错：

```
Debug Assertion Failed!
Expression: back called on empty deque
```

> [!WARNING]
> **看到这个报错别慌**
>
> 报错信息里写着 `empty`——明确告诉你：**空的 deque 不能调用 back**。
> 因为空容器没有"最后一个元素"，back 毫无意义，所以库直接断言拦下来了。
>
> 也就是说：**空栈不能 pop，也不能 top**。操作前一定先用 `empty()` 判断。

## 借报错学调试：断言与调用堆栈

遇到这种报错，与其猜，不如直接调试定位。

**第一步，点"调试" → "重试"**，程序会停在出错的地方，这时能通过**调用堆栈**看到是怎么一路调进来的：

```
main
 └── stack<int>::top
      └── deque<int>::back   ← 在这里断言失败
```

**第二步，看断言**——出错处有一句判断：

```
如果是非 empty（非空）→ 满足条件，什么都不做
否则（为空）→ 弹出报错框
```

非空才是正常情况，一旦容器为空、条件不满足，就会弹出那个报错框。

> [!NOTE]
> 再往下 F12 追，就会进到看不到实现的库里代码（只剩函数声明），到这就可以停了——我们已经知道出错点是"对空 deque 调 back"。
>
> 这套"调试 → 重试 → 看调用堆栈 → 看断言"的方法，平时项目里排查类似问题同样适用。

## 完整代码示例

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;
    stk.push(5);
    stk.push(4);
    stk.push(3);
    stk.push(2);
    stk.push(1);

    // 依次出栈并打印栈顶
    while (!stk.empty()) {
        cout << stk.top() << " ";
        stk.pop();
    }
    cout << endl;   // 输出：1 2 3 4 5

    return 0;
}
```

运行结果：

```
1 2 3 4 5
```

> 用 `while (!stk.empty())` 配合 `top + pop`，就是遍历栈的标准写法——边取栈顶边弹出，取完正好栈空。

## 本章小结

**接口是 pop** — `stk.pop()` 弹出栈顶元素，没有参数。

**底层是 pop_back** — 实现只有一行 `c.pop_back()`，弹掉底层 deque 的最后一个元素，和 top（back）正好对称。

**空栈不能弹** — 空栈调用 pop / top 会触发断言报错 `back called on empty deque`，操作前先 `empty()` 判断。

**报错要会看** — 断言信息里的 `empty` 就是在告诉你"容器空了不能取尾元素"。

**顺带学了调试** — 点调试 → 重试 → 看调用堆栈，就能定位是哪个函数、在哪一步出的错。
