## 本节概述：stack 的大小操作

stack 的大小操作有两个接口：**`empty`** 和 **`size`**。前者用来判空，后者用来获取栈里有多少元素。这俩函数非常简单，但几乎每一次用栈都离不开它们——尤其是 `empty`，用来保护空栈时的安全操作。

## 两个接口总览

| 接口 | 返回值 | 作用 |
|---|---|---|
| `stk.empty()` | `bool`（true/false） | 栈是否为空 |
| `stk.size()` | `size_t`（无符号整数） | 栈中元素个数 |

> [!TIP]
> **1 和 0 的含义**
>
> 打印出来 `empty` 的结果：
> - `1` → true → 空
> - `0` → false → 非空
>
> 不要看反了——`empty() == 1` 才是空的。

## 入栈过程中 empty / size 的变化

我们用循环往栈里压 0~4 共 5 个元素，每次压之前打印 `empty` 和 `size`：

```cpp
stack<int> stk;
for (int i = 0; i < 5; i++) {
    cout << stk.empty() << "," << stk.size() << endl;
    stk.push(i);
}
```

运行过程：

| 第几次循环 | empty | size | 说明 |
|---|---|---|---|
| 第 1 次 | 1 | 0 | 刚开始栈是空的 |
| 第 2 次 | 0 | 1 | 压了 0 后，非空，size = 1 |
| 第 3 次 | 0 | 2 | size = 2 |
| 第 4 次 | 0 | 3 | size = 3 |
| 第 5 次 | 0 | 4 | size = 4 |

> 注意：因为打印在 `push` 之前，所以循环 5 次里最后一次打印 size 是 4，不是 5。
> 循环结束后栈里实际上有 5 个元素（0 1 2 3 4）。

## 出栈过程中 empty / size 的变化

栈里有 5 个元素后，再循环 5 次每次 pop 一下，pop 完打印：

```cpp
for (int i = 0; i < 5; i++) {
    stk.pop();
    cout << stk.empty() << "," << stk.size() << endl;
}
```

运行过程：

| 第几次 pop | empty | size | 说明 |
|---|---|---|---|
| 第 1 次 | 0 | 4 | 弹掉一个，剩 4 个 |
| 第 2 次 | 0 | 3 | 剩 3 个 |
| 第 3 次 | 0 | 2 | 剩 2 个 |
| 第 4 次 | 0 | 1 | 剩 1 个 |
| 第 5 次 | 1 | 0 | 弹完了，空了 |

> 最后一次 pop 完，size 变成 0，empty 变成 1——栈空了。

## 底层实现

本着探索精神，F12 看一眼源码：

```cpp
bool empty() const {
    return c.empty();   // 调用底层容器的 empty
}

size_type size() const {
    return c.size();    // 调用底层容器的 size
}
```

又是老配方——`c` 就是底层的 deque，直接把活儿甩给它。

```
stk.empty()   →   c.empty()   →  deque 的判空
stk.size()    →   c.size()    →  deque 的大小
```

> stack 的所有接口几乎都是对底层容器的"转发"，这也印证了适配器的设计思想。

## 完整代码示例

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;

    cout << "=== 入栈过程 ===" << endl;
    for (int i = 0; i < 5; i++) {
        cout << "empty=" << stk.empty()
             << ", size=" << stk.size() << endl;
        stk.push(i);
    }
    // 循环结束后栈里有 5 个元素：0 1 2 3 4

    cout << "=== 出栈过程 ===" << endl;
    for (int i = 0; i < 5; i++) {
        stk.pop();
        cout << "empty=" << stk.empty()
             << ", size=" << stk.size() << endl;
    }

    return 0;
}
```

运行结果：

```
=== 入栈过程 ===
empty=1, size=0
empty=0, size=1
empty=0, size=2
empty=0, size=3
empty=0, size=4
=== 出栈过程 ===
empty=0, size=4
empty=0, size=3
empty=0, size=2
empty=0, size=1
empty=1, size=0
```

> [!WARNING]
> **empty 是保护神**
>
> 前几节反复强调——空栈不能 top，也不能 pop。
> 所以每次操作栈顶前，养成用 `if (!stk.empty())` 或 `while (!stk.empty())` 做保护的习惯。

## 本章小结

**两个接口** — `empty()` 判空（返回 bool），`size()` 取元素个数（返回 size_t）。

**入栈看变化** — empty 从 1 变 0 就一直是 0，size 从 0 开始逐次 +1。

**出栈看变化** — size 逐次 -1，直到变 0 时 empty 才变成 1。

**底层是转发** — 两个函数都是直接调用底层 deque 的 empty / size，stack 本身不做任何计算。

**empty 是保护神** — 操作栈顶前一定要用 empty 判空，防止崩溃。
