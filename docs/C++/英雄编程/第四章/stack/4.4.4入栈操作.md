## 本节概述：stack 的入栈操作

入栈（往栈里放元素）只有一个接口——**`push`**。用起来就一行代码，但它的底层实现非常值得一看：理解了它，你就能把 stack 和 deque 彻底串起来。

## 基本用法

```cpp
#include <stack>
using namespace std;

stack<int> stk;

stk.push(5);   // 入栈 5
stk.push(4);   // 入栈 4
stk.push(3);   // 入栈 3
```

> 这次记得先写 `#include <stack>`，就不会再报"未定义的标识符"了。

## push 内部干了什么

我们知道 stack 的底层默认是 deque，那 `push` 到底做了什么？看一眼源码就清楚了。

对 `push` 按 F12 跳进定义，会看到它的实现极短：

```cpp
void push(const value_type& value) {
    c.push_back(value);   // c 就是底层容器 deque
}
```

**就这一行**——`c` 就是 stack 里那个容器成员（默认 deque），`push` 做的事情就是调用 deque 的 `push_back`。

```
   stk.push(5)
      │
      │  stack::push
      ▼
   c.push_back(5)        （c 是底层 deque）
      │
      │  deque 的尾插
      ▼
   在 deque 尾部插入元素 5
```

> [!TIP]
> **为什么不用纠结"两个断点"？**
>
> 调试时可能会看到多个重载版本，打断点运行一下就知道真正走到哪个——最终都会落到 `c.push_back` 这一句上。
> 只要理解了 deque 的 `push_back`，stack 的 push 就自然懂了。

## 换个角度理解：从 deque 看入栈

其实完全不用从"栈"的角度去想，**直接从 deque 的角度看**反而更直观。

连续 push 的过程，就是往 deque 尾部不断追加元素：

```
push(5)   →  [ 5 ]
push(4)   →  [ 5 | 4 ]
push(3)   →  [ 5 | 4 | 3 ]
                     ↑
                  尾部（栈顶）
```

| 视角 | 理解方式 |
|---|---|
| 从栈的角度 | 元素一个一个往栈顶压 |
| 从 deque 的角度 | 元素一个一个往尾部插（push_back） |

两种说法是同一件事，只是叫法不同。

> [!NOTE]
> **栈顶在哪一端？**
>
> 栈顶就是 deque 的**尾部**。push 一次，栈顶就往右移动一格，指向最新压入的元素。

## 完整代码示例

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> stk;

    stk.push(5);
    stk.push(4);
    stk.push(3);

    // 此时栈顶是最新压入的 3
    cout << "top = " << stk.top() << endl;    // 3
    cout << "size = " << stk.size() << endl;  // 3

    return 0;
}
```

运行结果：

```
top = 3
size = 3
```

## 本章小结

**只有一个接口** — 入栈就是 `push`，传入要插入的值。

**底层是 push_back** — `push` 的实现只有一行：`c.push_back(value)`，`c` 就是底层容器 deque。

**本质是尾插** — 入栈在底层就是 deque 的尾插，栈顶对应 deque 的尾部。

**换个角度更清楚** — 不必从"栈"的角度硬想，直接当成 deque 不断尾插就好理解了。

**懂了 deque 就懂了 stack** — stack 的 push 没有任何额外逻辑，全靠底层容器。
