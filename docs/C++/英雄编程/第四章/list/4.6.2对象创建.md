## 本节概述：list 的对象创建

list 的对象创建和 vector、deque 非常像——常见的也是 6 种方式。学过前面的容器，这节课基本就是复习，换个类名而已。

## 打印函数：迭代器遍历

先写一个通用的打印函数，后面所有例子都用它。list 有迭代器，可以像 vector 那样用 begin / end 遍历：

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}
```

> [!TIP]
> **const 容器要用 const_iterator**
>
> 函数参数是 `const list<int>& L`（const 引用），说明不打算修改它。
> 这时候迭代器也必须用 `const_iterator`，不能用普通的 `iterator`——否则编译器会报错。
>
> 记住规律：容器是 const 的，迭代器就用 const_iterator。

## 六种创建方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 默认构造 | `list<int> L` | 空链表 |
| 2. 初始化列表 | `list<int> L {a, b, c}` | 大括号直接给数据 |
| 3. 迭代器区间 | `list<int> L(begin, end)` | 左闭右开拷贝 |
| 4. count 个默认值 | `list<int> L(n)` | n 个 0 |
| 5. count 个指定值 | `list<int> L(n, val)` | n 个 val |
| 6. 拷贝构造 | `list<int> L(other)` | 复制另一个 list |

> 跟 vector、deque 几乎一模一样。STL 的接口设计很统一，学会一个就能举一反三。

## 方式一：默认构造

```cpp
list<int> L1;
printList(L1);   // （空，什么都不输出）
```

> 默认构造函数创建一个**空的**链表，size = 0。

## 方式二：初始化列表

两种写法都可以：

```cpp
// 写法一：大括号直接初始化
list<int> L2_1 {9, 8, 7, 6, 5};
printList(L2_1);   // 9 8 7 6 5

// 写法二：等号 + 大括号（隐式构造）
list<int> L2_2 = {9, 8, 7, 1, 5};
printList(L2_2);   // 9 8 7 1 5
```

> [!NOTE]
> **等号写法是赋值还是初始化？**
>
> 是**初始化**！调用的是构造函数，不是 `operator=`。
> 定义时的等号 = 构造，定义之后再用等号 = 赋值。
> 这个知识点在 vector、deque 里都讲过，list 也一样。

## 方式三：迭代器区间

```cpp
list<int> L3(L2_1.begin(), L2_1.end());
printList(L3);   // 9 8 7 6 5（全部拷贝）
```

也可以只拷贝一部分（不过 list 的迭代器只能 ++/--，不能 +n，要挪位置得一步一步走）。

> [!TIP]
> 迭代器区间是**左闭右开** `[begin, end)`：包含起点，不包含终点。

## 方式四：count 个默认值

```cpp
list<int> L4(8);
printList(L4);   // 0 0 0 0 0 0 0 0
```

> 传入一个数字 n，创建**长度为 n** 的链表，所有元素初始化为 0（默认值）。

## 方式五：count 个指定值

```cpp
list<int> L5(8, 6);
printList(L5);   // 6 6 6 6 6 6 6 6
```

> 两个参数：
> - 第一个 = 元素个数（8 个）
> - 第二个 = 每个元素的值（6）

## 方式六：拷贝构造

```cpp
list<int> L6(L2_2);
printList(L6);   // 9 8 7 1 5（跟 L2_2 一模一样）
```

> 括号里传另一个 list 对象，完整拷贝一份。
> 函数签名：`list(const list& other)`

## 完整代码示例

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    // 1. 默认构造
    list<int> L1;
    cout << "L1: "; printList(L1);

    // 2. 初始化列表（两种写法）
    list<int> L2_1 {9, 8, 7, 6, 5};
    cout << "L2_1: "; printList(L2_1);

    list<int> L2_2 = {9, 8, 7, 1, 5};
    cout << "L2_2: "; printList(L2_2);

    // 3. 迭代器区间
    list<int> L3(L2_1.begin(), L2_1.end());
    cout << "L3: "; printList(L3);

    // 4. count 个默认值
    list<int> L4(8);
    cout << "L4: "; printList(L4);

    // 5. count 个指定值
    list<int> L5(8, 6);
    cout << "L5: "; printList(L5);

    // 6. 拷贝构造
    list<int> L6(L2_2);
    cout << "L6: "; printList(L6);

    return 0;
}
```

运行结果：

```
L1: 
L2_1: 9 8 7 6 5
L2_2: 9 8 7 1 5
L3: 9 8 7 6 5
L4: 0 0 0 0 0 0 0 0
L5: 6 6 6 6 6 6 6 6
L6: 9 8 7 1 5
```

## 本章小结

**六种创建方式** — 默认构造、初始化列表（括号版和等号版都行）、迭代器区间、count 个 0、count 个指定值、拷贝构造。

**跟 vector / deque 几乎一样** — STL 接口高度统一，学会一个就能类推。

**打印函数用 const_iterator** — const 引用传参时，迭代器必须用 const_iterator，否则报错。

**最常用的是默认构造** — 先建空的，后面慢慢 push。

**list 的构造函数有 15 个重载** — 但常用的就这 6 个，不用全记，掌握核心的就行。
