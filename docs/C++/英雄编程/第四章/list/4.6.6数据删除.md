## 本节概述：list 的数据删除

list 的删除有四类接口：**头删 pop_front**、**尾删 pop_back**、**中间删 erase**、**清空 clear**。头删尾删很简单，erase 有两种重载，稍微复杂一点。

## 删除接口总览

| 接口 | 作用 | 时间复杂度 |
|---|---|---|
| `pop_front()` | 删除头部元素 | O(1) |
| `pop_back()` | 删除尾部元素 | O(1) |
| `erase(pos)` | 删除迭代器 pos 指向的元素，返回下一个元素的迭代器 | O(1) |
| `erase(first, last)` | 删除 `[first, last)` 区间的元素，返回 last | O(n) |
| `clear()` | 清空所有元素 | O(n) |

> list 的优势就是：**找到位置之后，删除只需要 O(1)**——改一改指针就行，不用移动元素。

## 头删：pop_front

删掉链表最前面的元素：

```cpp
list<int> L = {-1, 9, 8, 5, 2, 1, 1, -1};

L.pop_front();   // 删掉最前面的 -1
// 结果：9 8 5 2 1 1 -1
```

头删之后，原来的第二个元素变成新的头。

## 尾删：pop_back

删掉链表最后面的元素：

```cpp
L.pop_back();    // 删掉最后面的 -1
// 结果：9 8 5 2 1 1
```

尾删之后，原来的倒数第二个元素变成新的尾。

> 头删 + 尾删之后，链表就只剩中间的 `9 8 5 2 1 1` 了。

## 中间删：erase 的两种重载

erase 是删除指定位置的元素，位置用**迭代器**指定。它有两种重载。

### 重载一：删单个元素

传一个迭代器，删掉它指向的元素，**返回下一个元素的迭代器**：

```cpp
list<int> L = {9, 8, 5, 2, 1, 1};

list<int>::iterator it = L.erase(L.begin());
// 删掉了 9，it 现在指向 8
cout << *it << endl;   // 8
// 结果：8 5 2 1 1
```

> [!TIP]
> **erase 的返回值很重要**
>
> 元素被删掉之后，指向它的迭代器就失效了（变成野指针）。
> 所以 erase 会**返回被删元素的下一个元素的迭代器**，让你知道"删完之后现在在哪"。
>
> 比如删掉 begin 指向的 9，返回的迭代器就指向 8（原来的第二个元素）。

可以连续删：

```cpp
it = L.erase(it);   // 再删 8，it 现在指向 5
// 结果：5 2 1 1
```

每 erase 一次，迭代器就往后走一格。

### 重载二：删一段区间

传两个迭代器（起点和终点），删掉左闭右开区间 `[first, last)` 内的所有元素：

```cpp
list<int>::iterator it = L.begin();
++it; ++it;   // 走到第三个元素（1）的位置

L.erase(it, L.end());   // 从 it 到末尾全部删掉
// 结果：5 2
```

> 删掉了 `[it, end)` 这一段——也就是从第三个元素开始，一直到最后。
> 剩下的就是前两个元素 5 和 2。

## 清空：clear

把整个链表的元素全部删掉：

```cpp
L.clear();
cout << L.size() << endl;   // 0
cout << L.empty() << endl;  // 1（空了）
```

> clear 之后，链表变成空的，size = 0，empty = true。

## 完整代码示例

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << "  (size=" << L.size() << ")";
    cout << endl;
}

int main() {
    list<int> L = {-1, 9, 8, 5, 2, 1, 1, -1};
    cout << "初始：     "; printList(L);

    // 尾删
    L.pop_back();
    cout << "pop_back："; printList(L);

    // 头删
    L.pop_front();
    cout << "pop_front："; printList(L);

    // erase 单个
    list<int>::iterator it = L.erase(L.begin());
    cout << "erase(9)： "; printList(L);
    cout << "返回的it指向：" << *it << endl;   // 8

    it = L.erase(it);
    cout << "erase(8)： "; printList(L);
    cout << "返回的it指向：" << *it << endl;   // 5

    // erase 区间
    ++it; ++it;   // 往后走两格
    L.erase(it, L.end());
    cout << "erase区间："; printList(L);

    // 清空
    L.clear();
    cout << "clear：    "; printList(L);

    return 0;
}
```

运行结果：

```
初始：     -1 9 8 5 2 1 1 -1   (size=8)
pop_back：-1 9 8 5 2 1 1       (size=7)
pop_front：9 8 5 2 1 1         (size=6)
erase(9)： 8 5 2 1 1           (size=5)
返回的it指向：8
erase(8)： 5 2 1 1             (size=4)
返回的it指向：5
erase区间：5 2                 (size=2)
clear：                         (size=0)
```

## 本章小结

**四类删除** — 头删 pop_front、尾删 pop_back、中间删 erase、清空 clear。

**头删尾删都是 O(1)** — 双向链表，两端删都很快，直接改指针。

**erase 两种重载**：
1. `erase(pos)` — 删单个元素，返回下一个元素的迭代器
2. `erase(first, last)` — 删一段区间（左闭右开），返回 last

**erase 返回值很重要** — 被删元素的迭代器会失效，返回值告诉你下一个有效位置在哪。

**erase 返回值用来连续删** — 每次 erase 完用返回值更新迭代器，就能继续往下删。

**clear 全部删完** — 清空整个链表，size 变成 0。
