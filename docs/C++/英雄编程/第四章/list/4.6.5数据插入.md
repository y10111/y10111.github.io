## 本节概述：list 的数据插入

list 的插入有三类接口：**头插 push_front**、**尾插 push_back**、**中间插 insert**。头插尾插很简单，insert 有三种重载，稍微复杂一点。

## 插入接口总览

| 接口 | 作用 | 时间复杂度 |
|---|---|---|
| `push_front(x)` | 头部插入一个元素 | O(1) |
| `push_back(x)` | 尾部插入一个元素 | O(1) |
| `insert(pos, x)` | 在迭代器 pos 位置插入一个元素 | O(1)（找到位置之后） |
| `insert(pos, n, x)` | 在迭代器 pos 位置插入 n 个 x | O(n) |
| `insert(pos, first, last)` | 在迭代器 pos 位置插入一段区间 | O(n) |

> list 的最大优势就是：**找到位置之后，插入只需要 O(1)**——改一改指针就行，不用移动元素。

## 头插：push_front

往链表最前面加元素：

```cpp
list<int> L;

L.push_front(-1);   // -1
L.push_front(-2);   // -2 -1
L.push_front(-3);   // -3 -2 -1
```

每次头插，新元素都变成新的头节点，原来的头往后挪。

```
插 -3 前：  -2 -1
插 -3 后：  -3 -2 -1
            ↑
          新头
```

## 尾插：push_back

往链表最后面加元素：

```cpp
L.push_back(1);   // -3 -2 -1 1
L.push_back(2);   // -3 -2 -1 1 2
L.push_back(3);   // -3 -2 -1 1 2 3
```

每次尾插，新元素接到尾巴上，变成新的尾节点。

```
插 3 前：  -3 -2 -1 1 2
插 3 后：  -3 -2 -1 1 2 3
                            ↑
                          新尾
```

> 头插 + 尾插之后，链表变成了 `-3 -2 -1 1 2 3`，两边对称。

## 中间插：insert 的三种重载

insert 是在指定位置插入元素，位置用**迭代器**指定。它有三种重载。

### 前置知识：list 迭代器只能 ++ 不能 +n

```cpp
list<int>::iterator it = L.begin();
++it;    // ✅ 可以，往前走一格
it++;    // ✅ 也可以
it = it + 1;  // ❌ 编译报错！为什么？
```

> [!WARNING]
> **为什么 list 迭代器不支持 +n？**
>
> 因为 list 是链表，节点在内存里不是连续的，**不支持随机访问**。
>
> 如果允许 `it + 7`，那内部就得一步一步走 7 次 `++`，时间复杂度 O(n)。
> 为了防止你无意中写出低效代码，STL 干脆**不提供这个运算符**——让你只能用 `++`，清楚地知道"我在一格一格走"。
>
> 想走 n 格？自己写 for 循环 `++` n 次，但你会清楚地意识到"这是 O(n) 的"。

### 重载一：迭代器 + 值

在指定位置插入**一个**元素：

```cpp
list<int> L = {-3, -2, -1, 1, 2, 3};

list<int>::iterator it = L.begin();
++it; ++it; ++it;   // 走到第 4 个元素（1）的位置

L.insert(it, 0);    // 在 it 前面插入 0
// 结果：-3 -2 -1 0 1 2 3
```

insert 是在迭代器指向的元素**前面**插入。

```
插入前：  -3 -2 -1 [1] 2 3
                    ↑
                   it
插入 0： -3 -2 -1 0 [1] 2 3
                  ↑
              新元素在 it 前面
```

### 重载二：迭代器 + 数量 + 值

在指定位置插入 **n 个相同的**元素：

```cpp
list<int>::iterator it = L.end();
--it;   // 从 end 往前退一格，指向最后一个元素（3）

L.insert(it, 5, 8);   // 在 it 前面插 5 个 8
// 结果：-3 -2 -1 0 1 2 8 8 8 8 8 3
```

> 这里用了 `--it`，list 的迭代器双向都能走（`++` 和 `--` 都支持），就是不能跳着走。

### 重载三：迭代器 + 区间

在指定位置插入**另一段区间**的数据：

```cpp
list<int>::iterator it = L.begin();
++it;   // 走到 -2 的位置

L.insert(it, L.begin(), L.end());   // 在 it 前面插入整个 L 自己
```

> 这相当于把链表自己复制一份，插在第二个元素前面。
> 插入后链表长度翻倍。

## 完整代码示例

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    list<int> L;

    // 头插
    L.push_front(-1);
    L.push_front(-2);
    L.push_front(-3);
    cout << "头插后：   "; printList(L);   // -3 -2 -1

    // 尾插
    L.push_back(1);
    L.push_back(2);
    L.push_back(3);
    cout << "尾插后：   "; printList(L);   // -3 -2 -1 1 2 3

    // insert 单个元素
    list<int>::iterator it = L.begin();
    ++it; ++it; ++it;     // 走到第 4 个位置
    L.insert(it, 0);      // 插入 0
    cout << "insert 0： "; printList(L);   // -3 -2 -1 0 1 2 3

    // insert n 个相同值
    it = L.end();
    --it;                  // 指向最后一个元素
    L.insert(it, 5, 8);    // 插 5 个 8
    cout << "insert 5个8："; printList(L);

    // insert 区间
    it = L.begin();
    ++it;                  // 走到第二个位置
    L.insert(it, L.begin(), L.end());  // 把整个链表插进去
    cout << "insert区间： "; printList(L);

    return 0;
}
```

运行结果：

```
头插后：   -3 -2 -1
尾插后：   -3 -2 -1 1 2 3
insert 0： -3 -2 -1 0 1 2 3
insert 5个8：-3 -2 -1 0 1 2 8 8 8 8 8 3
insert区间： -3 -3 -2 -1 0 1 2 8 8 8 8 8 3 -2 -1 0 1 2 8 8 8 8 8 3
```

## 本章小结

**三类插入** — 头插 push_front、尾插 push_back、中间插 insert。

**头插尾插都是 O(1)** — list 双向链表，两端插都很快，直接改指针。

**迭代器只能 ++ 不能 +n** — 链表不支持随机访问，STL 故意不提供 `+` 运算符，防止低效代码。可以用 for 循环 `++` 来走，但你要知道这是 O(n) 的。

**insert 三种重载**：
1. `insert(pos, val)` — 在 pos 前面插一个元素
2. `insert(pos, n, val)` — 在 pos 前面插 n 个相同元素
3. `insert(pos, first, last)` — 在 pos 前面插一段区间

**insert 在迭代器前面插** — 新元素插在 pos 指向的元素之前，pos 本身的位置（元素）不变。
