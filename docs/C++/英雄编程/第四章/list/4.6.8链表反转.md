## 本节概述：链表反转

力扣上有一道经典题叫"反转链表"——那是单向链表的反转。list 底层是**双向循环链表**，反转反而更简单。这节课我们先理解原理，再看看 STL 是怎么实现的。

## 双向链表反转比单向更简单

| 链表类型 | 反转难度 |
|---|---|
| 单向链表 | ⭐⭐⭐ 要保存 prev / next 指针 |
| 双向链表 | ⭐ 每个节点交换 prev 和 next 就行 |
| 双向循环链表 | ⭐ 更简单，连边界条件都不用考虑 |

> 多了一个方向，反转反而更简单了——因为每个节点同时知道前后是谁，交换一下指针就完事。

## 反转原理：每个节点交换 prev 和 next

对于双向循环链表，反转思路非常朴素：

**遍历每个节点，把它的 prev 和 next 指针交换一下。**

```
反转前：  ... ← 节点2 → ...
          prev    next

反转后：  ... → 节点2 ← ...
          next    prev
```

就这么简单。原本 prev 指向的节点，现在变成 next 指向的；原本 next 指向的，现在变成 prev 指向的。前后反过来了。

每个节点都这么干一遍，整条链表自然就反转了。

```
原始链表： head → 1 → 2 → 3 → head
          head ← 1 ← 2 ← 3 ← head

每个节点交换 prev/next 后：
          head → 3 → 2 → 1 → head
          head ← 3 ← 2 ← 1 ← head
```

原本是 1 → 2 → 3，反转后变成 3 → 2 → 1。

> 虚拟头节点 head 也跟着一起交换，所以整个结构依然是循环的，不需要额外处理边界。

## 直接用：reverse 成员函数

理论归理论，实际开发根本不用自己写——list 自带 `reverse()` 成员函数：

```cpp
#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> L = {1, 2, 3};

    cout << "反转前：";
    for (int x : L) cout << x << " ";   // 1 2 3
    cout << endl;

    L.reverse();   // 反转

    cout << "反转后：";
    for (int x : L) cout << x << " ";   // 3 2 1
    cout << endl;

    return 0;
}
```

运行结果：

```
反转前：1 2 3
反转后：3 2 1
```

> 一行代码搞定，根本不用自己手撕反转。

## 源码长什么样

按 F12 跳进 `reverse()` 的源码，会发现实现非常短，核心逻辑就是：

1. 从头节点开始遍历
2. 对每个节点，交换它的 `prev` 和 `next` 指针
3. 直到再次回到头节点（循环结束）

```
pNode = head
while pNode != head（循环回到起点就停）:
    交换 pNode 的 prev 和 next
    pNode = pNode->prev   （因为 prev/next 已经交换了，所以走 prev 等于往前走）
```

> [!TIP]
> **为什么用 prev 走？**
>
> 因为当前节点的 prev 和 next 已经交换了，原来的 "下一个节点" 现在在 prev 方向上。
> 所以遍历下一个节点时，要走 `pNode->prev`——相当于沿着原来的 next 方向继续走。
>
> 这是个容易绕晕的地方，不用死记——知道"每个节点交换 prev/next"就够了。

## 为什么需要临时变量

交换 prev 和 next 不能直接这么写：

```cpp
// ❌ 错的！
pNode->prev = pNode->next;
pNode->next = pNode->prev;   // 这时候 prev 已经被改成 next 了，等于没交换
```

第一行把 prev 改成了 next，第二行再把 next 改成 prev——但这时候 prev 已经是原来的 next 了，相当于 next 赋值给自己，**根本没交换成功**。

所以正确的做法是**先把其中一个存到临时变量里**：

```cpp
// ✅ 对的
tmp = pNode->prev;
pNode->prev = pNode->next;
pNode->next = tmp;
```

> 这跟"交换两个整数需要第三个变量"是一个道理，经典的 swap 三件套。

## 本章小结

**双向链表反转更简单** — 每个节点交换 prev 和 next 指针就行，比单向链表反转简单。

**循环链表更简单** — 连边界条件都不用考虑，从头节点出发遍历一圈、回到头节点就停。

**不用自己写** — list 自带 `reverse()` 成员函数，直接调用就行。

**核心就是交换 prev/next** — 每个节点把前后指针互换，整条链表自然就反转了。

**交换要存临时变量** — 不然第一个值被覆盖了，第二个就没法正确赋值，等于没交换。

**F12 看源码更清楚** — 源码很短，自己跳进去读一遍理解更深刻。
