## 本节概述：list 的赋值操作

list 的赋值操作有四种方式：等号赋值、assign 迭代器区间、assign 初始化列表、assign n 个指定值。跟 vector、deque 的赋值几乎一模一样，学过前面的，这里就是换个类名的事。

## 四种赋值方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 等号赋值 | `L1 = L2` | 把 L2 完整复制给 L1 |
| 2. assign 迭代器区间 | `L.assign(begin, end)` | 用区间数据覆盖原数据 |
| 3. assign 初始化列表 | `L.assign({a, b, c})` | 用列表数据覆盖原数据 |
| 4. assign n 个值 | `L.assign(n, val)` | 用 n 个 val 覆盖原数据 |

> 赋值 = 先清空旧数据，再写入新数据。不管原来有多少元素，赋值完之后就变成新的样子。

## 方式一：等号赋值

最简单的一种，一个等号搞定：

```cpp
list<int> L = {9, 8, 5, 2, 1, 1};

list<int> L1;
L1 = L;   // 把 L 的数据完整复制给 L1
```

> 注意：这里 `L1 = L` 才是真正的赋值。
> 上面的 `list<int> L = {9,8,5,2,1,1}` 看起来像赋值，其实是**初始化**——走的是构造函数，不是 `operator=`。

## 方式二：assign 迭代器区间

用另一个容器的一段数据来赋值：

```cpp
list<int> L2;
L2.assign(L1.begin(), L1.end());   // 把 L1 的所有数据复制给 L2
```

> 这驾轻就熟的写法，vector、deque 里都用过，list 也是一样的配方。
> 迭代器区间还是左闭右开 `[begin, end)`。

## 方式三：assign 初始化列表

直接传一个大括号列表进去：

```cpp
list<int> L3;
L3.assign({1, 3, 1, 4});   // 用 1 3 1 4 覆盖原数据
```

> 赋值完之后，L3 里就只有 1、3、1、4 这四个元素了——之前的旧数据全部被清掉。

## 方式四：assign n 个值

用 n 个相同的值来赋值：

```cpp
list<int> L4;
L4.assign(8, 6);   // 8 个 6
```

> 两个参数：第一个是数量（8 个），第二个是每个元素的值（6）。
> 打括号的一瞬间，IDE 的函数提示就会告诉你参数含义——`count` 和 `value`，很清晰。

## 完整代码示例

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << endl;
}

int main() {
    list<int> L = {9, 8, 5, 2, 1, 1};
    cout << "L:   "; printList(L);

    // 1. 等号赋值
    list<int> L1;
    L1 = L;
    cout << "L1:  "; printList(L1);

    // 2. assign 迭代器区间
    list<int> L2;
    L2.assign(L1.begin(), L1.end());
    cout << "L2:  "; printList(L2);

    // 3. assign 初始化列表
    list<int> L3;
    L3.assign({1, 3, 1, 4});
    cout << "L3:  "; printList(L3);

    // 4. assign n 个值
    list<int> L4;
    L4.assign(8, 6);
    cout << "L4:  "; printList(L4);

    return 0;
}
```

运行结果：

```
L:   9 8 5 2 1 1
L1:  9 8 5 2 1 1
L2:  9 8 5 2 1 1
L3:  1 3 1 4
L4:  6 6 6 6 6 6 6 6
```

## 本章小结

**四种赋值方式** — 等号赋值、assign 迭代器区间、assign 初始化列表、assign n 个值。

**赋值 = 清空旧的 + 写入新的** — 不管原来有多少元素，赋值后完全变成新数据。

**跟 vector / deque 几乎一样** — STL 接口高度统一，都是这四种赋值方式。

**等号最常用** — 简单直接，日常开发基本够用。assign 适合需要灵活赋值的场景。

**初始化 ≠ 赋值** — 定义时的等号走构造函数，对象已存在时的等号才走赋值运算符。
