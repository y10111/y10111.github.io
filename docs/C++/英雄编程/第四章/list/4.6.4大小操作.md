## 本节概述：list 的大小操作

list 的大小操作有三个接口：**`empty`**、**`size`**、**`resize`**。前两个判空和取个数，第三个用来改变链表大小——既可扩大也可缩小。

## 三个接口总览

| 接口 | 作用 | 说明 |
|---|---|---|
| `L.empty()` | 判空 | 空返回 true(1)，非空返回 false(0) |
| `L.size()` | 取元素个数 | 返回链表中当前有多少个节点 |
| `L.resize(n)` | 改变大小到 n | 多出的位置补 0，多出的元素删掉 |
| `L.resize(n, val)` | 改变大小到 n，新元素用 val | 多出的位置补 val |

## empty 和 size

先建一个空链表，看看初始状态：

```cpp
list<int> L;
cout << "empty = " << L.empty() << endl;   // 1（空）
cout << "size = " << L.size() << endl;     // 0
```

> 空链表，empty = 1，size = 0，符合预期。

给它赋值一些数据再看：

```cpp
L.assign({1, 2, 3});
cout << "empty = " << L.empty() << endl;   // 0（非空）
cout << "size = " << L.size() << endl;     // 3
```

有数据之后，empty 变成 0，size 变成 3——里面有 3 个元素。

## resize：改变链表大小

resize 有两个重载版本，可以把链表变大或变小。

### 变大：多出的位置补默认值

```cpp
list<int> L = {1, 2, 3};
L.resize(8);   // 扩大到 8 个元素
// 结果：1 2 3 0 0 0 0 0
```

前三个元素还是 1 2 3 保持不变，后面新增的 5 个位置补 0（默认值）。

### 变大：多出的位置补指定值

```cpp
list<int> L = {1, 2, 3, 0, 0, 0, 0, 0};   // 接着上面 8 个元素
L.resize(10, 6);   // 扩大到 10 个，新元素补 6
// 结果：1 2 3 0 0 0 0 0 6 6
```

再扩大 2 个，这次指定新元素的值是 6。原来的 8 个不变，新增的两个变成 6。

### 变小：删掉后面多出的元素

```cpp
list<int> L = {1, 2, 3, 0, 0, 0, 0, 0, 6, 6};   // 10 个元素
L.resize(5);   // 缩小到 5 个
// 结果：1 2 3 0 0
```

缩小的时候，从后面往前删，保留前 5 个元素，后面的全部丢掉。

> [!TIP]
> **resize 的规律**
>
> - **扩大** → 保留前面的元素，后面补新值（默认 0 或你指定的 val）
> - **缩小** → 保留前面的元素，后面多余的删掉
>
> 总之，前面的元素尽量保留，变动都发生在尾部。

## 完整代码示例

```cpp
#include <iostream>
#include <list>
using namespace std;

void printList(const list<int>& L) {
    for (list<int>::const_iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << " ";
    }
    cout << "  (size=" << L.size() << ", empty=" << L.empty() << ")";
    cout << endl;
}

int main() {
    list<int> L;
    cout << "初始空链表：";
    printList(L);   // empty=1, size=0

    // 赋值 3 个元素
    L.assign({1, 2, 3});
    cout << "赋值后：    ";
    printList(L);   // empty=0, size=3

    // 扩大到 8 个（补 0）
    L.resize(8);
    cout << "resize(8)： ";
    printList(L);   // 1 2 3 0 0 0 0 0, size=8

    // 扩大到 10 个（补 6）
    L.resize(10, 6);
    cout << "resize(10,6)：";
    printList(L);   // 1 2 3 0 0 0 0 0 6 6, size=10

    // 缩小到 5 个
    L.resize(5);
    cout << "resize(5)： ";
    printList(L);   // 1 2 3 0 0, size=5

    return 0;
}
```

运行结果：

```
初始空链表：  (size=0, empty=1)
赋值后：    1 2 3   (size=3, empty=0)
resize(8)： 1 2 3 0 0 0 0 0   (size=8, empty=0)
resize(10,6)：1 2 3 0 0 0 0 0 6 6   (size=10, empty=0)
resize(5)： 1 2 3 0 0   (size=5, empty=0)
```

## 本章小结

**三个接口** — empty 判空、size 取元素个数、resize 改变大小。

**空链表状态** — empty = 1，size = 0；有数据后 empty = 0。

**resize 有两个重载** — 一个只传大小（新元素补 0），一个传大小 + 值（新元素补指定值）。

**扩大补后面** — 链表变大时，原数据保留，新增元素补在尾部。

**缩小删后面** — 链表变小时，保留前面的元素，后面多余的被删掉。

**可以反复扩大缩小** — resize 可以连续调用，想变多大变多大、想变多小变多小。
