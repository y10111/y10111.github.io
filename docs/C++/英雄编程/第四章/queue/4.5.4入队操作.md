## 本节概述：queue 的入队操作

入队（往队列里加元素）只有一个接口——**`push`**。它和 stack 的 push 名字一样、底层实现也几乎一样——都是在 deque 的尾部追加元素。

## 基本用法

```cpp
#include <queue>
using namespace std;

queue<int> q;
q.push(5);   // 入队 5
```

参数就是你要插入的元素。

> 入队 = 在队尾加一个新元素。

## push 内部干了什么

老规矩，F12 看源码：

```cpp
void push(const value_type& value) {
    c.push_back(value);   // c 就是底层 deque
}
```

`c` 还是那个底层容器（默认 deque），**push 做的事情就是调用 deque 的 `push_back`**。

```
   q.push(5)
      │
      │  queue::push
      ▼
   c.push_back(5)       （c 是底层 deque）
      │
      │  deque 的尾插
      ▼
   在 deque 尾部插入元素 5
```

> [!TIP]
> **跟 stack 的 push 一模一样**
>
> stack 的 push 也是 `c.push_back(value)`，queue 的 push 还是 `c.push_back(value)`。
> 两者底层完全相同，差别只在另一端：stack 从尾部 pop，queue 从头部 pop。

## 连续入队的变化

连续 push 几个元素，看看结构怎么变：

```cpp
queue<int> q;
q.push(5);   // [ 5 ]
             //  ↑   ↑
             // front back

q.push(4);   // [ 5 | 4 ]
             //  ↑       ↑
             // front   back

q.push(3);   // [ 5 | 4 | 3 ]
             //  ↑           ↑
             // front       back

q.push(2);   // [ 5 | 4 | 3 | 2 ]
             //  ↑               ↑
             // front           back

q.push(1);   // [ 5 | 4 | 3 | 2 | 1 ]
             //  ↑                   ↑
             // front               back
```

| 操作 | front 队头 | back 队尾 | 说明 |
|---|---|---|---|
| push(5) | 5 | 5 | 只有一个元素，头尾是同一个 |
| push(4) | 5 | 4 | 队头不动，队尾往后走 |
| push(3) | 5 | 3 | 队头还是 5 |
| push(2) | 5 | 2 | 队头还是 5 |
| push(1) | 5 | 1 | 队头还是 5 |

> 记住：**入队的时候，队头 front 不变，队尾 back 一直往后走。**
> 5 是最先进去的，所以它一直是队头；1 是最后进去的，所以它是队尾。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    q.push(5);
    cout << "front=" << q.front()
         << ", back=" << q.back()
         << ", size=" << q.size() << endl;

    q.push(4);
    cout << "front=" << q.front()
         << ", back=" << q.back()
         << ", size=" << q.size() << endl;

    q.push(3);
    cout << "front=" << q.front()
         << ", back=" << q.back()
         << ", size=" << q.size() << endl;

    q.push(2);
    cout << "front=" << q.front()
         << ", back=" << q.back()
         << ", size=" << q.size() << endl;

    q.push(1);
    cout << "front=" << q.front()
         << ", back=" << q.back()
         << ", size=" << q.size() << endl;

    return 0;
}
```

运行结果：

```
front=5, back=5, size=1
front=5, back=4, size=2
front=5, back=3, size=3
front=5, back=2, size=4
front=5, back=1, size=5
```

> 可以清楚看到：front 从头到尾都是 5（不变），back 一直在变（往后走），size 逐次 +1。

## 本章小结

**接口是 push** — `q.push(x)` 在队尾插入元素，参数就是要插入的值。

**底层是 push_back** — 实现只有一行 `c.push_back(value)`，底层就是 deque 的尾插。

**跟 stack 的 push 一模一样** — 两者底层都是 deque 的 push_back，区别只在出栈/出队的另一端。

**入队谁在动** — 队头 front 不变（始终是第一个进去的元素），队尾 back 一直往后走。

**5 是队头，1 是队尾** — 先入的在前面、后入的在后面，体现了先进先出的特点。
