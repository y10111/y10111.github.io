## 本节概述：queue 的赋值操作

queue 的赋值操作本身很简单，一个等号就搞定。但这节课的重点不在用法——而在于顺着调用链一层一层往下挖，看看赋值背后到底做了什么、效率怎么样。

## 基本用法

```cpp
#include <queue>
using namespace std;

queue<int> q1;
queue<int> q2;

q1 = q2;   // 把 q2 赋值给 q1
```

> 赋值就是把右边队列里的数据，完整复制一份给左边的队列。
> 实际开发中用得不多，主要是借它学底层原理。

## 调用链第一层：queue 没有 operator=

对 queue 的等号按 F12，搜 `operator=`——**发现根本没有**。

没有自己写的赋值运算符重载，那走的就是**编译器默认生成的赋值运算符**。

默认赋值做什么？**逐个成员调用自己的赋值**。

queue 只有一个成员 `c`（底层 deque），所以 `q1 = q2` 就变成：

```
   q1 = q2
      │
      │  默认逐成员赋值
      ▼
   q1.c = q2.c         （c 是 deque）
      │
      │  deque 的 operator=
      ▼
   deque 完成真正的数据复制
```

跟 stack 的赋值逻辑一模一样。

## 调用链第二层：deque 的 operator=

在 deque 的 `operator=` 里打断点，运行 `q1 = q2`——果然走进去了。

调用堆栈变成：

```
main
 └── queue<int>::operator=   ← 编译器默认生成的
      └── deque<int>::operator=   ← 真正干活的
```

那 deque 的赋值具体是怎么做的？继续往里挖。

## 调用链第三层：assign 逐元素拷贝

F11 单步往里进，会发现 deque 的 `operator=` 内部调用了一个叫 **`assign`** 的函数。

继续追 `assign` → `_Assign_range`，最后会看到核心逻辑：

> **一个 for 循环，从 begin 迭代器遍历到 end 迭代器，把元素一个一个赋值过去。**

也就是说，deque 的赋值本质是**逐元素拷贝**。

```
deque 的 operator=
   └── assign
        └── _Assign_range
             └── for 循环：
                 for (first != last; ++first, ++cur)
                     *cur = *first;
```

## 效率分析

既然是逐元素拷贝，时间复杂度就是 **O(n)**——有多少个元素，就要赋值多少次。

| 场景 | 效率 |
|---|---|
| 队列小（几十个元素） | 无所谓，很快 |
| 队列大（几万、几十万元素） | 很慢，要慎重 |

> [!WARNING]
> **大队列赋值要谨慎**
>
> 队列元素特别多的时候，赋值的开销非常大。
> 能用拷贝构造就别用赋值（构造阶段一次成型，不需要先释放旧数据再拷贝）；
> 能传引用就别传值（函数参数用 `const queue<T>&`，不走拷贝）。

## 调试翻车小插曲：以为走了拷贝构造

追代码的时候很容易产生一个错觉——"是不是走到拷贝构造了？"

在 deque 的拷贝构造里打个断点，运行赋值操作——**断点根本不触发**。

为什么？因为赋值是"对象已经存在，用新数据覆盖旧数据"，走的是 `operator=`；拷贝构造是"对象正在创建"，走的是构造函数。两个完全不同的阶段。

> 一开始判断错了很正常，断点没进去就说明思路不对，重新追就行，调试本身就是个不断修正的过程。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q1;
    queue<int> q2;

    // 给 q2 塞点数据
    for (int i = 1; i <= 5; i++) {
        q2.push(i * 10);
    }

    // 赋值：把 q2 复制给 q1
    q1 = q2;

    // 验证 q1 有数据了
    cout << "q1 size = " << q1.size() << endl;   // 5
    while (!q1.empty()) {
        cout << q1.front() << " ";
        q1.pop();
    }
    cout << endl;   // 10 20 30 40 50

    return 0;
}
```

运行结果：

```
q1 size = 5
10 20 30 40 50
```

## 本章小结

**用法很简单** — 一个等号 `q1 = q2` 即可，实际开发中用得少。

**queue 没有 operator=** — 搜源码没有自己实现赋值，用的是编译器默认的逐成员赋值。

**底层是 deque 的赋值** — queue 只有一个成员 `c`（deque），等号最终掉到 deque 的 `operator=`。

**deque 赋值走 assign** — 内部是一个 for 循环，逐元素从 begin 到 end 拷贝，时间复杂度 O(n)。

**大队列赋值要谨慎** — 元素多的时候效率不高，优先用拷贝构造或传引用。

**赋值 ≠ 拷贝构造** — 赋值是对象已存在时覆盖数据，拷贝构造是对象正在创建，两个完全不同的阶段。
