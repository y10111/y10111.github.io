## 本节概述：获取队尾元素

获取队尾元素用成员函数 **`back`**。队尾就是最后插入的那个元素——每次 push 完，back 一定是刚刚塞进去的那个数。

## 基本用法

```cpp
#include <iostream>
#include <queue>
using namespace std;

queue<int> q;
q.push(5);

cout << q.back() << endl;   // 5
```

> [!WARNING]
> **"未定义的标识符" 别慌**
>
> 写了 `queue<int> q;` 报这个错，99% 是漏了 `#include <queue>`。加上就好。

## back 内部干了什么

F12 看源码：

```cpp
reference back() {
    return c.back();   // 返回底层容器的最后一个元素
}
```

老配方——`c` 是底层 deque，`back` 返回的就是 **deque 的最后一个元素**。

```
   q.back()
      │
      │  queue::back
      ▼
   c.back()           （c 是底层 deque）
      │
      │  deque 的尾元素
      ▼
   返回 deque 尾部那个元素
```

> 跟 stack 的 `top()` 底层完全一样，都是 `c.back()`。只不过一个叫 top（栈顶），一个叫 back（队尾）。

## 入队时 back 永远是最后插入的

做个实验：for 循环从 0 到 4，每次 push 完立刻打印 back：

```cpp
queue<int> q;
for (int i = 0; i < 5; i++) {
    q.push(i);
    cout << "push " << i << ", back = " << q.back() << endl;
}
```

运行结果：

```
push 0, back = 0
push 1, back = 1
push 2, back = 2
push 3, back = 3
push 4, back = 4
```

**每次 back 都等于刚刚 push 进去的值。**

为什么？因为：

- `push(x)` 底层是 `c.push_back(x)` —— 往 deque 尾部塞
- `back()` 底层是 `c.back()` —— 取 deque 尾部元素

往尾部塞的那个元素，自然就是尾部元素。刚塞完立刻看尾部，看到的当然就是它。

```
push(0)  →  [ 0 ]                 ← back = 0（刚塞的）
push(1)  →  [ 0 | 1 ]             ← back = 1（刚塞的）
push(2)  →  [ 0 | 1 | 2 ]         ← back = 2（刚塞的）
push(3)  →  [ 0 | 1 | 2 | 3 ]     ← back = 3（刚塞的）
push(4)  →  [ 0 | 1 | 2 | 3 | 4 ] ← back = 4（刚塞的）
```

> [!TIP]
> **一句话总结**：入队时，**front 不变、back 在变**；back 永远等于最新入队的那个元素。

## 什么时候会用到队尾

做题的时候，队尾其实**不常用**。

| 场景 | 用不用队尾 | 说明 |
|---|---|---|
| 广度优先搜索（BFS）等普通队列 | ❌ 不用 | 只用到先进先出，拿队头就够了 |
| **单调队列** | ✅ 要用 | 队尾也要操作（插入 + 删除） |

> 普通队列只有一端插、一端删。
> 单调队列则是一端只能删、另一端可以插也可以删——所以必须能拿到队尾才能做。
>
> 单调队列属于算法部分的内容，后面算法课再细讲。现在先把 `back` 这个接口记住就行。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 连续入队，每次打印 front 和 back
    for (int i = 0; i < 5; i++) {
        q.push(i);
        cout << "push " << i
             << ", front = " << q.front()
             << ", back = " << q.back() << endl;
    }

    return 0;
}
```

运行结果：

```
push 0, front = 0, back = 0
push 1, front = 0, back = 1
push 2, front = 0, back = 2
push 3, front = 0, back = 3
push 4, front = 0, back = 4
```

> 对比看更直观：front 从头到尾都是 0（不变），back 从 0 走到 4（每次 +1）。

## 本章小结

**接口是 back** — `q.back()` 获取队尾元素，返回队尾元素的引用。

**底层是 deque 的 back** — 实现就是 `return c.back()`，返回底层 deque 的最后一个元素。

**back = 最新入队的** — 因为 push 是 push_back，刚塞到尾部的那个自然就是 back，所以每次 push 完 back 都是刚塞的值。

**入队特征** — front 不变、back 在变，一前一后体现了先进先出。

**队尾什么时候用** — 普通队列（如 BFS）一般不用队尾，单调队列才需要操作队尾。
