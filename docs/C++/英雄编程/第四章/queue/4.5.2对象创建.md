## 本节概述：queue 的对象创建

queue 的对象创建和 stack 几乎一模一样——只有**两种**：默认构造和拷贝构造。这节课除了用法，还会深挖一下构造函数的底层，看看 `=default` 是什么意思、构造函数最终调到哪里去了。

## 两种创建方式总览

| 方式 | 语法 | 说明 |
|---|---|---|
| 1. 默认构造 | `queue<int> q` | 空的队列 |
| 2. 拷贝构造 | `queue<int> q2(other)` | 复制另一个同类型 queue |

> 跟 stack 一样，queue 也没有初始化列表、迭代器区间、count 个值等创建方式——因为它也是访问受限的适配器，没有迭代器。

## 方式一：默认构造

最常用的一种，尖括号里指定元素类型：

```cpp
#include <queue>
using namespace std;

queue<int> q1;       // 空的 int 队列
```

元素类型可以是任意的：

```cpp
queue<double> qd;           // double 类型
queue<Person> qp;           // 自定义结构体或类
queue<queue<int>> qq;       // 甚至可以嵌套队列（队列里装队列）
```

> [!TIP]
> 类型怎么来的？因为 queue 是个**类模板**，第一个模板参数 `T` 就是元素类型。
> 你传什么类型，它就存什么类型。

## 方式二：拷贝构造

括号里传一个**同类型**的已有队列对象：

```cpp
queue<int> q2(q1);    // 把 q1 完整拷贝一份给 q2
```

> 函数签名：`queue(const queue& other)`
> 拷贝完之后两个队列各自独立，互不影响。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    // 1. 默认构造
    queue<int> q1;
    q1.push(10);
    q1.push(20);
    q1.push(30);

    // 2. 拷贝构造
    queue<int> q2(q1);

    // 验证拷贝成功
    cout << "q1 front = " << q1.front() << endl;   // 10
    cout << "q1 back = " << q1.back() << endl;     // 30
    cout << "q1 size = " << q1.size() << endl;     // 3

    cout << "q2 front = " << q2.front() << endl;   // 10
    cout << "q2 back = " << q2.back() << endl;     // 30
    cout << "q2 size = " << q2.size() << endl;     // 3

    return 0;
}
```

运行结果：

```
q1 front = 10
q1 back = 30
q1 size = 3
q2 front = 10
q2 back = 30
q2 size = 3
```

## 深入底层：构造函数调到哪去了

内容比较少，借这节课挖深一点——看看构造函数的底层原理。

### = default 是什么

对 queue 的默认构造函数按 F12，会看到：

```cpp
queue() = default;
```

这个 **`= default`** 的意思是：**让编译器生成默认实现**，我自己不写。

默认实现做什么呢？就是把所有成员变量挨个初始化。

### queue 只有一个成员

跳转到 queue 类的成员部分（大约 154 行附近），会发现 queue 和 stack 一样——**只有一个成员变量 `c`**，类型就是模板参数里的 `Container`（默认 deque）：

```cpp
template <class T, class Container = deque<T>>
class queue {
protected:
    Container c;   // 就这一个成员，默认是 deque
    // ...
};
```

所以默认构造函数实际干的事就是：**调用 `c` 的构造函数**，也就是 deque 的默认构造。

### 断点验证

在 deque 的构造函数里打个断点，运行 `queue<int> q1;`——

程序会停在 deque 的构造函数里，调用堆栈显示：

```
main
 └── queue<int>::queue()      ← queue 的默认构造（=default）
      └── deque<int>::deque() ← 最终调到 deque 的构造函数
```

完美印证——queue 自己不干活，全甩给底层 deque。

## 拷贝构造呢

拷贝构造也是同样的套路：F12 进去看 queue 的拷贝构造，它做的事就是**调用底层 deque 的拷贝构造**。

```cpp
queue(const queue& other) = default;
```

> [!WARNING]
> **拷贝构造 ≠ 赋值**
>
> 注意，这里走的是**拷贝构造函数**，不是赋值运算符 `operator=`。
> 因为这是**初始化阶段**——对象正在被创建，还不存在，所以调用构造函数。
>
> 只有对象已经存在、再用等号覆盖，才走赋值。
>
> 这是面向对象里的基础知识，如果这里懵，建议回去把面向对象的拷贝构造和赋值重载复习一下。

### 断点验证翻车小插曲

老师一开始在 deque 里找拷贝构造，断点打错位置、程序没进去——这不是 bug，而是**找错了函数**。仔细往下翻找到真正的 deque 拷贝构造函数再打断点，程序就停进去了，调用堆栈显示：

```
main
 └── queue<int>::queue(const queue&)   ← queue 的拷贝构造
      └── deque<int>::deque(const deque&) ← deque 的拷贝构造
```

> 调试时断点没触发，多半是打错了位置或者函数不是你以为的那个，别急着怀疑编译器。

## 本章小结

**只有两种创建方式** — 默认构造 `queue<int> q` 和拷贝构造 `queue<int> q2(other)`，跟 stack 完全一样。

**元素类型灵活** — int、double、自定义类型、甚至嵌套的 queue 都可以，因为它是类模板。

**= default 的含义** — 让编译器自动生成默认实现，本质就是逐个初始化成员变量。

**只有一个成员 c** — queue 只有一个成员变量 `Container c`，默认就是 deque，所有存储工作都交给它。

**默认构造 → deque 默认构造** — queue 自己不管理内存，构造时直接调底层 deque 的构造函数。

**拷贝构造 → deque 拷贝构造** — 拷贝时走的是 deque 的拷贝构造函数，不是赋值（初始化阶段调构造，不是赋值）。
