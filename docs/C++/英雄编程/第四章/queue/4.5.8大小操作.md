## 本节概述：queue 的大小操作

queue 的大小操作有两个接口：**`empty`** 和 **`size`**。前者判空，后者取元素个数。这俩函数非常简单，但 `empty` 尤其重要——它是队列安全操作的保护神。

## 两个接口总览

| 接口 | 返回值 | 作用 |
|---|---|---|
| `q.empty()` | `bool`（true/false） | 队列是否为空 |
| `q.size()` | `size_t`（无符号整数） | 队列中元素个数 |

> STL 的函数名都很规范，小写字母开头，看到名字基本就知道干什么的——push 塞元素、pop 弹元素、front 队首、back 队尾、empty 判空、size 大小，好记又好读。

## 标准写法：while (!empty) 遍历

队列没有迭代器，不能像 vector 那样 for 循环遍历。标准做法是**边出队边处理**：

```cpp
while (!q.empty()) {
    // 做你想做的事，比如取队首
    cout << q.front() << " ";
    // 出队
    q.pop();
}
```

> [!TIP]
> **为什么用 while 不是 for？**
>
> 因为你不知道队列里有多少个元素也能写——只要非空就继续，空了自然停下。
> 而且 `empty()` 还能保证你不会在空队列上调用 front / pop，天然安全。

## 出队过程中 front / back / size 的变化

往队列里塞 0 1 2 3 4 共 5 个元素，然后边出队边打印 front、back、size：

| 第几次 | front | back | size | 说明 |
|---|---|---|---|---|
| 第 1 次 | 0 | 4 | 5 | 初始状态，5 个元素 |
| 第 2 次 | 1 | 4 | 4 | 出了一个，size 减 1 |
| 第 3 次 | 2 | 4 | 3 | front 往后走 |
| 第 4 次 | 3 | 4 | 2 | back 一直没变 |
| 第 5 次 | 4 | 4 | 1 | 剩最后一个 |
| 出完后 | — | — | 0 | 空队列，empty = true |

规律：

- **front 一直在变**（往后挪）
- **back 一直不变**（出队不影响队尾）
- **size 逐次 -1**，从 5 一直减到 0

## size 是怎么算的

直观理解：**元素个数 = 队尾位置 − 队头位置 + 1**。

```
[ 0 | 1 | 2 | 3 | 4 ]
  ↑               ↑
front           back

size = back − front + 1
     = 4 − 0 + 1
     = 5
```

> 当然这里的 0 和 4 是元素值，不是下标。真正底层用的是迭代器的位置差。
> 原理是一样的：尾迭代器位置 − 头迭代器位置 + 1 = 元素个数。

## 底层实现

本着探索精神，F12 看源码：

```cpp
bool empty() const {
    return c.empty();   // 调用底层容器的 empty
}

size_type size() const {
    return c.size();    // 调用底层容器的 size
}
```

又是老配方——直接把活儿甩给底层的 deque。

```
q.empty()  →  c.empty()  →  deque 的判空
q.size()   →  c.size()   →  deque 的大小
```

那 deque 的 empty 又做了什么？追进去会发现——**就是判断 size 是否等于 0**：

```cpp
bool empty() const {
    return size() == 0;
}
```

> 所以 `empty()` 和 `size() == 0` 本质是一回事，只是 empty 读起来更自然、更语义化。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 入队 5 个元素：0 1 2 3 4
    for (int i = 0; i < 5; i++) {
        q.push(i);
    }

    cout << "=== 出队过程 ===" << endl;
    while (!q.empty()) {
        cout << "front=" << q.front()
             << ", back=" << q.back()
             << ", size=" << q.size() << endl;
        q.pop();
    }

    // 出完后
    cout << "empty = " << q.empty() << endl;   // 1
    cout << "size = " << q.size() << endl;     // 0

    return 0;
}
```

运行结果：

```
=== 出队过程 ===
front=0, back=4, size=5
front=1, back=4, size=4
front=2, back=4, size=3
front=3, back=4, size=2
front=4, back=4, size=1
empty = 1
size = 0
```

> 完美印证：front 从 0 走到 4，back 一直是 4，size 从 5 减到 0。

## 本章小结

**两个接口** — `empty()` 判空（返回 bool），`size()` 取元素个数（返回 size_t）。

**标准遍历写法** — `while (!q.empty()) { q.front(); q.pop(); }`，既方便又安全。

**出队变化规律** — front 往后挪（一直变），back 不动（一直不变），size 逐次 -1。

**size 的计算** — 尾位置 − 头位置 + 1 = 元素个数，底层用迭代器位置差来算。

**底层是转发** — empty 和 size 都是直接调用底层 deque 的对应函数，queue 自己不计算。

**empty 就是 size == 0** — deque 的 empty 内部就是判断 size 是否为 0，两者等价但 empty 更语义化。
