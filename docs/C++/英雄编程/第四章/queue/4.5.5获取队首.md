## 本节概述：获取队首元素

获取队首元素用成员函数 **`front`**。名字很直观——STL 的命名都比较规范，小写字母开头，看到名字基本就知道干什么的。

## 基本用法

```cpp
#include <iostream>
#include <queue>
using namespace std;

queue<int> q;
q.push(5);

cout << q.front() << endl;   // 5
```

> 队首元素就是最先进去的那个元素。

## front 内部干了什么

F12 看源码：

```cpp
reference front() {
    return c.front();   // 返回底层容器的第一个元素
}
```

`c` 是底层 deque，`front` 做的就是返回 **deque 的第一个元素**。

```
   q.front()
      │
      │  queue::front
      ▼
   c.front()          （c 是底层 deque）
      │
      │  deque 的头元素
      ▼
   返回 deque 头部那个元素
```

## 入队时 front 为什么不变

我们做一个实验：每插入一个元素就打印一次队首。

```cpp
queue<int> q;
q.push(5);  cout << q.front() << " ";   // 5
q.push(4);  cout << q.front() << " ";   // 5
q.push(3);  cout << q.front() << " ";   // 5
q.push(2);  cout << q.front() << " ";   // 5
q.push(1);  cout << q.front() << " ";   // 5
```

输出：

```
5 5 5 5 5
```

**队首一直都是 5，没变过。** 为什么？

因为入队是往 deque 的**尾部**插（push_back），尾部加元素不影响头部——第一个元素当然还是第一个元素。

```
push(5)  →  [ 5 ]                 ← front = 5
push(4)  →  [ 5 | 4 ]             ← front = 5（没变！）
push(3)  →  [ 5 | 4 | 3 ]         ← front = 5（没变！）
push(2)  →  [ 5 | 4 | 3 | 2 ]     ← front = 5（没变！）
push(1)  →  [ 5 | 4 | 3 | 2 | 1 ] ← front = 5（没变！）
```

> [!TIP]
> **往后面插，第一个元素永远不变**
>
> 对于任何一个序列，只要是往尾部追加元素，第一个元素就始终是同一个。
> 队首 front 就是第一个元素，所以入队过程中 front 不变。
>
> 这也符合"先进先出"的特点——先到的在队头，后来的都排在后面。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 每入队一个，就打印队首
    for (int i = 5; i >= 1; i--) {
        q.push(i);
        cout << "push " << i
             << ", front = " << q.front()
             << ", back = " << q.back() << endl;
    }

    return 0;
}
```

运行结果：

```
push 5, front = 5, back = 5
push 4, front = 5, back = 4
push 3, front = 5, back = 3
push 2, front = 5, back = 2
push 1, front = 5, back = 1
```

> front 全程都是 5，back 一直在变——队头不动、队尾往后走，这就是入队的特征。

> [!WARNING]
> **空队列不能 front！**
>
> 队列为空时调用 `front()` 是未定义行为，会触发断言报错。
> 取值前先用 `empty()` 判断一下。

## 学 STL 的小技巧

这节课顺便带出一个学习方法：**多看源码**。

STL 里很多函数，按一下 F12 跳进源码看一眼实现，原理立刻就清楚了。不用死记硬背——知道了底层是什么，自然就知道它会有什么行为。

比如这节课的 front：

- 跳进源码 → 发现是 `c.front()`
- 知道 c 是 deque → front 就是 deque 的第一个元素
- 入队是 push_back → 尾部追加不影响头部 → front 不变

**逻辑顺下来，结论自己就出来了。**

## 本章小结

**接口是 front** — `q.front()` 获取队首元素，返回队首元素的引用。

**底层是 deque 的 front** — 实现就是 `return c.front()`，返回底层 deque 的第一个元素。

**入队时 front 不变** — 因为入队是往尾部 push_back，第一个元素永远是第一个，所以队首一直不变。

**front 不变、back 在变** — 这是入队过程的特征：队头不动、队尾往后走。

**学 STL 多看源码** — F12 跳进去看一眼，原理立刻就懂，不用死记硬背。

**空队列不能取** — 取队首前先 `empty()` 检查，否则崩溃。
