## 本节概述：queue 的出队操作

出队（从队头删掉一个元素）调用的是 **`pop`** 函数。它和 stack 的 pop 名字一样，但删的位置不一样——stack 从尾部删，queue 从头部删。

## 基本用法

```cpp
#include <queue>
using namespace std;

queue<int> q;
q.push(10);
q.push(20);

q.pop();   // 删掉队头（10）
```

> 每次 `pop` 就从队头去掉一个元素——最先进去的那个先走。

| 接口 | 在哪一端 | 说明 |
|---|---|---|
| `push(x)` | 队尾 back | 入队 |
| `pop()` | 队头 front | 出队，只删队头 |

## pop 内部干了什么

按 F12 看源码：

```cpp
void pop() {
    c.pop_front();   // 弹掉底层容器的第一个元素
}
```

又是一行代码——调用了底层 deque 的 **`pop_front`**（头删）。

```
   q.pop()
      │
      │  queue::pop
      ▼
   c.pop_front()      （c 是底层 deque）
      │
      │  deque 的头删
      ▼
   删掉 deque 头部那个元素
```

> [!TIP]
> **跟 stack 的 pop 不一样**
>
> - stack 的 pop → `c.pop_back()` — 从尾部删
> - queue 的 pop → `c.pop_front()` — 从头部删
>
> 这就是两者最核心的区别：一个后进先出，一个先进先出。

## 出队时谁在动

先往队列里塞 0 1 2 3 4，然后连续 pop，每次 pop 前打印 front 和 back：

```
初始：    [ 0 | 1 | 2 | 3 | 4 ]    front=0, back=4
pop() 后：[ 1 | 2 | 3 | 4 ]        front=1, back=4（front 变了！）
pop() 后：[ 2 | 3 | 4 ]            front=2, back=4（front 又变了！）
pop() 后：[ 3 | 4 ]                front=3, back=4（back 没变！）
pop() 后：[ 4 ]                    front=4, back=4（还没变）
pop() 后：[ 空 ]                   空队列
```

规律很明显：

- **队头 front 一直在变** — 每出一个，队头就往后挪一格
- **队尾 back 一直没变** — 出队不从尾部删，队尾当然不动

> 这正好和入队反过来：入队时 front 不变、back 在变；出队时 back 不变、front 在变。

## 印证先进先出

出队顺序是什么？依次是 **0 → 1 → 2 → 3 → 4**。

入队顺序也是 0 → 1 → 2 → 3 → 4。

**进去的顺序 = 出来的顺序**——这就是**先进先出 FIFO**。

```
入队顺序：  0 → 1 → 2 → 3 → 4
出队顺序：  0 → 1 → 2 → 3 → 4
```

> 先到的先走，后来的后走，跟排队打饭一模一样。

## 完整代码示例

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 入队 5 个元素：0 1 2 3 4
    for (int i = 0; i < 5; i++) {
        q.push(i);
    }

    // 出队过程：每次 pop 前打印 front 和 back
    for (int i = 0; i < 5; i++) {
        cout << "front = " << q.front()
             << ", back = " << q.back() << endl;
        q.pop();
    }

    // 验证队列已空
    cout << "empty = " << q.empty() << endl;   // 1

    return 0;
}
```

运行结果：

```
front = 0, back = 4
front = 1, back = 4
front = 2, back = 4
front = 3, back = 4
front = 4, back = 4
empty = 1
```

> 观察一下：front 从 0 一路变到 4，back 全程都是 4——完美印证了"出队时 front 变、back 不变"。

> [!WARNING]
> **空队列不能 pop！**
>
> 队列为空时调用 `pop()` 是未定义行为，会触发断言报错。
> 出队前一定先用 `empty()` 判断一下。
>
> 标准写法是 `while (!q.empty()) { ... q.pop(); }`，既安全又简洁。

## 本章小结

**接口是 pop** — `q.pop()` 删除队头元素，没有参数。

**底层是 pop_front** — 实现只有一行 `c.pop_front()`，弹掉底层 deque 的第一个元素。

**跟 stack 的 pop 位置不同** — stack 从尾部 pop_back，queue 从头部 pop_front，这是 LIFO 和 FIFO 的根本区别。

**出队时谁在动** — front 一直在变（往后挪），back 一直不变（队尾不受影响）。

**印证先进先出** — 入队顺序 01234，出队顺序也是 01234，先到先走。

**空队不能弹** — 出队前先 `empty()` 检查，标准写法是 `while (!q.empty())`。
