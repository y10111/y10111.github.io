## 准备工作：需要哪些工具

要用 C++ 编写程序，只需要两样东西：一台电脑，以及一套能"构建"C++ 程序的工具。这套工具取决于你的操作系统——本集以 Windows 为例（Windows 是游戏行业使用最广泛的操作系统），Mac 和 Linux 用户可跳转到对应的视频。

## 工具链速览：从源码文本到可运行程序

要写 C++ 代码，表面上看一个记事本就够了——你写的 .cpp 文件本质上就是纯文本。但我们还需要**编译器**：它把我们写好的文本翻译成可执行的二进制文件（在 Windows 上就是 .exe），程序才能真正运行起来。所以这条流水线是：

```mermaid
flowchart LR
    A["源代码文本<br/>（.cpp 文件）"] --> B["编译器 Compiler"]
    B --> C["可执行二进制<br/>（.exe 文件）"]
    C --> D["运行程序"]
```

不过用记事本写 C++ 并不现实——写代码容易出错，记事本帮不上忙。这时候就需要 **IDE（集成开发环境）**：它是一整套帮你编写、调试代码的工具集合。在 Windows 上，我们选用 **Microsoft Visual Studio**——作者用过很多 IDE，认为它虽然不是完美的，但几乎是目前能找到的最好的，也是游戏行业最流行的 IDE（插件能帮你适配 PC、移动设备、游戏主机等几乎所有平台）。

> [!TIP]
> **Visual Assist 插件**：作者强烈推荐的第三方插件（个人许可证约 99 美元），能补上 Visual Studio 缺失的很多功能。作者声明并非受赞助，纯粹好用。没有它课程也能继续，只是会遇到一些警告。

## 创建第一个项目：Hello World

为验证工具链是否正常，我们创建一个输出 "Hello World" 的小程序。

**第一步，新建空项目**：菜单「文件 > 新建 > 项目」→ 左侧选「Visual C++ > 常规」→ 模板选「空项目」。给项目起名 "Hello World"。

**存放位置建议**：项目应该放在一个好路径下。作者推荐放在磁盘根目录的文件夹里（例如 `C:\CPPSeries`），理由有两个：

> [!WARNING]
> 不要放在系统默认的"用户目录"下，否则路径过长；更要避免路径中包含**空格**——某些插件会因此无法工作（例如 NVIDIA 的 Android 版 Visual Studio 插件某些组件，路径里有空格就会出问题）。

**第二步，添加源文件**：把"解决方案资源管理器"停靠到左侧，右键「源文件」→「添加 > 新建项」→ 选择"C++ 文件"，命名为 main.cpp。

**第三步，编写代码**：在 main.cpp 中输入以下内容：

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello World!" << std::endl;
    std::cin.get();
}
```

> [!NOTE]
> **这里顺带理解两个概念**：Visual Studio 里有"解决方案"和"项目"两个层级——**解决方案**像你的工作台，是一组相互关联的项目；**项目**本质上是一组会被编译成某个目标二进制文件（库或可执行程序）的文件集合。

**第四步，编译运行**：右键项目 →「生成」，输出窗口会给出结果。成功后会在项目目录下生成 `Hello World.exe`（Windows 可执行二进制），双击即可运行，控制台会打印 Hello World，按回车程序结束；也可以在 Visual Studio 里点「本地 Windows 调试器」按钮编译并运行。

## 本章小结

这一集没有任何语法讲解，目标是搭建完整的 Windows 开发工具链并跑通第一个程序：

**工具选择**：写 C++ 需要三件套——文本编辑器/IDE（选 Visual Studio）、编译器（把文本转成可执行文件）、以及理解"源码 → 编译 → 可执行文件 → 运行"这条流水线。

**安装要点**：Visual Studio Community 2017 免费，安装时只需勾选"使用 C++ 进行桌面开发"一个工作负载，其余组件按需取舍。

**路径规范**：项目目录放在磁盘根目录下，路径要短、不能含空格，否则插件会出问题——这是新手最容易踩的坑。

**项目结构**：理解了"解决方案（若干相关项目的集合）= 工作台"与"项目（一组文件 → 编译成一个二进制产物）"的层级关系。

**验证结果**：成功编译并运行了第一个 C++ 程序（标准 99 行不到的 Hello World），工具链正式可用。接下来的视频会讲解 C++ 的工作原理——理解它，是写出正确 C++ 代码的关键。
